# Kline Quant · Curriculum V2 / 课程内容与发布规范

> 状态：增量实施中（不是全站完成声明）。规范适用于 `quant/math`、`quant/ml` 和二者之间的知识链。禁止按篇数或字数机械充数；不设置练习题模块；优先使用可核查的原始论文、开放教材与官方文档。所有新讲义先通过内容审查，再接入网站。

## 1. 整体课程设计

- **领域 / 课程群**：数学的基础分析、概率统计、优化、金融数学；ML 的统计学习、经典算法、深度学习、决策学习及量化研究。
- **知识链 / 章节**：按严格先修与研究问题建立，而不是按发布时间或算法名字简单拼接。
- **知识点 / 正文**：每篇讲义应能独立回答一个明确问题，同时保留与前后知识点的逻辑关系。
- **正文内部分节**：问题与对象 → 严格定义、维度、单位 → 必要条件 → 核心公式与证明 → 性质、计算和数值核验 → 反例或失效条件 → 研究应用 → 延伸。
- 数学完整证明以 `math` 为权威版本，机器学习可以概述必要的推导，但通过明确链接指向数学原稿，避免维护两个不同的数学事实版本。
- **依赖类型**：严格先修（prerequisite）、相关延伸（related）、应用（application）；不可用“下一篇”冒充严格先修。
- 所有数值、公式与解释都应明确条件。模型训练可行、统计推断有效、样本外性能优良、实盘可交易是四种不同命题。

## 2. 内容质量的完成条件

一篇数学讲义标记为完整之前，至少包含：

1. 研究对象、动机和严格定义，写明空间、内积或概率条件、参数维度与计量单位。
2. 必需且尽可能弱的假设；每个重要结论指出该假设在何处使用。
3. 核心性质及定理，完整逻辑证明；如使用深层定理，应给出准确引用和适用条件。
4. 一组从输入到中间计算、最终结果均可复核的数值例子。
5. 合理的反例、退化情形、极限情形或数值失败机制。
6. 与其他知识点的明确连接，以及至少两项可靠资料（没有适用资料时需说明原因）。
7. 自检：KaTeX语法、符号一致、维度和时间可得性、算例独立复算。

一篇机器学习或量化研究讲义标记为完整之前，在上述标准上还应明确：

1. 预测对象和观测数据的抽样粒度、可得信息集、标签成熟时间、数据泄漏风险。
2. 模型目标函数与软件参数尺度；超参数、优化求解和停止条件。
3. 基线模型、训练/验证/测试协议与模型选择机制，尤其是金融时间依赖和重叠目标。
4. 数学统计评价与经济业务评价的区别；若为交易策略，记录权重、融资、借券、换手及成本口径。
5. 允许报告失败实验，禁止以样本内性能、单次回测或公式正确代替未来表现的证据。

质量标准不是字数门槛，论证确有必要时应延展；对于短而严格的基础定理不应为了凑字数制造机械重复。

**机器学习层**：

数学和ML的入口应双向导航；章节内均应采用研究问题、算例与边界先导的小节组织。**尚未深化的其他课程不能据此宣称整体达到相同的讲义标准。**

## 4. 保留兼容与稳定交付

- 原课程知识点 ID 保持不变。原数学简稿由更完整的相同 ID 内容取代，不能同时加载两份讲义。
- 增加 ML 专题时使用唯一新 ID；不得破坏原归档的720个ID及其浏览器学习进度。
- 修改目录先审核先修有向图，拒绝不存在的依赖和循环依赖；不同学科链接必须经过现有实际课程目录检查。
- 内容模块独立分组，清单记录路径和数量；正式页面采用有界并发、校验和缓存版本控制，避免局部故障令全站不可读。
- 每批使用 GitHub 提交及 Actions 验证：JSON结构、唯一ID、全部LaTeX、数值算例、跨页链接、页面挂载、Python脚本（如涉及）。
- GitHub Actions 完成不等于人工审稿、真实浏览器或金融实盘验证。部署成功以后仍需检查实际站点的新正文、搜索、进度和跨设备路径。
- 若新版本无法通过验证，先修复或恢复至可用版本，不以失败状态作为完成交付。

## 5. 学术来源与版权

优先使用 MIT 18.06/OCW、Stanford CS229/CS229T、ISL/ESL、Boyd凸优化、scikit-learn、statsmodels、官方论文与代码仓库；金融项目可参考 Qlib 等具有研究链路的开源项目。

公开可读不等于可复制。代码、图表、正文与翻译分别核查许可证及附带第三方素材，保留署名和版本。对于不允许改编的教材，仅在独立推导和研究核查层面参考，不整段复制或公开翻译原文。重要公式优先引用第一手来源，禁止把参考链接当作内容真实性的唯一证明。

## 6. 后续工作队列与审查优先级

1. **先修数学补缺**：内积与正交、Gram–Schmidt、QR、特征值谱定理、伪逆、Gauss–Markov及凸最优性，尤其是现有仍为“知识目录”的节点。
2. **正则化闭环**：Elastic Net、偏差方差、交叉验证、模型选择偏差、选择后统计推断和泛化保证。
3. **数学与ML对接**：概率与统计学习的ERM、集中界、稳定性、核方法；严格区分共同的数学证明与ML训练方法。
4. **金融研究闭环**：点时ETF因子、收益标签、模型比较、组合优化、净值/现金账本、容量与压力测试。
5. **其他领域逐链推进**：连续时间金融、概率图、深度模型、强化学习、因果机器学习、高维概率、最优传输和微观结构，优先依赖密度高、可复用价值高的节点。

实施只以已经验证的内容和明确的完成标准计算进度；不得将待扩展目录节点当作完成的正式教材。每一轮后检查相邻知识点的定义、符号口径、先修关系与内容重复，再扩大范围。
