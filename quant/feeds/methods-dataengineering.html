交易流序号缺口与重复事件诊断

模型与推导

序号高水位只增不减，新序号跳跃记录检测时缺口，低于或等于高水位标记为重复或迟到。缺口是当时未见序号，不保证最终丢失；该程序不恢复乱序消息。

$$H_t=\max(H_{t-1},s_t),\quad g_t=(s_t-H_{t-1}-1)_+$$
$$\ell_t=\mathbf1\{s_t\le H_{t-1}\}$$

研究应用与成立条件

序号10、11、11、14、13、15，14处检测缺2条，13随后迟到。真实交易所多频道有各自序号空间，应按会话和频道隔离，重连需恢复状态。

时点可用数据与陈旧度过滤

模型与推导

时点一致性要求数据实际可用时间不晚于决策时刻，进一步按最大陈旧度过滤。实现对已经关联的观测逐条检验，未来数据直接拒绝，陈旧数据保留原值和标志以便诊断。

$$a_i=t_i^{\mathrm{decision}}-t_i^{\mathrm{available}}$$
$$I_i=\mathbf1\{0\le a_i\le a_{\max}\}$$

研究应用与成立条件

决策10、20、30对应可用8、20、25，年龄2、0、5，阈值3拒绝最后一条。实际as-of连接须使用发布或到达时间而非经济归属期，并处理修订数据版本。

分段交易延迟及尾部分位数

模型与推导

按同一时钟单位计算分段及往返延迟，经验分位数采用最近秩。单向延迟只有时钟同步且定义一致才有意义；往返延迟不依赖交易所绝对时钟，但仍要求端点正确关联。

$$L_i^{\mathrm{out}}=t_i^{\mathrm{exchange}}-t_i^{\mathrm{send}},\quad L_i^{\mathrm{in}}=t_i^{\mathrm{ack}}-t_i^{\mathrm{exchange}}$$
$$Q_\alpha=L_{(\lceil\alpha n\rceil)}^{\mathrm{RT}},\quad L_i^{\mathrm{RT}}=L_i^{\mathrm{out}}+L_i^{\mathrm{in}}$$

研究应用与成立条件

往返延迟5、5、10、6，均值6.5、75％分位6、最大10。尾部平均不能由两个分段分位数相加获得；需区分网络、网关及撮合延迟。

成交回报的持仓、现金与权益守恒

模型与推导

现金和持仓是成交状态的两个守恒账户，标记权益等于现金加持仓市值。权益变化拆为旧仓价格变化、新成交相对标记价格的影响及费用。代码输出成交标记项，不将它误作全部权益变化。

$$q_t=q_{t-1}+\Delta q_t,\quad C_t=C_{t-1}-P_t\Delta q_t-f_t$$
$$E_t=C_t+q_tm_t,\quad\Delta E_t=q_{t-1}(m_t-m_{t-1})+\Delta q_t(m_t-P_t)-f_t$$

研究应用与成立条件

起始现金1000，买2、卖1、再卖1，最终持仓0、现金及权益1001。未处理借贷、期货保证金或外部现金流；实际系统须对重复成交ID去重，费用返佣允许负值。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace methods_dataengineering {
using namespace evidence;
inline Report sequence_gap(const Mat& x,const Vec& p){
    validate(x,1,1,1);
    parameters(p,0);
    double h=0;
    Report o{{"Row","Sequence","GapDetected","DuplicateOrLate","HighWatermark"},{}};
    for(std::size_t i=0;
    i<x.size();
    ++i){double v=x[i][0];
    require(v>=0&&v<=9007199254740991.&&v==std::floor(v),"Sequence must be exact integer");
    double g=i?std::max(v-h-1,0.):0,l=i?double(v<=h):0;
    h=i?std::max(h,v):v;
    o.rows.push_back({double(i+1),v,g,l,h});
    }return o;
    
}

inline Report asof_staleness(const Mat& x,const Vec& p){
    validate(x,1,3,3);
    parameters(p,1);
    require(p[0]>=0,"Negative age limit");
    Report o{{"DecisionTime","Age","Accepted","Value"},{}};
    for(auto&r:x){double a=r[0]-r[1];
    require(a>=0,"Future information detected");
    o.rows.push_back({r[0],a,double(a<=p[0]),r[2]});
    }return o;
    
}

inline Report latency_tail(const Mat& x,const Vec& p){
    validate(x,1,3,3);
    parameters(p,1);
    require(p[0]>0&&p[0]<=1,"Invalid quantile");
    double a=0,b=0;
    Vec v;
    for(auto&r:x){require(r[1]>=r[0]&&r[2]>=r[1],"Invalid event chronology");
    a+=r[1]-r[0];
    b+=r[2]-r[1];
    v.push_back(r[2]-r[0]);
    }std::sort(v.begin(),v.end());
    auto n=x.size(),k=std::size_t(std::ceil(p[0]*n))-1;
    return scalar({"MeanOutbound","MeanInbound","MeanRoundTrip","RoundTripQuantile","Maximum"},{a/n,b/n,(a+b)/n,v[k],v.back()});
    
}

inline Report position_cash_reconcile(const Mat& x,const Vec& p){
    validate(x,1,4,4);
    parameters(p,1);
    double c=p[0],q=0;
    Report o{{"Trade","Position","Cash","MarkedEquity","TradeMarkImpact"},{}};
    for(std::size_t i=0;
    i<x.size();
    ++i){auto&r=x[i];
    positive(r[1]);
    positive(r[3]);
    q+=r[0];
    c-=r[0]*r[1]+r[2];
    o.rows.push_back({double(i+1),q,c,c+q*r[3],r[0]*(r[3]-r[1])-r[2]});
    }return o;
    
}
