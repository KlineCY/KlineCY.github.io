1．离散二次风险下的Almgren–Chriss执行路径

模型结构与数学定义

将暂态冲击近似为成交量平方成本，将持仓未清算风险近似为剩余库存平方。对内部库存节点求导得到三对角线性系统；用Thomas算法前向消元、逆向回代得到最优库存路径，输出每期应成交量。

$$\min_{x_0=Q,x_N=0}\sum_{k=1}^N \eta(x_k-x_{k-1})^2+\lambda\sigma^2 x_k^2$$

推导、最优性条件与数值结构

$$-\eta x_{k-1}+(2\eta+\lambda\sigma^2)x_k-\eta x_{k+1}=0,\quad 1\le k<N$$

对内部库存节点的二次目标求导，前一期与后一期成交量同时依赖当前库存，产生三对角方程。首行右端为ηQ，尾端库存固定为零。风险惩罚增大时，最优路径倾向提前完成更多成交。

完整计算案例

总量100、4个等长时段、冲击参数1、库存风险惩罚0，目标最小化四期成交量平方和，最优成交量各25。

$$\mathrm{Output}\approx\left(25,\ 25,\ 25,\ 25\right)$$

输出顺序：按时间顺序排列的各期成交数量。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

2．成交量上限约束的最早可行执行计划

模型结构与数学定义

给定未来各时间窗的成交量预测和最大参与率，将剩余父订单依次与各窗允许的最大数量比较。该规则在仅有逐窗上限约束时尽可能提前完成订单；输出各窗成交量和最终未成交量。

$$q_t=\min\{Q-\sum_{s<t}q_s,\ \rho V_t\}$$

推导、最优性条件与数值结构

$$R_0=Q,\quad R_t=R_{t-1}-q_t,\quad q_t\le \rho V_t$$

每期在剩余数量与当期容量之间取较小值，保持成交非负并不超过容量约束。递推的剩余量与累计成交之和恒等于初始订单总量。

完整计算案例

市场量100、200、100，最高参与率0.2，父订单50，依次成交20、30、0，未成交0。

$$\mathrm{Output}\approx\left(20,\ 30,\ 0,\ 0\right)$$

输出顺序：各期成交数量及最后未成交数量。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

3．价格时间优先队列的部分成交回放

模型结构与数学定义

在每个事件窗口，首先假设位于本订单之前的撤单量减少排队数量，再由对手方主动成交消耗前方队列，只有剩余主动量到达本订单时才形成部分成交。追踪累计成交与剩余订单量，输出最终成交、未成交及前方剩余队列。

$$A_{t+1}=(A_t-C_t-M_t)_+,\quad F_t=\min\{R_t,(M_t-(A_t-C_t)_+)_+\}$$

推导、最优性条件与数值结构

$$A'_t=A_t-C_t,\quad M_t^A=\min(A'_t,M_t),\quad R_{t+1}=R_t-F_t$$

在假设撤单全部确实位于前方的前提下，先以主动成交消耗前方队列，再将未被前方队列吸收的主动量分配给自身订单，因而不会把前方排队成交误判为自身成交。

完整计算案例

初始前方排队10，本订单5。第一窗口前方撤单2、主动成交5，前方剩3；第二窗口主动成交6，前方消耗3，自己的订单成交3，未成交2。

$$\mathrm{Output}\approx\left(3,\ 2,\ 0\right)$$

输出顺序：累计成交量、剩余订单量、前方剩余队列。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

4．多交易场所含费用的最优静态扫单

模型结构与数学定义

对于可拆分的买单，各场所和价位的有效单位成本为卖价加单位费用。按有效成本排序，依次使用最低成本可用深度，直到满足订单或深度耗尽。返回总花费、已成交量、未成交量和每一原始记录分配量。

$$\min_{0\le q_i\le a_i,\ \sum q_i=Q}\sum_i q_i(P_i+f_i)$$

推导、最优性条件与数值结构

$$c_i=P_i+f_i,\quad c_i<c_j,\ q_i<a_i,\ q_j>0\ \Rightarrow\ \text{成本仍可下降}$$

若高成本场所已经成交而低成本场所仍有可用深度，将一小部分成交从前者交换至后者必能降低成本。因此连续可分割的线性目标可以用按成本排序的贪心算法求解。

完整计算案例

两个场所卖价10、11，深度2、4，单位费用0，订单5，先用第一场所2，再用第二场所3，总花费53。

$$\mathrm{Output}\approx\left(53,\ 5,\ 0,\ 2,\ 3\right)$$

输出顺序：总成本、已成交量、未成交量、各输入行的成交分配量。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

5．指数冲击衰减的对数线性估计

模型结构与数学定义

假设冲击的正幅度沿时间指数衰减。把冲击幅度取对数，回归于事件后时间，斜率取负得到衰减速度，截距指数化恢复初始幅度，再由半衰期公式衡量冲击持续性。

$$\log I_t=a-\kappa t+\epsilon_t,\quad h_{1/2}=\log 2/\kappa$$

推导、最优性条件与数值结构

$$\widehat b=\frac{\sum_i(t_i-\bar t)(\log I_i-\overline{\log I})}{\sum_i(t_i-\bar t)^2},\quad \widehat\kappa=-\widehat b$$

指数衰减通过取对数变为线性模型，估计斜率即负衰减率。令预测冲击降至初始冲击的一半，可解出半衰期为log2除以衰减速度。

完整计算案例

时间0、1、2对应冲击4、2、1，拟合初始幅度4、衰减速度log2、半衰期1。

$$\mathrm{Output}\approx\left(4,\ 0.693147181,\ 1\right)$$

输出顺序：初始冲击估计、衰减速度、半衰期。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

#pragma once
#include "lab24_common.hpp"
#include <map>

namespace kline { namespace lab24 {
inline Vec ac_schedule(const Mat& x,const Vec& p){
    inputs(x,p,1,3);require(x.size()==1,"One parent order required");double Q=positive(x[0][0]),eta=positive(p[1]),risk=p[2];require(risk>=0,"Negative risk penalty");auto n=integer(p[0],1,10000);
    if(n==1)return {Q};
    Vec d(n-1,2*eta+risk),rhs(n-1,0),u(n-2,-eta),inv(n+1,0);rhs[0]=eta*Q;inv[0]=Q;
    for(std::size_t i=1;i<d.size();++i){double k=-eta/positive(d[i-1]);d[i]-=k*u[i-1];rhs[i]-=k*rhs[i-1];}
    for(std::size_t i=d.size();i-->0;){double z=rhs[i]-(i+1<d.size()?u[i]*inv[i+2]:0);inv[i+1]=z/positive(d[i]);}
    Vec trades;for(std::size_t i=1;i<=n;++i)trades.push_back(inv[i-1]-inv[i]);return checked(trades);
}

inline Vec participation_schedule(const Mat& x,const Vec& p){
    inputs(x,p,1,2);double left=p[0],rate=p[1];require(left>=0&&rate>=0&&rate<=1,"Invalid order or cap");Vec q;
    for(const auto& r:x){require(r[0]>=0,"Negative market volume");double fill=std::min(left,rate*r[0]);q.push_back(fill);left-=fill;}
    q.push_back(left);return checked(q);
}

inline Vec queue_fifo(const Mat& x,const Vec& p){
    inputs(x,p,2,2);double ahead=p[0],remaining=p[1],total=0;require(ahead>=0&&remaining>=0,"Negative initial queue");
    for(const auto& r:x){require(r[0]>=0&&r[1]>=0&&r[0]<=ahead+1e-10,"Invalid queue event");ahead=std::max(0.0,ahead-r[0]);double before=std::min(ahead,r[1]);ahead-=before;double f=std::min(remaining,r[1]-before);remaining-=f;total+=f;}
    return checked({total,remaining,ahead});
}

inline Vec multi_venue_sweep(const Mat& x,const Vec& p){
    inputs(x,p,3,1);double left=p[0],cost=0;require(left>=0,"Negative order");std::vector<std::size_t> ix(x.size());std::iota(ix.begin(),ix.end(),0);
    for(const auto& r:x){positive(r[0]);require(r[1]>=0&&r[0]+r[2]>0,"Invalid venue quote");}
    std::stable_sort(ix.begin(),ix.end(),[&](std::size_t a,std::size_t b){return x[a][0]+x[a][2]<x[b][0]+x[b][2];});
    Vec q(x.size(),0);for(auto i:ix){q[i]=std::min(left,x[i][1]);left-=q[i];cost+=q[i]*(x[i][0]+x[i][2]);}
    Vec out={cost,p[0]-left,left};out.insert(out.end(),q.begin(),q.end());return checked(out);
}

inline Vec impact_decay_fit(const Mat& x,const Vec& p){
    inputs(x,p,2,0,3);Vec t=col(x,0),y;for(std::size_t i=0;i<x.size();++i){require(t[i]>=0&&(i==0||t[i]>t[i-1]),"Invalid elapsed time");y.push_back(std::log(positive(x[i][1])));}
    double b=covariance(t,y,false)/positive(variance(t,false)),a=mean(y)-b*mean(t),k=positive(-b);
    return checked({std::exp(a),k,std::log(2.0)/k});
}
} }

namespace kline { namespace lab24 {
using Vec=std::vector<double>;
using Mat=std::vector<Vec>;

inline void inputs(const Mat& x,const Vec& p,std::size_t cols,std::size_t params,
                   std::size_t min_rows=1) {
    require(x.size()>=min_rows&&x.size()<=250000,"Invalid number of observations");
    require(p.size()==params,"Incorrect scalar parameter count");
    for(double v:p)require(std::isfinite(v),"Nonfinite scalar parameter");
    for(const auto& row:x){
        require(row.size()==cols,"Unexpected CSV column count");
        for(double v:row)require(std::isfinite(v),"Nonfinite matrix entry");
    }
}
inline std::size_t integer(double x,std::size_t low,std::size_t high){
    require(std::isfinite(x)&&x>=double(low)&&x<=double(high)&&std::floor(x)==x,
            "Integer parameter outside allowed range");
    return std::size_t(x);
}
inline double dot(const Vec& a,const Vec& b){
    require(a.size()==b.size(),"Dot product dimension mismatch");
    return std::inner_product(a.begin(),a.end(),b.begin(),0.0);
}
inline Vec col(const Mat& x,std::size_t j){
    Vec out;out.reserve(x.size());
    for(const auto& row:x)out.push_back(row.at(j));
    return out;
}
inline double positive(double x){require(x>0&&std::isfinite(x),"Positive finite quantity required");return x;}
inline Vec checked(Vec v){check_finite(v);return v;}
inline double logistic(double x){
    if(x>=0)return 1/(1+std::exp(-x));
    double e=std::exp(x);return e/(1+e);
}
inline double normal_cdf(double x){return 0.5*std::erfc(-x/std::sqrt(2.0));}
inline double sum(const Vec& v){return std::accumulate(v.begin(),v.end(),0.0);}
} }
