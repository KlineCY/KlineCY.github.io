盘口流动性、价格冲击斜率与订单流持续性

报价、成交与挂单恢复各自代表不同的市场流动性机制。将相对报价价差、流动性补充、成交引致的价格变动和订单流方向依赖放在同一研究框架，有助于区分交易成本与订单簿动态。

每个模型均对应可执行的标准C++17实现、明确单位与前提、解析计算案例，以及真实CSV或参数输入工作流。

1．相对报价价差（基点）

数学对象与估计量

$$S_{\mathrm{bps}}=\frac1n\sum_t10^4\frac{A_t-B_t}{(A_t+B_t)/2}$$

统计结构与推导

将最优卖价减去最优买价，除以当时中间价得到无量纲相对价差，再乘以10000换算为基点。相比以货币单位直接表示的绝对价差，它便于比较不同价格水平的资产。

数值计算与经济解释

在每条记录中卖一价为101、买一价为99，价差为2，中间价为100，对应价差为200基点。多个记录取平均得到时点等权的市场报价价差。

识别条件、数据口径与边界

快照时点等权不同于成交量加权或持续时间加权；本函数拒绝交叉与锁定报价，不将这些无效市场状态计入正常价差均值。

CSV或参数复算

./kline_quant quoted-spread quotes.csv Bid Ask

2．成交后流动性补充比率

数学对象与估计量

$$R_{\mathrm{replenish}}=\frac{\sum_tV^{\mathrm{posted}}_t}{\sum_tV^{\mathrm{executed}}_t}$$

统计结构与推导

订单簿遭受成交消耗后，新挂入的流动性决定深度恢复。把同一观察窗口内新增挂单数量与被成交消耗的数量相除，可得到简单的流动性补充强度诊断。

数值计算与经济解释

某一窗口两次消耗量分别为1和3，同时对应新增挂单量为2和2，则补充比率为4／4，即1。这一比率等于1并不表示订单簿的价格层级和队列位置完全恢复。

识别条件、数据口径与边界

撤单、价格档位迁移及隐藏成交可能使新增挂单与真实可执行深度不同。输入必须以相同股数或合约数计量，且总成交消耗量为正。

CSV或参数复算

./kline_quant replenishment quotes.csv Executed Replenished

3．Kyle线性价格冲击斜率

数学对象与估计量

$$\widehat\lambda=\frac{\sum_t(Q_t-\bar Q)(\Delta P_t-\overline{\Delta P})}{\sum_t(Q_t-\bar Q)^2}$$

统计结构与推导

把带符号成交量作为解释变量，对同时段价格变化做单变量OLS回归。斜率量化平均每单位订单流不平衡对应的价格变动，是衡量交易信息含量和冲击的一个研究代理指标。

数值计算与经济解释

若三个窗口的带符号交易量为1、2、3，价格变动为3、5、7，则线性关系的斜率为2，截距为1。输出斜率的单位取决于价格币种及交易量单位。

识别条件、数据口径与边界

斜率是回归关联指标，订单流和价格具有内生反馈；采样时间窗口、共同信息到达和买卖方向识别都会影响研究解释。

CSV或参数复算

./kline_quant kyle-lambda trades.csv SignedVolume PriceChange

4．订单方向一阶依赖

数学对象与估计量

$$\widehat\rho_1=\frac{\widehat{\operatorname{Cov}}(\epsilon_t,\epsilon_{t-1})}{\widehat{\sigma}(\epsilon_t)\widehat{\sigma}(\epsilon_{t-1})}$$

统计结构与推导

将主动买卖方向分别编码为正一与负一，通过相邻交易方向样本的相关系数，描述订单拆分或持续性买卖压力产生的方向延续。分母使用两段滞后样本各自的方差。

数值计算与经济解释

买卖方向交替且持续的序列会产生接近负一的一阶相关，说明成交方向经常反转；同向连续区段较多的序列则可能呈正相关。该值始终在相关系数的定义范围内。

识别条件、数据口径与边界

只有真实方向标签可用时，结果才具有主动成交含义。使用报价规则推断的方向标签可能含系统误差；全部为同一方向时相关系数无定义。

CSV或参数复算

./kline_quant sign-autocorr trades.csv Sign

#pragma once
#include "stats.hpp"
#include <algorithm>
#include <cmath>
#include <vector>
namespace kline {
inline double quoted_spread_basis_points(
 const std::vector<double>& bid,const std::vector<double>& ask){
 check_finite(bid);check_finite(ask);
 require(bid.size()==ask.size(),"Quote sides do not align");
 double total=0;
 for(std::size_t i=0;i<bid.size();++i){
  require(bid[i]>0&&ask[i]>bid[i],"Valid non-crossed quotes required");
  total+=20000.0*(ask[i]-bid[i])/(ask[i]+bid[i]);
 }
 return total/bid.size();
}
inline double liquidity_replenishment_ratio(
 const std::vector<double>& executed,const std::vector<double>& replenished){
 check_finite(executed);check_finite(replenished);
 require(executed.size()==replenished.size(),"Liquidity flow rows differ");
 double out=0,in=0;
 for(std::size_t i=0;i<executed.size();++i){
  require(executed[i]>=0&&replenished[i]>=0,
          "Signed trades are invalid for total replenishment");
  out+=executed[i];in+=replenished[i];
 }
 require(out>0,"Replenishment requires executed volume");
 return in/out;
}
inline double kyle_price_impact_slope(
 const std::vector<double>& signedVolume,const std::vector<double>& priceChange){
 check_finite(signedVolume);check_finite(priceChange);
 require(signedVolume.size()==priceChange.size()&&signedVolume.size()>=3,
         "Kyle regression needs at least three aligned observations");
 const double mu=mean(signedVolume),mv=mean(priceChange);
 double numerator=0,denominator=0;
 for(std::size_t i=0;i<signedVolume.size();++i){
   numerator+=(signedVolume[i]-mu)*(priceChange[i]-mv);
   denominator+=(signedVolume[i]-mu)*(signedVolume[i]-mu);
 }
 require(denominator>0,"Kyle impact requires variation in signed volume");
 return numerator/denominator;
}
inline double lag_one_order_sign_correlation(const std::vector<double>& signs){
 check_finite(signs);require(signs.size()>=3,"Order signs require three trades");
 for(double s:signs)require(s==-1||s==1,"Trade signs must be -1 or +1");
 const std::vector<double> a(signs.begin()+1,signs.end());
 const std::vector<double> b(signs.begin(),signs.end()-1);
 const double varA=variance(a,false),varB=variance(b,false);
 require(varA>0&&varB>0,"Both lagged signs require variation");
 return covariance(a,b,false)/std::sqrt(varA*varB);
}
}
