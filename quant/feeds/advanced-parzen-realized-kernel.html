Parzen实现核：高频噪声、自协方差和非负估计

高级研究方法　完整模型源码　公共数值函数

模型定义与识别条件

高频成交价格包含买卖价跳动、报价离散化及其他微观结构噪声，简单平方收益和可能偏离潜在连续价格的变差。实现核通过加权收益自协方差修正平方和。Parzen核具有平滑紧支撑，适合展示不同带宽如何改变噪声调整。

数学推导与求解机制

采用未中心化的有限样本自协方差和，而非统计软件常见的除以n估计。带宽H对应核权重h/(H+1)，因此第H阶仍有正权重。直接求和并输出RV、RK及调整量；不人为将负值截为零，负值标志帮助发现数值或口径问题。

$$\gamma_h=\sum_{t=h+1}^n r_tr_{t-h},\quad\gamma_0=\sum_t r_t^2$$
$$k_P(z)=\begin{cases}1-6z^2+6z^3&0\le z\le1/2\\2(1-z)^3&1/2<z\le1\\0&z>1\end{cases}$$
$$RK_H=\gamma_0+2\sum_{h=1}^H k_P(h/(H+1))\gamma_h$$
$$\widehat{\mathrm{Adjustment}}=RK_H-\gamma_0$$

独立解析基准

四条交替收益±0.01，RV=0.0004，γ1=−0.0003，H=1时Parzen权重k(0.5)=0.25，调整为−0.00015，RK=0.00025。该基准验证权重及自协方差索引。

计算复杂度与研究边界

计算O(nH)，输入为同一交易日按时间顺序排列的对数收益，不自动处理不规则采样、隔夜、端点抖动或异步多资产。实证实现核的渐近性质依赖带宽与端点处理；此处是明确的有限样本核估计器。

C++17完整实现

inline Report parzen_realized_kernel(const Mat& x,const Vec& p){
    validate(x,2,1,1);parameters(p,1);auto H=count(p[0],0,x.size()-1);require(double(H+1)*x.size()<=5e7,"Realized kernel work limit");
    double rv=0,adj=0;for(auto&r:x)rv+=r[0]*r[0];
    for(std::size_t h=1;h<=H;++h){double z=double(h)/(H+1),w=z<=.5?1-6*z*z+6*z*z*z:2*std::pow(1-z,3),g=0;for(std::size_t t=h;t<x.size();++t)g+=x[t][0]*x[t-h][0];adj+=2*w*g;}
    double rk=rv+adj;return scalar({"Bandwidth","RealizedVariance","RealizedKernel","AutocovarianceAdjustment","NegativeFlag"},{double(H),rv,rk,adj,double(rk<0)});
}
