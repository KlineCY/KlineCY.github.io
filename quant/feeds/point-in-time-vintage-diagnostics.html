1．两期数据版本的修订RMSE

数学对象与估计量

$$\mathrm{RMSE}_{vintage}=\sqrt{\frac1n\sum_{i=1}^{n}(X_i^{revised}-X_i^{initial})^2}$$

统计结构与推导

为同一个历史观测期保留初次发布值及后续修订值，逐条计算版本差的平方并平均开根号，可以刻画经济指标在不同发布版本之间的修订幅度。

数值计算与经济解释

原始数值为1、2，修订后为2、2时，版本变化分别为1和0，因此修订均方根误差为√0.5，约0.7071。结果单位与指标本身保持一致。

识别条件、数据口径与边界

两个版本必须严格匹配同一观测期及数据定义。修订RMSE不直接识别事前预测误差，因为后期真实值的生成和统计定义变化会影响修订数据的含义。

CSV或参数复算

./kline_quant vintage-rmse macro.csv Initial Revised

2．观测期至公开发布的平均时滞

数学对象与估计量

$$\bar\ell=\frac1n\sum_i(t_i^{release}-t_i^{reference})$$

统计结构与推导

经济数据所属月份与首次可得日期之间通常存在时间距离。把这两个时点统一转换为相同单位的可比较时间轴，得到平均发布时间滞后，可为As-of历史合并提供初步诊断。

数值计算与经济解释

若两个指标观测的参考时间分别为1和3，发布时间分别为2和5，则时滞为1和2，平均时滞为1.5个时间单位。

识别条件、数据口径与边界

时间单位应保持一致，并依据真实交易日历与时区定义；仅记录平均滞后不足以替代每条数据的真实公开时间，代码拒绝发生在观测时间之前的发布日期。

CSV或参数复算

./kline_quant publish-delay macro.csv Reference Released

3．盘口快照的陈旧报价比例

数学对象与估计量

$$\widehat p_{\mathrm{stale}}=\frac1{n-1}\sum_{i=2}^{n}\mathbf1\{t_i-t_{i-1}>g\}$$

统计结构与推导

按严格递增的报价时间戳计算相邻快照间距，超过事先指定阈值的时间段被标记为陈旧间隔。该指标以时间戳间隔的个数为分母，反映采样与行情更新中的数据空窗。

数值计算与经济解释

若报价时间依次为0、1、4、5，阈值为1.5，那么三个间隔中仅中间的间隔3超阈值，陈旧间隔比例为三分之一。

识别条件、数据口径与边界

该定义不是按自然时间长度计算的陈旧时间占比。不同交易时段和消息频率需要不同阈值，交易所停牌和非交易时间应单独识别。

CSV或参数复算

./kline_quant quote-stale quotes.csv Timestamp 1.5

4．无效、锁定与交叉盘口频率

数学对象与估计量

$$\widehat p_{\mathrm{invalid}}=\frac1n\sum_i\mathbf1\{B_i\le0\;\lor\;A_i\le0\;\lor\;B_i\ge A_i\}$$

统计结构与推导

最优买价不低于最优卖价时，报价处于锁定或交叉状态；非正价格在正常证券报价数据中同样标记为无效。将这些异常快照占全部快照的比例报告，有利于评估行情源在数据清洗前的质量。

数值计算与经济解释

三个报价中，第一条为买1卖2，第二条为买2卖1，第三条为买5卖5。后二条为交叉与锁定，异常频率为2／3。

识别条件、数据口径与边界

交易场所之间的合法交叉报价、集合竞价和不同市场币种单位可能具有特殊制度含义。统计应保留原始记录，并由市场规则决定清洗与研究口径。

CSV或参数复算

./kline_quant crossed-quotes quotes.csv Bid Ask

#pragma once
#include "stats.hpp"
#include <algorithm>
#include <cmath>
#include <vector>
namespace kline {
inline double vintage_revision_rmse(
 const std::vector<double>& initialVintage,const std::vector<double>& revised){
 check_finite(initialVintage);check_finite(revised);
 require(initialVintage.size()==revised.size(),"Revision vintage rows do not align");
 double squared=0;
 for(std::size_t i=0;i<initialVintage.size();++i)
  squared+=std::pow(revised[i]-initialVintage[i],2);
 return std::sqrt(squared/initialVintage.size());
}
inline double average_publication_delay(
 const std::vector<double>& referenceTime,const std::vector<double>& releasedTime){
 check_finite(referenceTime);check_finite(releasedTime);
 require(referenceTime.size()==releasedTime.size(),"Release events misaligned");
 double lag=0;
 for(std::size_t i=0;i<referenceTime.size();++i){
  require(releasedTime[i]>=referenceTime[i],"Release cannot predate reference time");
  lag+=releasedTime[i]-referenceTime[i];
 }
 return lag/referenceTime.size();
}
inline double stale_quote_fraction(
 const std::vector<double>& quoteTimestamps,double allowedGap){
 check_finite(quoteTimestamps);
 require(quoteTimestamps.size()>=2&&std::isfinite(allowedGap)&&allowedGap>=0,
         "Stale quote requires ordered timestamp gaps");
 int stale=0;
 for(std::size_t i=1;i<quoteTimestamps.size();++i){
  require(quoteTimestamps[i]>quoteTimestamps[i-1],
          "Quote timestamps must be strictly increasing");
  stale+=quoteTimestamps[i]-quoteTimestamps[i-1]>allowedGap;
 }
 return double(stale)/(quoteTimestamps.size()-1);
}
inline double invalid_bid_ask_fraction(
 const std::vector<double>& bids,const std::vector<double>& asks){
 check_finite(bids);check_finite(asks);
 require(bids.size()==asks.size(),"Bid ask events misaligned");
 int invalid=0;
 for(std::size_t i=0;i<bids.size();++i)
   invalid+=(bids[i]<=0||asks[i]<=0||bids[i]>=asks[i]);
 return double(invalid)/bids.size();
}
