成交后多期限Markout

买后中价上涨及卖后中价下降均为正Markout。区分单位价格变化与数量乘价格的货币变化，尚未扣费。

$$M_{i,h}=s_i(m_{i,h}-P_i),\quad s_i\in\{-1,1\}$$
$$\bar M_h=\sum_iq_iM_{i,h}/\sum_iq_i$$

买2单位、卖1单位，首期限总Markout4，第二期限−3。未来中价须和真实成交时间对齐，不能用不规则行号代替时间。

参与率上限与剩余订单

每期成交不超过剩余订单和固定比例市场量，形成守恒账本。零量时不成交，给定实现量的情景计算并非事前预测。

$$q_t=\min(Q_{t-1},\eta V_t),\quad Q_t=Q_{t-1}-q_t$$
$$\sum_{u\le t}q_u+Q_t=Q_0$$

目标30、参与率10％，市场量100、50、200，成交10、5、15。真实执行仍受价格、队列、撤单与冲击约束。

冲击后价差恢复比例

以冲击前正常价差为基准，异常价差缩减比例即恢复程度，可超1或为负。首次越过一半是观测网格上的首次触及。

$$R(t)=1-\frac{s(t)-s_*}{s(0)-s_*}$$
$$\tau_{1/2}=\inf\{t:R(t)\ge1/2\}$$

正常价差1，冲击后4、3、2、1，半恢复在时点2。多个冲击叠加及基准变化时，应按事件对齐分层比较。

做市成交费用净Markout

成交后中价相对成交价的有利变化为毛Markout。费用可为负表示返佣，按量计算后从毛值扣除。方向为该交易者自身买卖方向。

$$G_i=q_is_i(m_{i,h}-P_i),\quad F_i=q_if_i$$
$$N_i=G_i-F_i$$

买2单位毛收益2、返佣0.2，净2.2；卖1单位后价格上涨，净−1.2。不包含后续库存和资金风险。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace applied_execution {
using namespace evidence;
inline Report markout(const Mat& x,const Vec& p){
    auto n=validate(x,1,4,64);
    parameters(p,0);
    double q=0;
    for(auto&r:x){require(r[0]==1||r[0]==-1,"Invalid side");
    positive(r[1]);
    q+=positive(r[2]);
    for(std::size_t j=3;
    j<n;
    ++j)positive(r[j]);
    }Report o{{"Horizon","SignedMarkout","QuantityWeightedMarkout"},{}};
    for(std::size_t j=3;
    j<n;
    ++j){double v=0;
    for(auto&r:x)v+=r[0]*r[2]*(r[j]-r[1]);
    o.rows.push_back({double(j-2),v,v/q});
    }return o;
    
}

inline Report participation_cap(const Mat& x,const Vec& p){
    validate(x,1,1,1);
    parameters(p,2);
    double rem=positive(p[0]),eta=p[1];
    require(eta>=0&&eta<=1,"Invalid participation");
    Report o{{"Period","MarketVolume","Fill","Remaining","Participation"},{}};
    for(std::size_t i=0;
    i<x.size();
    ++i){double v=x[i][0];
    require(v>=0,"Negative volume");
    double q=std::min(rem,eta*v);
    rem-=q;
    o.rows.push_back({double(i+1),v,q,rem,v==0?0:q/v});
    }return o;
    
}

inline Report recovery(const Mat& x,const Vec& p){
    validate(x,1,2,2);
    parameters(p,1);
    double b=p[0],d=positive(x[0][1]-b);
    require(b>=0,"Negative reference spread");
    Report o{{"Time","Spread","Recovery","HalfRecovered"},{}};
    for(std::size_t i=0;
    i<x.size();
    ++i){auto&r=x[i];
    require(r[0]>=0&&r[1]>=0&&(i==0||r[0]>x[i-1][0]),"Invalid time or spread");
    double z=1-(r[1]-b)/d;
    o.rows.push_back({r[0],r[1],z,double(z>=.5)});
    }return o;
    
}

inline Report maker_taker(const Mat& x,const Vec& p){
    validate(x,1,5,5);
    parameters(p,0);
    Report o{{"Trade","GrossMarkout","Fee","NetMarkout"},{}};
    for(std::size_t i=0;
    i<x.size();
    ++i){auto&r=x[i];
    require(r[0]==1||r[0]==-1,"Invalid side");
    positive(r[1]);
    positive(r[2]);
    positive(r[3]);
    double g=r[0]*(r[2]-r[1])*r[3],f=r[3]*r[4];
    o.rows.push_back({double(i+1),g,f,g-f});
    }return o;
    
}
