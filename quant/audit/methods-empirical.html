事件窗口市场模型异常收益累计

模型与推导

先用事件前独立估计窗口拟合市场模型，在事件窗口固定参数构造反事实期望收益，再累计异常收益。代码只执行给定参数的事件窗口计算，不重新拟合。

$$AR_{it}=r_{it}-(\hat\alpha_i+\hat\beta_i r_{mt})$$
$$CAR_i[a,b]=\sum_{t=a}^bAR_{it}$$

研究应用与成立条件

示例α＝0.001、β＝1.2，三日异常收益−0.003、0.025、−0.011，累计0.011。事件时钟与公告可用时间一致；事件重叠会影响统计推断。

配对实验的精确随机化检验

模型与推导

在每对独立随机分配处理且尖锐零假设成立时，交换处理标签等价于改变差值符号。遍历全部2^n分配获得有限样本精确p值，无需正态假设。

$$T(z)=n^{-1}\sum_i z_i d_i,\quad z_i\in\{-1,1\}$$
$$p=2^{-n}\sum_z\mathbf1\{|T(z)|\ge|T(\mathbf1)|\}$$

研究应用与成立条件

三对差值3、2、1，均值2，只有全正与全负两种达到同样绝对统计量，双侧p为0.25。观察性匹配不自动获得随机化有效性；程序限制对数以控制指数复杂度。

逆概率权重的协变量平衡诊断

模型与推导

ATE逆概率加权以处理概率的倒数重新构造两组可比总体，归一化组内权重后比较协变量均值。平衡只是可观测诊断，不能证明无未观测混杂。

$$w_i^1=D_i/e_i,\quad w_i^0=(1-D_i)/(1-e_i)$$
$$\Delta_w=\frac{\sum_iw_i^1X_i}{\sum_iw_i^1}-\frac{\sum_iw_i^0X_i}{\sum_iw_i^0}$$

研究应用与成立条件

倾向得分均0.5时组内权重一致，处理协变量均值4，对照2，差异2未改善。极端倾向得分会提高方差，截尾改变估计对象。

安慰剂分布的有限样本秩概率

模型与推导

将第一行视为观测统计量，其余为同一设计产生的安慰剂，按绝对值比较并加入观测本身。平局保守计入，避免报告零p。交换性来自抽样或随机化设计，不由计算公式自动保证。

$$p=(1+\sum_{j=1}^B\mathbf1\{|T_j|\ge|T_{\mathrm{obs}}|\})/(B+1)$$
$$\Pr(p\le\alpha)\le\alpha\quad\text{under exchangeable ranks}$$

研究应用与成立条件

观测3、四个安慰剂1、−2、4、−1，只有4超过，秩概率2／5。适用于合成控制等置换诊断；非可交换的预趋势、规模和误差需要设计处理。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace methods_empirical {
using namespace evidence;
inline Report event_car(const Mat& x,const Vec& p){
    validate(x,1,3,3);
    parameters(p,2);
    double s=0;
    Report o{{"RelativeDay","ExpectedReturn","AbnormalReturn","CAR"},{}};
    for(std::size_t i=0;
    i<x.size();
    ++i){auto&r=x[i];
    require(i==0||r[0]>x[i-1][0],"Increasing event time required");
    double a=p[0]+p[1]*r[2],e=r[1]-a;
    s+=e;
    o.rows.push_back({r[0],a,e,s});
    }return o;
    
}

inline Report paired_randomization(const Mat& x,const Vec& p){
    validate(x,1,2,2);
    parameters(p,0);
    auto n=x.size();
    require(n<=20&&double(std::uint64_t(1)<<n)*n<=3e7,"Exact enumeration work limit");
    Vec d;
    double s=0,scale=0;
    for(auto&r:x){d.push_back(r[0]-r[1]);
    s+=d.back();
    scale+=std::abs(d.back());
    }auto M=std::uint64_t(1)<<n;
    double hit=0;
    for(std::uint64_t z=0;
    z<M;
    ++z){double t=0;
    for(std::size_t i=0;
    i<n;
    ++i)t+=(z&(std::uint64_t(1)<<i)?1:-1)*d[i];
    if(std::abs(t)+1e-12*scale>=std::abs(s))++hit;
    }return scalar({"Pairs","MeanDifference","TwoSidedP","Assignments"},{double(n),s/n,hit/M,double(M)});
    
}

inline Report ipw_balance(const Mat& x,const Vec& p){
    validate(x,2,3,3);
    parameters(p,0);
    double n1=0,n0=0,a=0,b=0,w1=0,w0=0,c=0,d=0;
    for(auto&r:x){require((r[0]==0||r[0]==1)&&r[1]>0&&r[1]<1,"Invalid treatment or propensity");
    if(r[0]){++n1;
    a+=r[2];
    w1+=1/r[1];
    c+=r[2]/r[1];
    }else{++n0;
    b+=r[2];
    w0+=1/(1-r[1]);
    d+=r[2]/(1-r[1]);
    }}positive(n1);
    positive(n0);
    return scalar({"TreatedMean","ControlMean","RawDifference","WeightedDifference"},{c/w1,d/w0,a/n1-b/n0,c/w1-d/w0});
    
}

inline Report placebo_rank(const Mat& x,const Vec& p){
    validate(x,2,1,1);
    parameters(p,0);
    double z=std::abs(x[0][0]),h=0;
    for(std::size_t i=1;
    i<x.size();
    ++i)if(std::abs(x[i][0])>=z)++h;
    return scalar({"ObservedAbs","Placebos","Exceedances","RankP"},{z,double(x.size()-1),h,(1+h)/x.size()});
    
}
