按标签区间进行净化与禁入期划分

数学定义与推导

使用半开标签区间明确边界：标签结束等于测试开始时不重叠；若标签跨越测试区间，即使起点在测试前，也须从训练候选删除。测试之后的禁入期另按开始时点标记。这里把整个测试时间窗作为净化区间，并非自动生成K折或滚动训练。

$$I_i=[s_i,e_i),\quad J=[a,b)$$
$$\operatorname{overlap}(I_i,J)=\mathbf1\{s_i<b,\ e_i>a\}$$
$$\operatorname{train}_i=\mathbf1\{I_i\cap J=\varnothing,\ s_i\notin[b,b+E)\}$$

数值演算与金融应用

测试窗[3,5)、禁入长度2。区间[1,3)可训练，[3,4)和[4,6)重叠而剔除，[6,7)位于禁入期，起点8可训练。真实部署若仅允许过去训练，则还须额外排除所有测试后的样本。

算法复杂度、输入契约与边界

O(n)，要求开始<结束、测试开始<结束、禁入期非负。金融标签包含实际结束时点，特征可用时点也需独立检查；本例不假定普通随机K折合法。

训练统计量冻结与样本外标准化

数学定义与推导

训练集确定中心和尺度，验证及测试只应用该转换。标准化使用总体型分母，与常见机器学习标准化器一致。若将未来样本并入均值或方差，训练表示本身会随测试信息变化，构成数据泄漏。

$$\mu_{\mathrm{tr}}=n_{\mathrm{tr}}^{-1}\sum_{i\in T}x_i$$
$$s_{\mathrm{tr}}^2=n_{\mathrm{tr}}^{-1}\sum_{i\in T}(x_i-\mu_{\mathrm{tr}})^2$$
$$z_i=(x_i-\mu_{\mathrm{tr}})/s_{\mathrm{tr}}\quad(i\in T\cup V)$$

数值演算与金融应用

训练值1、3，均值2、尺度1，样本外5及9标准化为3、7。极端测试值被如实保留，便于发现分布漂移，而不是将测试截面强行变成单位方差。

算法复杂度、输入契约与边界

O(n)两遍扫描，至少两条训练观察且训练方差正。标记只表示集合归属，时间顺序需由上游切分保证；交叉验证必须逐折单独估计。

固定可用基准的样本外决定系数

数学定义与推导

样本外决定系数与样本内拟合优度不同，比较模型和当时真实可用基准的预测平方误差。基准可以是滚动历史均值或其他预先固定的模型，不应使用测试期实际均值。负值表示样本外预测不及基准。

$$\mathrm{SSE}_m=\sum_t(y_t-\hat y_{t|t-1})^2$$
$$\mathrm{SSE}_b=\sum_t(y_t-b_{t|t-1})^2$$
$$R^2_{\mathrm{OOS}}=1-\mathrm{SSE}_m/\mathrm{SSE}_b$$

数值演算与金融应用

实际1、2，模型1、1，基准0、0，模型平方误差1，基准5，样本外R²为0.8。可用于收益率或波动预测，但经济收益还取决于信号映射、风险及成本。

算法复杂度、输入契约与边界

O(n)，两组预测必须共享完全相同目标、时间和样本。基准误差严格正，避免未定义比率。统计显著性需另用损失差检验及依赖调整。

模型损失差的分块贡献与不稳定性

数学定义与推导

整体平均损失改善可按互斥时间块分解，贡献使用样本量权重而非简单平均块均值。分块诊断能发现总体优势是否集中于单一时期；它是描述性归因，不自动构成独立块检验。

$$d_i=L_{b,i}-L_{m,i},\quad \bar d_g=n_g^{-1}\sum_{i\in g}d_i$$
$$\bar d=\sum_g (n_g/n)\bar d_g$$
$$C_g=(n_g/n)\bar d_g$$

数值演算与金融应用

第一块两条损失差均1，贡献2/3；第二块损失差−3，贡献−1，整体改善−1/3。即使多数时间块表现较好，也可能被大幅失效块抵销。适用于跨市场状态的样本外模型比较。

算法复杂度、输入契约与边界

O(n log G)，块ID整数、损失非负（如平方误差），至少一条。若损失可为负的评分，则需根据其定义扩展输入约束；分块规则必须预先固定。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace depth_validation {
using namespace evidence;
inline Report purge_interval(const Mat& x,const Vec& p){
    validate(x,1,2,2);parameters(p,3);require(p[0]<p[1]&&p[2]>=0,"Invalid test interval");Report o{{"Row","Start","End","TestOverlap","Embargo","TrainEligible"},{}};
    for(std::size_t i=0;i<x.size();++i){auto&r=x[i];require(r[0]<r[1],"Invalid label interval");bool a=r[0]<p[1]&&r[1]>p[0],b=r[0]>=p[1]&&r[0]<p[1]+p[2];o.rows.push_back({double(i+1),r[0],r[1],double(a),double(b),double(!a&&!b)});}return o;
}

inline Report train_only_standardization(const Mat& x,const Vec& p){
    validate(x,2,2,2);parameters(p,0);double n=0,m=0;
    for(auto&r:x){require(r[0]==0||r[0]==1,"Binary train flag required");if(r[0]){++n;m+=r[1];}}
    require(n>=2,"Two training values required");m/=n;double v=0;for(auto&r:x)if(r[0])v+=(r[1]-m)*(r[1]-m)/n;double s=std::sqrt(positive(v));
    Report o{{"Row","TrainFlag","Value","TrainingMean","TrainingScale","Standardized"},{}};
    for(std::size_t i=0;i<x.size();++i)o.rows.push_back({double(i+1),x[i][0],x[i][1],m,s,(x[i][1]-m)/s});return o;
}

inline Report forecast_oos_r2(const Mat& x,const Vec& p){
    validate(x,1,3,3);parameters(p,0);double a=0,b=0;
    for(auto&r:x){a+=(r[0]-r[1])*(r[0]-r[1]);b+=(r[0]-r[2])*(r[0]-r[2]);}double q=a/positive(b);return scalar({"ModelSSE","BenchmarkSSE","OOSR2","MSERatio"},{a,b,1-q,q});
}

inline Report block_loss_decomposition(const Mat& x,const Vec& p){
    validate(x,1,3,3);parameters(p,0);std::map<double,Vec> a;
    for(auto&r:x){require(r[0]==std::floor(r[0])&&r[1]>=0&&r[2]>=0,"Invalid block or loss");if(!a.count(r[0]))a[r[0]]=Vec(3,0);auto&v=a[r[0]];++v[0];v[1]+=r[1];v[2]+=r[2];}
    Report o{{"Block","Count","MeanModelLoss","MeanBenchmarkLoss","MeanImprovement","Contribution"},{}};
    for(auto&z:a){auto&v=z.second;double d=v[2]-v[1];o.rows.push_back({z.first,v[0],v[1]/v[0],v[2]/v[0],d/v[0],d/x.size()});}return o;
}
