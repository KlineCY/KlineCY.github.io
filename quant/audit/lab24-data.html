1．时间戳对齐的向后As-of连接与时效

模型结构与数学定义

当市场决策时点与数据发布时间不一致时，用有序发布时间数组的upper_bound查找不晚于决策时点的最后一条记录。若距发布时点的年龄超出允许上限，结果标为未匹配。输出每行匹配标志、数值、年龄三元组，未匹配用零占位并由标志识别。

$$j(t)=\max\{j:a_j\le t\},\quad \ell_t=t-a_{j(t)}$$

推导、最优性条件与数值结构

$$m_t=\mathbf1\{j(t)\text{ 存在},\ t-a_{j(t)}\le L\}$$

时间索引有序时，二分搜索可在对数时间内找到最后一个可得版本。时效条件不满足时使用明确的缺失标志，而不是以未来数据或无条件插值替代。

完整计算案例

$$\mathrm{Output}\approx\left(1,\ 10,\ 1,\ 1,\ 30,\ 0,\ 0,\ 0,\ 0\right)$$

2．标签区间相交的Purging与测试后Embargo

模型结构与数学定义

标签存在从特征时点到结果成熟时点的区间。训练候选若与测试信息区间发生交叉，就可能与测试目标共享未来价格；剔除交叉样本，再剔除测试结束后预设缓冲期内起始的训练候选。输出0/1训练可用标记。

$$I_i^{train}=\mathbf1\{[s_i,e_i]\cap[a,b]=\varnothing,\ s_i\notin(b,b+h]\}$$

推导、最优性条件与数值结构

$$[s_i,e_i]\cap[a,b]\ne\varnothing\iff s_i\le b\ \land\ e_i\ge a$$

两个闭区间相交当且仅当一个区间的起点不超过另一区间终点，反向条件也成立。先通过该判据剔除重叠，再对测试结束后的起始时点实施缓冲期限制。

3．重叠事件标签的平均唯一性权重

模型结构与数学定义

对离散时间标签区间，先利用差分数组计算每个时点同时活动的事件个数，再构建并发倒数的前缀和。每条事件唯一性等于其区间内并发倒数的均值。算法复杂度为O(n+T)，避免逐事件逐时点重复扫描。

$$c_t=\sum_i\mathbf1\{s_i\le t\le e_i\},\quad u_i=\frac1{e_i-s_i+1}\sum_{t=s_i}^{e_i}\frac1{c_t}$$

推导、最优性条件与数值结构

$$d_{s_i}\leftarrow d_{s_i}+1,\quad d_{e_i+1}\leftarrow d_{e_i+1}-1,\quad c_t=\sum_{s\le t}d_s$$

在事件起点增加并发、终点后一位减少并发。差分数组的累计和得到所有离散时点的活动标签数；再用并发倒数的前缀和以常数时间计算每个标签区间的平均权重。

完整计算案例

两个事件区间[0,1]和[1,2]，并发数为1、2、1，两事件平均唯一性都为0.75。

$$\mathrm{Output}\approx\left(0.75,\ 0.75\right)$$

输出顺序：各事件标签的平均唯一性权重。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

4．逐观测期的点时版本数据选择

模型结构与数学定义

同一个宏观观测期可能有多次初值或修订。按观测期分组，保留发布日期不晚于研究截点的最新版本；输出按照观测期排序的观测期、可得时间、数值三元组。此方法不将最终修订值提前带入历史研究。

$$v_j(t)=v_{j,k^*},\quad k^*=\arg\max_{k:a_{j,k}\le t} a_{j,k}$$

推导、最优性条件与数值结构

$$a_{j,k^*}\le t,\qquad a_{j,k}\le t\Rightarrow a_{j,k}\le a_{j,k^*}$$

对每一个观测期独立保留发布时间最近且不晚于研究时点的数值。这个最大化约束体现真实信息集，确保更晚修订值不会提前进入历史样本。

完整计算案例

观测期1在时点2发布10、时点4修订为12；观测期2在时点3发布20。研究截点3时应返回(1,2,10)和(2,3,20)。

$$\mathrm{Output}\approx\left(1,\ 2,\ 10,\ 2,\ 3,\ 20\right)$$

输出顺序：按观测期排序的参考期、发布日期和值三元组。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

5．交易事件的等成交量Bar聚合

模型结构与数学定义

按交易事件顺序累积成交量；单笔成交跨越Bar边界时，将该笔数量精确拆分到相邻Bar，价格保持一致。每个完成的Bar返回开盘、最高、最低、收盘、成交量与VWAP；最后未满额Bar单独按同样结构输出。

$$V_b=V^*,\quad VWAP_b=\frac{\sum_i p_i q_{ib}}{V_b}$$

推导、最优性条件与数值结构

$$\sum_b q_{ib}=q_i,\quad \sum_bV_b=\sum_iq_i,\quad \sum_bV_bVWAP_b=\sum_ip_iq_i$$

将跨Bar的原始成交数量拆成多个子数量，在每个子Bar上累计价格乘数量。所有子数量之和与原始事件一致，所以成交量和成交金额必须同时守恒；该恒等式是数据聚合的重要核对标准。

完整计算案例

成交价10、12、11，对应数量2、3、1，目标Bar量3。第一Bar数量2@10和1@12，VWAP=32/3；第二Bar数量2@12和1@11，VWAP=35/3。

$$\mathrm{Output}\approx\left(10,\ 12,\ 10,\ 12,\ 3,\ 10.6666667,\ 12,\ 12,\ 11,\ 11,\ 3,\ 11.6666667\right)$$

输出顺序：每个Bar依次为开盘价、最高价、最低价、收盘价、成交量与VWAP。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

#pragma once
#include "lab24_common.hpp"
#include <map>

namespace kline { namespace lab24 {
inline Vec asof_age(const Mat& x,const Vec& p){
    inputs(x,p,3,1);require(p[0]>=0,"Negative max age");Vec a=col(x,0),out;
    for(std::size_t i=1;i<a.size();++i)require(a[i]>a[i-1],"Available times must increase");
    for(const auto& r:x){auto it=std::upper_bound(a.begin(),a.end(),r[2]);if(it==a.begin()){out.insert(out.end(),{0,0,0});continue;}auto j=std::size_t(it-a.begin()-1);double age=r[2]-a[j];if(age>p[0])out.insert(out.end(),{0,0,0});else out.insert(out.end(),{1,x[j][1],age});}
    return checked(out);
}

inline Vec purged_mask(const Mat& x,const Vec& p){
    inputs(x,p,2,3);require(p[0]<=p[1]&&p[2]>=0,"Invalid test interval");Vec out;
    for(const auto& r:x){require(r[1]>=r[0],"Reversed label interval");bool overlap=r[0]<=p[1]&&r[1]>=p[0],embargo=r[0]>p[1]&&r[0]<=p[1]+p[2];out.push_back(overlap||embargo?0:1);}
    return out;
}

inline Vec label_uniqueness(const Mat& x,const Vec& p){
    inputs(x,p,2,0);std::size_t T=0;
    for(const auto& r:x){auto a=integer(r[0],0,1000000),b=integer(r[1],0,1000000);require(a<=b,"Reversed event interval");T=std::max(T,b);}
    Vec delta(T+2,0),prefix(T+2,0);
    for(const auto& r:x){++delta[std::size_t(r[0])];--delta[std::size_t(r[1])+1];}
    double c=0;for(std::size_t t=0;t<=T;++t){c+=delta[t];prefix[t+1]=prefix[t]+(c>0?1/c:0);}
    Vec out;for(const auto& r:x){auto a=std::size_t(r[0]),b=std::size_t(r[1]);out.push_back((prefix[b+1]-prefix[a])/double(b-a+1));}return checked(out);
}

inline Vec revision_latest(const Mat& x,const Vec& p){
    inputs(x,p,3,1);std::map<double,std::pair<double,double>> latest;
    for(const auto& r:x){require(r[1]>=r[0],"Publication precedes reference");if(r[1]>p[0])continue;auto it=latest.find(r[0]);if(it==latest.end()||r[1]>it->second.first)latest[r[0]]={r[1],r[2]};else if(r[1]==it->second.first)require(r[2]==it->second.second,"Conflicting vintage");}
    require(!latest.empty(),"No available vintage");Vec out;for(const auto& q:latest)out.insert(out.end(),{q.first,q.second.first,q.second.second});return checked(out);
}

inline Vec event_time_bars(const Mat& x,const Vec& p){
    inputs(x,p,2,1);double cap=positive(p[0]),v=0,turn=0,o=0,h=0,l=0,c=0;Vec out;
    auto emit=[&](){require(out.size()<600000,"Too many volume bars");out.insert(out.end(),{o,h,l,c,v,turn/v});v=0;turn=0;};
    for(const auto& r:x){positive(r[0]);require(r[1]>=0,"Negative trade quantity");double remain=r[1];
        while(remain>0){if(v==0){o=h=l=r[0];}h=std::max(h,r[0]);l=std::min(l,r[0]);c=r[0];double q=std::min(remain,cap-v);require(q>0&&remain-q<remain,"Volume resolution too small");v+=q;turn+=q*r[0];remain-=q;if(v>=cap*(1-1e-12))emit();}
    }
    if(v>0){emit();}
    require(!out.empty(),"No positive trade volume");
    return checked(out);
}

using Vec=std::vector<double>;
using Mat=std::vector<Vec>;

inline void inputs(const Mat& x,const Vec& p,std::size_t cols,std::size_t params,
                   std::size_t min_rows=1) {
    require(x.size()>=min_rows&&x.size()<=250000,"Invalid number of observations");
    require(p.size()==params,"Incorrect scalar parameter count");
    for(double v:p)require(std::isfinite(v),"Nonfinite scalar parameter");
    for(const auto& row:x){
        require(row.size()==cols,"Unexpected CSV column count");
        for(double v:row)require(std::isfinite(v),"Nonfinite matrix entry");
    }
}
inline std::size_t integer(double x,std::size_t low,std::size_t high){
    require(std::isfinite(x)&&x>=double(low)&&x<=double(high)&&std::floor(x)==x,
            "Integer parameter outside allowed range");
    return std::size_t(x);
}
inline double dot(const Vec& a,const Vec& b){
    require(a.size()==b.size(),"Dot product dimension mismatch");
    return std::inner_product(a.begin(),a.end(),b.begin(),0.0);
}
inline Vec col(const Mat& x,std::size_t j){
    Vec out;out.reserve(x.size());
    for(const auto& row:x)out.push_back(row.at(j));
    return out;
}
inline double positive(double x){require(x>0&&std::isfinite(x),"Positive finite quantity required");return x;}
inline Vec checked(Vec v){check_finite(v);return v;}
inline double logistic(double x){
    if(x>=0)return 1/(1+std::exp(-x));
    double e=std::exp(x);return e/(1+e);
}
inline double normal_cdf(double x){return 0.5*std::erfc(-x/std::sqrt(2.0));}
inline double sum(const Vec& v){return std::accumulate(v.begin(),v.end(),0.0);}
