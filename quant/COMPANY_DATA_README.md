# 量化公司数据库：数据口径与维护说明

更新日期：2026-10-30

## 收录目标与边界

目标是收录全球管理资产不低于所在地区当地货币 **100,000,000（1亿）** 的量化基金、系统化资产管理人及相关资管机构。但单靠公开资料不能构建全球穷尽名单；该文件是开放式、有来源的研究索引，**不是全部满足门槛的机构名单**。做市商、自营交易商等没有可比AUM的公司仅作为明确标记的参考公司，不能视为规模已达标。

机构收录按照独立管理人或投资机构实体去重，管理人集团与旗下登记实体有可能不是一个AUM口径，需进一步核验。新采集的中国机构仅有简称时，该简称不作为已核实的法定全称。

## 中文与英文金额格式

首选中文以“亿”表述资产规模，货币不做汇率换算；旁边显示全额原币数字并使用逗号分隔：

- `CNY 1,250,000,000` = 人民币 12.5 亿元。
- `USD 860,000,000` = 8.6 亿美元。
- 2026Q1估算 `50—100亿元` = `CNY 5,000,000,000 – 10,000,000,000`，不得代入75亿元作为估算中点。
- 英文原币金额是货币代码和整数金额，而非 `million`/`billion`，页面不再展示“十亿”。

JSON 旧格式 `scale.amount_billion` 仅作**存储字段兼容**（乘10得到「亿」，乘1,000,000,000得到原币整数）；2026年新增的区间采用 `range_yi_min` 和 `range_yi_max`，单位均为原币「亿」。不要同时将区间表示为精确AUM。

## 证据等级

- `official`：公司官网披露，仍必须查明统计时间和是否为集团AUM。
- `regulatory-derived`：中基协规模区间或美国SEC等监管口径的间接转引。应优先复核官方原始登记页。
- `third-party-estimate`：行业研究/QIML/媒体转载的AUM规模区间，仅能作为估计区间，不是官方最新精确AUM。
- `third-party-directory`：商业名录披露数字，未逐家与监管机构/官网验证。公开列表可能为分支机构行；已在本目录按公司名称合并，同一集团仍需进一步核查。
- 无规模：未披露、不适用或不够证据，不能判断是否满足1亿门槛。

**不要将** `RAUM`（Form ADV Regulatory Assets Under Management）、交易资本、杠杆总敞口、交易额、净资产和非标准私募估值，默认为可比的集团AUM。

中国AMAC对部分管理人仅公开 `0—5亿元` 大区间，因此无法从该区间确认是否已超过1亿元，绝不可直接认定通过。

## 主要公开来源

1. [AMAC 机构/分类查询](https://www.amac.org.cn/fwdt/wyc/jgcprycx/)：中国私募基金管理人，可能仅公开规模区间。
2. [SEC Investment Adviser Public Disclosure](https://adviserinfo.sec.gov/)：美国投资顾问注册和Form ADV，可核查监管资产管理规模，口径与基金AUM不同。
3. [源达研究2026Q1量化私募规模梯队](https://finance.sina.com.cn/roll/2026-04-30/doc-inhwhkui1290646.shtml)：规模区间数据为第三方估计。
4. [东方财富研究中心2026Q3](https://emwap.eastmoney.com/a/202610093891374536.html)：部分中国量化管理人最新季度规模梯队。
5. [Hedge Fund Contacts Quant hedge funds](https://hedgefundcontacts.com/resources/quant-hedge-funds/)：2026-08-15商业样本，含中小机构；非监管核验。
6. [AMAC登记名录第三方索引](https://www.chinatrust.cn/seo/china/index.html)：公开区间及注册信息整理，需通过AMAC核验。

## 后续扩展原则

优先采集**1—5亿元、5—10亿元、10—20亿元、20—50亿元**的量化管理人，但必须具备区间下界≥1亿的证据，或精确数值≥1亿。未达到可核实门槛的机构单独维护候选清单，不宜为了追求“数量”而加入主数据集中的「已达标」统计。

每期更新记录 `as_of`（资产规模日期）、`source`（原文来源）、`quality`（核实级别）、`metric`（集团AUM/策略AUM/区间/非AUM）、以及 `scale_history`（旧数据）。不要以抓取时间替代规模披露时间。任何无法独立验证的字段应留空并明确标注待核验。
