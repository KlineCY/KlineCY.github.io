Logistic回归Hessian向量积

数学定义与推导

Logistic负对数似然的曲率由设计向量外积加权构成，因此为半正定。Hessian向量积先对每条样本算方向投影，再累加加权设计向量，不构造d×d矩阵，可用于Newton-CG和曲率检查。代码采用总和损失，未加正则或截距。

$$L(w)=\sum_i[\log(1+e^{x_i^\top w})-y_ix_i^\top w]$$
$$\nabla L=X^\top(p-y),\quad H=X^\top\operatorname{diag}(p_i(1-p_i))X$$
$$Hv=\sum_i p_i(1-p_i)x_i(x_i^\top v),\quad v^\top Hv\ge0$$

数值演算与金融应用

两个样本(1,0)和(0,2)，权重0、方向(1,1)，梯度(−0.5,1)，Hessian向量积(0.25,1)，方向曲率1.25。方向若在设计零空间，曲率为0，不能据此保证严格凸。

算法复杂度、输入契约与边界

O(nd)时间、O(d)附加空间。参数前d项为模型权重，后d项为方向；最后一列标签0/1。截距需作为设计列输入；样本权重与正则项需单独纳入。

Softmax Jacobian向量积与平移不变性

数学定义与推导

商法则给出Softmax Jacobian，写成diag(p)−ppᵀ。对任意方向v只需一次概率内积即可计算Jv；所有输出分量和为0，对统一logit平移的导数为零。该Jacobian也等于分类分布指标向量的协方差。

$$p_i=\frac{e^{z_i}}{\sum_j e^{z_j}}$$
$$J_{ij}=p_i(\delta_{ij}-p_j)$$
$$(Jv)_i=p_i(v_i-p^\top v),\quad J\mathbf1=0$$

数值演算与金融应用

两个logit均0，方向(1,−1)，输出概率(0.5,0.5)，Jv=(0.5,−0.5)。在神经网络分类头和策略网络中，方向导数可用于检查自动微分实现及概率归一化。

算法复杂度、输入契约与边界

O(K)时间，减最大logit稳定计算。极端概率接近0时部分方向几乎无梯度；概率饱和不代表模型已获得可靠的校准。

逐样本梯度的噪声尺度估计

数学定义与推导

在独立同分布梯度抽样近似下，小批均值梯度协方差约为Σg/B，噪声相对信号强度与批大小有关。使用无偏样本协方差迹估计总噪声，分母为当前样本均值梯度平方范数。该比率是诊断量，不是无偏的真实噪声尺度估计。

$$\bar g=n^{-1}\sum_i g_i$$
$$\widehat{\operatorname{tr}\Sigma_g}=(n-1)^{-1}\sum_i\|g_i-\bar g\|^2$$
$$\widehat B_{\mathrm{noise}}=\widehat{\operatorname{tr}\Sigma_g}/\|\bar g\|^2$$

数值演算与金融应用

两条梯度(1,0)、(3,0)，均值(2,0)，平方范数4，协方差迹2，比率0.5。金融时间序列的批间相关会改变批均值方差；重叠标签下不能直接将该量解释为最佳batch size。

算法复杂度、输入契约与边界

O(nd)两遍，均值梯度范数必须非零。近驻点时该比率可能很大；应同时保留分子与分母，比较同一损失缩放和参数空间。

全局梯度裁剪及方向保持

数学定义与推导

将梯度投影到二范数球；若已可行，原梯度即最近点，否则沿原方向缩放到球面。由对称性或KKT条件得到统一比例，保留整体方向，与逐元素截断不同。梯度裁剪改变优化更新幅度，并不改变模型损失函数本身。

$$\tilde g=g\min(1,C/\|g\|_2)$$
$$\tilde g=\arg\min_{\|v\|_2\le C}\tfrac12\|v-g\|^2$$
$$g\ne0,\ C>0\ \Longrightarrow\ \cos(g,\tilde g)=1$$

数值演算与金融应用

梯度(3,4)的范数5，阈值2，比例0.4，裁剪后(1.2,1.6)，范数2。金融深度模型训练中大梯度可来自异常收益标签或不稳定状态，但裁剪不能替代数据质量诊断。

算法复杂度、输入契约与边界

O(d)，使用hypot累计范数减轻中间平方溢出。阈值严格正；零梯度输出不变。混合精度训练应在取消损失缩放后裁剪。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace depth_differentiation {
using namespace evidence;
inline Report logistic_hvp(const Mat& x,const Vec& p){
    auto d=validate(x,1,2,33)-1;parameters(p,2*d);Vec w(p.begin(),p.begin()+d),v(p.begin()+d,p.end()),g(d,0),hv(d,0);
    for(auto&r:x){double y=r.back();require(y==0||y==1,"Binary label required");double z=0,a=0;
        for(std::size_t j=0;j<d;++j){z+=r[j]*w[j];a+=r[j]*v[j];}
        double q=z>=0?1/(1+std::exp(-z)):std::exp(z)/(1+std::exp(z));double b=q*(1-q)*a;
        for(std::size_t j=0;j<d;++j){g[j]+=(q-y)*r[j];hv[j]+=b*r[j];}
    }double cur=dot(v,hv);Report o{{"Feature","Gradient","HessianVector","DirectionalCurvature"},{}};
    for(std::size_t j=0;j<d;++j)o.rows.push_back({double(j+1),g[j],hv[j],cur});return o;
}

inline Report softmax_jvp(const Mat& x,const Vec& p){
    validate(x,2,2,2);parameters(p,0);double m=x[0][0];for(auto&r:x)m=std::max(m,r[0]);Vec q;double s=0,a=0;
    for(auto&r:x){q.push_back(std::exp(r[0]-m));s+=q.back();}
    for(std::size_t i=0;i<x.size();++i){q[i]/=s;a+=q[i]*x[i][1];}
    Vec v;double z=0;for(std::size_t i=0;i<x.size();++i){v.push_back(q[i]*(x[i][1]-a));z+=v.back();}
    Report o{{"Class","Probability","JacobianVector","SumDerivative"},{}};
    for(std::size_t i=0;i<x.size();++i)o.rows.push_back({double(i),q[i],v[i],z});return o;
}

inline Report gradient_noise(const Mat& x,const Vec& p){
    auto d=validate(x,2,1,64);parameters(p,0);Vec m=means(x);double a=dot(m,m),b=0;
    for(auto&r:x)for(std::size_t j=0;j<d;++j)b+=(r[j]-m[j])*(r[j]-m[j]);b/=x.size()-1;
    return scalar({"MeanNormSquared","CovarianceTrace","NoiseScale"},{a,b,b/positive(a)});
}

inline Report global_gradient_clip(const Mat& x,const Vec& p){
    validate(x,1,1,1);parameters(p,1);double c=positive(p[0]),n=0;for(auto&r:x)n=std::hypot(n,r[0]);double s=n>c?c/n:1;
    Report o{{"Coordinate","Original","Clipped","Norm","Scale"},{}};
    for(std::size_t i=0;i<x.size();++i)o.rows.push_back({double(i+1),x[i][0],s*x[i][0],n,s});return o;
}
} }
