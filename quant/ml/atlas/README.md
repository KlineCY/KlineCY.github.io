# Kline Quant / Machine Learning Atlas

正式课程入口为 `quant/ml/index.html`，通过侧边栏进入。课程主体包含 **24 个专题、120 章、720 篇知识点讲义**。原版备份不参与正式阅读流程，不能将遗留的独立稿或旧版页面当成已发布教材。

## 数据与正文组成

- `atlas/data.part1` 至 `atlas/data.part4`：按顺序拼接的 gzip 数据。压缩后总长固定为 1,969,862 字节；前端解压后检查 720 个唯一讲义 ID 与 24 个专题。
- `atlas-editorial.json`：针对原始正文进行 20 处定义校订、31 处成立条件/适用边界校订及 2 处数学表达式勘误。仅在确认目标原文匹配时应用，不覆盖原始档案。
- `atlas-depth.json`、`atlas-depth-foundations.json`、`atlas-depth-learning.json`、`atlas-depth-quant.json`：第一阶段进阶讲义。
- `atlas-depth-foundations-2.json`、`atlas-depth-learning-2.json`、`atlas-depth-quant-2.json`：第二阶段进阶讲义。
- `atlas-depth-foundations-3.json`、`atlas-depth-learning-3.json`、`atlas-depth-quant-3.json`：第三阶段跨24专题深化，每篇包含具体数值或研究示例。
- `atlas-depth-foundations-4.json`、`atlas-depth-learning-4.json`、`atlas-depth-models-4.json`、`atlas-depth-deep-4.json`、`atlas-depth-crossdomain-4.json`、`atlas-depth-quant-4.json`：第四阶段根据剩余未深化讲义的分专题正文长度审计，逐一补充48篇（每个专题2篇），每篇含至少3项公式与可核算的数值/研究案例。
- `atlas-depth-foundations-5.json`、`atlas-depth-classical-5.json`、`atlas-depth-models-5.json`、`atlas-depth-deep-5.json`、`atlas-depth-crossdomain-5.json`、`atlas-depth-quant-5.json`：第五阶段采用分专题剩余薄弱正文审计，逐篇补充48篇，每个专题新增2篇，均含公式、条件推导、研究工作流、误区与数值案例。
- `atlas-depth-foundations-6.json`、`atlas-depth-learning-6.json`、`atlas-depth-quant-6.json`：第六阶段根据下一轮薄弱正文审计，跨24专题再补充24篇，均提供具体公式、条件分析、数值例子与研究工作流。
- `atlas-depth-07-a.json` 至 `atlas-depth-07-l.json`：第七阶段经24专题未深化知识点深度审计，逐一针对96篇原文添加数学推导、适用条件、数值示例、研究协议与误区（每专题4篇）；经过单独的结构与案例质量复审。
- `atlas-depth-08-a.json` 至 `atlas-depth-08-l.json`：第八阶段从未深化知识点中按专题各选5篇，围绕泛化与数值推导、时间泄漏、可复算案例、金融研究和生产风险直接完善120篇正式原文，全部保持精确原文标题映射。
- `atlas-depth-09-a.json` 至 `atlas-depth-09-l.json`：第九阶段经剩余未深化知识点的逐专题审计，新增122篇数学与金融研究深化内容，其中两个专题各6篇，其余22个专题各5篇；保持真实原文标题匹配与具体研究案例。
- 第十阶段跨23个仍有未深化知识点的专题，补充23篇进阶数学推导、数值示例与研究审查流程；MLOps专题原有30篇均已有进阶内容。第十一阶段覆盖从数学基础到金融策略的23个专题，新增23篇严格对应的深度正文及独立数值案例。第十二阶段跨23个专题新增23篇有数值示例、成立条件及研究工作流的进阶正文。第十三阶段跨23个专题新增23篇定向深化，覆盖统计学习、神经网络、生成模型、强化学习与量化研究。第十四阶段继续跨23个专题增加23篇可核算的数学推导与可执行研究协议。第十五阶段在23个专题各补充一篇正式深度正文，涵盖数学与统计推导、网络架构、强化学习和量化风险验证。第十六阶段在23个专题补充第二轮定向深化，新增23篇数值和研究示例。第十七阶段前3批新增17篇，补充时间序列、注意力掩码、SFT、图归一及扩散模型等推导。第十八阶段补齐最后4篇强化学习与量化风险核算讲义，实现 **720/720篇正式知识点的进阶深化全覆盖**。93 个进阶模块合计提供 **720 篇增强正文**；共664篇附带数值或研究示例。每个专题至少22篇进阶内容。原有24专题、120章、720篇正式结构保持不变，不新增独立草稿或重复目录。

页面加载顺序：完整档案 → 精确正文勘误 → 基于 `atlas-depth-manifest.json` 加载93个进阶模块，最多同时请求6个模块、失败时进行有上限的重试 → 进阶正文附加 → 全文索引及目录。前端 `atlas.js` 校验资源路径、模块数量、目标 ID、原始标题、增强内容结构以及24专题覆盖。数学由 KaTeX 渲染。可以通过“只看进阶深化”筛选720篇增强正文；同时支持“只看未学讲义”“继续下一篇未学”和在单篇正文内直接跳至进阶推导。学习状态只保存在当前浏览器，跨设备不自动同步。

## 持续校验

在仓库根目录运行：

```bash
python quant/ml/tools/verify_atlas.py
node quant/ml/test_ml.mjs
node quant/ml/test_loader.mjs
python -m unittest discover quant/ml -p 'test_*.py' -v
```

其中 Node.js 脚本需要依赖 `katex@0.16.11`，可参照 `.github/workflows/test-quant-ml.yml` 安装。GitHub Actions 在 `quant/ml/**` 更新后运行数学/JavaScript 结构检查及 Python 示例测试。

主要校验包括档案完整性、HTML 结构、720 段 Python 的语法、已内链目标、补充内容与真实讲义标题的对应关系、KaTeX 公式语法，以及所有已识别通用模板段落不再残留。数值测试包括第三阶段14项独立单元测试、第四阶段每专题1项合计24项可复算示例、第五阶段每专题1项合计24项、以及第六阶段每专题1项合计24项，以及第七阶段每专题2项合计48项、第八阶段每专题3项合计72项、第九阶段每专题2项合计48项可复算示例（以上为早期阶段案例检查，后续阶段还有独立单元测试；以仓库实际测试结果为准）。此外结构校验要求第五阶段48篇、第六阶段24篇、第七阶段96篇、第八阶段120篇、第九阶段122篇和第十阶段23篇全部具有具体数学案例。覆盖回归风险、KL、滚动收益、核正定、神经网络参数、强化学习、EGARCH及量化交易净收益等。自动测试 **不等于** 正文数学结论的形式化证明、全部示例在真实环境中执行成功、浏览器端所有交互验证或量化策略的实盘可交易性证明。

## 编辑准则

1. 内容必须落到既有讲义 ID；每项深化明确数学对象、符号、条件、推导、工程/研究流程和失败边界。
2. 所有样本内外比较均应说明数据可得时点、特征与标签的时间关系、估计窗和成本/风险口径；不能用回测结果代替验证。
3. 新增模块保留 `source_title` 与原文标题逐字对应，并提供至少两条可被 KaTeX 校验的数学公式及足够具体的推导和限制条件。第三至第十阶段强化内容额外提供数值或研究示例。第四至第十阶段每篇至少提供3条数学公式、具体推导条件、一个可核算案例及研究流程。
4. 不增加“独立稿”“待扩展”“泛化提示”等替代正文的占位模块；临时研究备份不得进入公开导航。
5. 对解释性实验、研究示例和实际可执行交易分别标注，严禁把自动化检查通过表述为经济价值已证实。

页面资源下载采用固定并发上限和有限次数重试；加载过程中显示档案解压、模块下载进度与最终索引校验状态。进阶模块必须完整、标题一致才能启用正式阅读器，防止部分下载成功却被误报为完整教材。
