中心化线性核目标对齐

单特征线性核的中心化为中心化向量外积，标签核同理；Frobenius内积化简为中心化内积的平方。

$$K_c=HKH,\quad L_c=Hyy^\top H,\quad H=I-\mathbf1\mathbf1^\top/n$$
$$A(K,L)=\langle K_c,L_c\rangle_F/(\|K_c\|_F\|L_c\|_F)$$

样本特征与标签一致时对齐值1，两个核范数均2。可筛选金融特征，标签参与筛选必须限制在训练集；非线性核需完整矩阵。

核矩阵双中心化

对称矩阵行列均值一致，减去二者再加回总均值得双中心化；原核半正定时中心化仍半正定。

$$K_c=HKH=K-\mathbf1m^\top-m\mathbf1^\top+\bar K\mathbf1\mathbf1^\top$$
$$K_c\mathbf1=0,\quad z^\top HKHz=(Hz)^\top K(Hz)\ge0$$

核PCA中外积矩阵中心化后元素±0.25。代码检查对称性，不自动检验半正定；样本外核需沿用训练集中心化口径。

软标签交叉熵与KL差距

目标熵固定时交叉熵最小化等价于KL最小化，最优预测为目标概率。两列概率分别归一，预测概率严格正，目标允许零。

$$H(q,p)=-\sum_kq_k\log p_k,\quad H(q)=-\sum_kq_k\log q_k$$
$$D_{\mathrm{KL}}(q\Vert p)=H(q,p)-H(q)\ge0$$

教师模型概率蒸馏：均匀预测对目标0.25、0.75，交叉熵ln2、KL约0.1308。软标签也要遵循训练信息时点约束。

线性概率校准截距与斜率

若条件事件概率等于预测值，线性投影截距斜率必为0、1；反向不成立，非线性失准也可能满足两矩条件。

$$y_i=a+bp_i+u_i,\quad \hat b=S_{py}/S_{pp}$$
$$\hat a=\bar y-\hat b\bar p,\quad (a,b)=(0,1)\ \text{under calibration}$$

违约概率案例平均预测及频率均0.5，但斜率1.5、截距−0.25。此为线性诊断，不是Logistic校准，不能保证输出在单位区间。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace applied_learning {
using namespace evidence;
inline Report kernel_alignment(const Mat& x,const Vec& p){
    validate(x,2,2,2);
    parameters(p,0);
    double a=mean(column(x,0)),b=mean(column(x,1)),s=0,t=0,c=0;
    for(auto&r:x){double u=r[0]-a,v=r[1]-b;
    s+=u*u;
    t+=v*v;
    c+=u*v;
    }return scalar({"Alignment","KernelNorm","TargetNorm"},{c*c/(positive(s)*positive(t)),s,t});
    
}

inline Report gram_centering(const Mat& x,const Vec& p){
    auto n=validate(x,2,2,64);
    parameters(p,0);
    require(x.size()==n,"Square Gram matrix required");
    Vec m(n,0);
    double a=0;
    for(std::size_t i=0;
    i<n;
    ++i)for(std::size_t j=0;
    j<n;
    ++j){require(std::abs(x[i][j]-x[j][i])<=1e-10*std::max({1.,std::abs(x[i][j]),std::abs(x[j][i])}),"Symmetric Gram matrix required");
    m[i]+=x[i][j]/n;
    a+=x[i][j]/double(n*n);
    }Report o{{"Row"},{}};
    for(std::size_t j=0;
    j<n;
    ++j)o.header.push_back("Kc"+std::to_string(j+1));
    for(std::size_t i=0;
    i<n;
    ++i){Vec r{double(i+1)};
    for(std::size_t j=0;
    j<n;
    ++j)r.push_back(x[i][j]-m[i]-m[j]+a);
    o.rows.push_back(r);
    }return o;
    
}

inline Report soft_label(const Mat& x,const Vec& p){
    validate(x,2,2,2);
    parameters(p,0);
    double a=0,b=0,ce=0,h=0;
    for(auto&r:x){require(r[0]>0&&r[0]<=1&&r[1]>=0&&r[1]<=1,"Invalid probability");
    a+=r[0];
    b+=r[1];
    if(r[1]>0){ce-=r[1]*std::log(r[0]);
    h-=r[1]*std::log(r[1]);
    }}require(std::abs(a-1)<1e-10&&std::abs(b-1)<1e-10,"Probabilities must sum to one");
    return scalar({"CrossEntropy","TargetEntropy","KL"},{ce,h,ce-h});
    
}

inline Report calibration_slope(const Mat& x,const Vec& p){
    validate(x,2,2,2);
    parameters(p,0);
    double a=mean(column(x,0)),b=mean(column(x,1)),s=0,c=0;
    for(auto&r:x){require(r[0]>=0&&r[0]<=1&&(r[1]==0||r[1]==1),"Invalid forecast or event");
    s+=(r[0]-a)*(r[0]-a);
    c+=(r[0]-a)*(r[1]-b);
    }double beta=c/positive(s);
    return scalar({"Intercept","Slope","MeanForecast","MeanOutcome"},{b-beta*a,beta,a,b});
    
}
} }
