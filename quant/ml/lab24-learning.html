1．在线Logistic梯度更新与逐步预测

模型结构与数学定义

每条观测到达时先用当前参数形成概率预测，再根据该样本的对数损失梯度更新参数。两个特征的权重从零开始，返回最终两个权重和更新前预测的平均对数损失。预测必须先于标签更新，适合研究真正的在线样本外过程。

$$\widehat p_t=\sigma(w_t^\top x_t),\quad w_{t+1}=w_t-\eta(\widehat p_t-y_t)x_t$$

推导、最优性条件与数值结构

$$\ell(z,y)=\log(1+e^z)-yz,\qquad \nabla_w\ell=(\sigma(z)-y)x$$

将二元负对数似然写为log-sum-exp形式，对线性预测值求导得到概率减标签。稳定计算使用max(z,0)+log(1+exp(−|z|))，避免正指数溢出。

完整计算案例

特征(1,0)、标签1、学习率0.2；初始预测0.5，第一权重更新为0.1，第二权重保持0，预测对数损失log2。

$$\mathrm{Output}\approx\left(0.1,\ 0,\ 0.693147181\right)$$

输出顺序：第一特征权重、第二特征权重、预测前平均对数损失。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

标签只能取0或1。特征缩放决定合适的学习率；此实现不含截距，常数项可作为一个特征显式传入。

2．AdaGrad在线平方损失与L2惩罚

模型结构与数学定义

平方预测误差的梯度与L2收缩项结合，再按每个坐标历史梯度平方和调整步长。对于稀疏特征，该机制能够使较少更新的坐标维持较大有效学习率。返回两个最终权重及预测前均方误差。

$$g_t=(w_t^\top x_t-y_t)x_t+\lambda w_t,\quad G_t=G_{t-1}+g_t^2,\quad w_{t+1}=w_t-\eta g_t/(\sqrt{G_t}+\varepsilon)$$

推导、最优性条件与数值结构

$$G_{t,j}=\sum_{s\le t}g_{s,j}^2,\quad \eta_{t,j}=\eta/(\sqrt{G_{t,j}}+\varepsilon)$$

坐标尺度由历史梯度二阶累积量调整。累积量越大，未来同坐标的有效步长越小；L2项在梯度中直接收缩权重，预测误差在当前更新发生前记录。

完整计算案例

仅一条特征(1,0)、响应2、学习率0.1、L2惩罚1、稳定项0.001，初始梯度−2，更新后第一权重为0.2/2.001，初始平方误差为4。

$$\mathrm{Output}\approx\left(0.099950025,\ 0,\ 4\right)$$

输出顺序：两个最终权重、更新前平均平方预测误差。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

3．离散概率分组的Brier分解

模型结构与数学定义

将具有完全相同预测概率的记录分组，分别计算组内事件发生频率、预测与组内频率之差及组内频率与总体发生率之差。Murphy分解在这些精确分组上给出可靠性、分辨率、不确定性及原始Brier分数。

$$BS=\underbrace{\sum_g n_g(p_g-o_g)^2/n}_{REL}-\underbrace{\sum_g n_g(o_g-\bar o)^2/n}_{RES}+\bar o(1-\bar o)$$

推导、最优性条件与数值结构

$$\mathbb E[(p-Y)^2\mid p]=(p-o_p)^2+o_p(1-o_p),\quad UNC=RES+\sum_g\frac{n_g}{n}o_g(1-o_g)$$

在每个概率组内展开平方，交叉项因标签残差均值为零而消失。总不确定性又可拆分为组间与组内方差，组合得到BS=REL−RES+UNC。

完整计算案例

概率0.25、0.75分别预测标签0、1，原始分数0.0625；可靠性0.0625、分辨率0.25、不确定性0.25，三项满足恒等式。

$$\mathrm{Output}\approx\left(0.0625,\ 0.0625,\ 0.25,\ 0.25\right)$$

输出顺序：Brier原始分数、可靠性、分辨率、不确定性。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

4．PAV单调概率校准

模型结构与数学定义

输入按模型分数由低到高排列。先合并相同分数的标签，再把每个分数组视为一个带权均值块。若相邻块均值违反单调性，合并两块并继续向左检查，直至所有块均值有序。输出逐样本校准概率。

$$\min_{q_1\le\cdots\le q_n}\sum_i(y_i-q_i)^2$$

推导、最优性条件与数值结构

$$\widehat q_B=\frac{\sum_{i\in B}y_i}{|B|}$$

若相邻块均值逆序，受单调约束的两块最优解必须共享边界值，即合并块的均值。不断合并违反顺序的相邻块，直至满足全部单调约束。

完整计算案例

四条递增分数对应标签0、1、0、1；中间两块违反单调性，合并为0.5，输出0、0.5、0.5、1。

$$\mathrm{Output}\approx\left(0,\ 0.5,\ 0.5,\ 1\right)$$

输出顺序：原始排序记录的逐行单调校准概率。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

5．两模型非负归一权重的最小平方Stacking

模型结构与数学定义

设组合预测为w乘模型1加(1−w)乘模型2。对组合残差平方和求导，得到一元无约束闭式解，再投影到[0,1]保证非负权重和为1。输出两模型权重及组合均方误差。

$$w^*=\Pi_{[0,1]}\frac{\sum_i(\widehat y_{1i}-\widehat y_{2i})(y_i-\widehat y_{2i})}{\sum_i(\widehat y_{1i}-\widehat y_{2i})^2}$$

推导、最优性条件与数值结构

$$RSS(w)=\sum_i[a_i-wd_i]^2,\quad a_i=y_i-\widehat y_{2i},\quad d_i=\widehat y_{1i}-\widehat y_{2i}$$

二次目标的曲率为两模型预测差的平方和。若存在预测差异，目标凸且驻点唯一，将驻点截断至合法区间即可获得约束全局解；否则任意权重等价。

完整计算案例

模型1预测0、2，模型2预测2、0，真实值均为1，最优权重各0.5，组合误差为0。

$$\mathrm{Output}\approx\left(0.5,\ 0.5,\ 0\right)$$

输出顺序：模型1权重、模型2权重、组合均方误差。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

独立算法

#pragma once
#include "lab24_common.hpp"
#include <map>

namespace kline { namespace lab24 {
inline Vec online_logistic(const Mat& x,const Vec& p){
    inputs(x,p,3,1);double lr=positive(p[0]),a=0,b=0,loss=0;
    for(const auto& r:x){require(r[2]==0||r[2]==1,"Binary label required");double z=a*r[0]+b*r[1],q=logistic(z);loss+=std::max(z,0.0)-r[2]*z+std::log1p(std::exp(-std::abs(z)));a-=lr*(q-r[2])*r[0];b-=lr*(q-r[2])*r[1];}
    return checked({a,b,loss/x.size()});
}

inline Vec adagrad_ridge(const Mat& x,const Vec& p){
    inputs(x,p,3,3);double lr=positive(p[0]),l=p[1],eps=positive(p[2]);require(l>=0,"Negative regularization");
    Vec w(2,0),g2(2,0);double mse=0;
    for(const auto& r:x){double e=w[0]*r[0]+w[1]*r[1]-r[2];mse+=e*e;for(std::size_t j=0;j<2;++j){double g=e*r[j]+l*w[j];g2[j]+=g*g;w[j]-=lr*g/(std::sqrt(g2[j])+eps);}}
    return checked({w[0],w[1],mse/x.size()});
}

inline Vec brier_decomposition(const Mat& x,const Vec& p){
    inputs(x,p,2,0);std::map<double,Vec> groups;double bs=0,base=0,n=double(x.size());
    for(const auto& r:x){require(r[0]>=0&&r[0]<=1&&(r[1]==0||r[1]==1),"Invalid probability or label");double e=r[0]-r[1];bs+=e*e;base+=r[1];auto& g=groups[r[0]];if(g.empty())g={0,0};g[0]+=r[1];++g[1];}
    base/=n;double rel=0,res=0;
    for(const auto& g:groups){double o=g.second[0]/g.second[1],w=g.second[1]/n;rel+=w*(g.first-o)*(g.first-o);res+=w*(o-base)*(o-base);}
    return checked({bs/n,rel,res,base*(1-base)});
}

inline Vec isotonic_pav(const Mat& x,const Vec& p){
    inputs(x,p,2,0);struct Block{std::size_t count;double s;};std::vector<Block> blocks;
    for(std::size_t i=0;i<x.size();){require(i==0||x[i][0]>=x[i-1][0],"Scores must be sorted");std::size_t j=i;double s=0;
        while(j<x.size()&&x[j][0]==x[i][0]){require(x[j][1]==0||x[j][1]==1,"Binary label required");s+=x[j][1];++j;}
        blocks.push_back({j-i,s});i=j;
        while(blocks.size()>=2){auto b=blocks.back(),a=blocks[blocks.size()-2];if(a.s/a.count<=b.s/b.count)break;blocks.pop_back();blocks.back()={a.count+b.count,a.s+b.s};}
    }
    Vec out;for(auto b:blocks)out.insert(out.end(),b.count,b.s/b.count);return checked(out);
}

inline Vec stacking_two(const Mat& x,const Vec& p){
    inputs(x,p,3,0);double a=0,b=0;
    for(const auto& r:x){double d=r[0]-r[1];a+=d*(r[2]-r[1]);b+=d*d;}
    double w=b>0?std::clamp(a/b,0.0,1.0):0.5,mse=0;
    for(const auto& r:x){double e=w*r[0]+(1-w)*r[1]-r[2];mse+=e*e;}
    return checked({w,1-w,mse/x.size()});
}
} }

namespace kline { namespace lab24 {
using Vec=std::vector<double>;
using Mat=std::vector<Vec>;

inline void inputs(const Mat& x,const Vec& p,std::size_t cols,std::size_t params,
                   std::size_t min_rows=1) {
    require(x.size()>=min_rows&&x.size()<=250000,"Invalid number of observations");
    require(p.size()==params,"Incorrect scalar parameter count");
    for(double v:p)require(std::isfinite(v),"Nonfinite scalar parameter");
    for(const auto& row:x){
        require(row.size()==cols,"Unexpected CSV column count");
        for(double v:row)require(std::isfinite(v),"Nonfinite matrix entry");
    }
}
inline std::size_t integer(double x,std::size_t low,std::size_t high){
    require(std::isfinite(x)&&x>=double(low)&&x<=double(high)&&std::floor(x)==x,
            "Integer parameter outside allowed range");
    return std::size_t(x);
}
inline double dot(const Vec& a,const Vec& b){
    require(a.size()==b.size(),"Dot product dimension mismatch");
    return std::inner_product(a.begin(),a.end(),b.begin(),0.0);
}
inline Vec col(const Mat& x,std::size_t j){
    Vec out;out.reserve(x.size());
    for(const auto& row:x)out.push_back(row.at(j));
    return out;
}
inline double positive(double x){require(x>0&&std::isfinite(x),"Positive finite quantity required");return x;}
inline Vec checked(Vec v){check_finite(v);return v;}
inline double logistic(double x){
    if(x>=0)return 1/(1+std::exp(-x));
    double e=std::exp(x);return e/(1+e);
}
inline double normal_cdf(double x){return 0.5*std::erfc(-x/std::sqrt(2.0));}
inline double sum(const Vec& v){return std::accumulate(v.begin(),v.end(),0.0);}
