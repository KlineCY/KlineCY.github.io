先验概率漂移的二元后验修正

模型与推导

标签漂移假设保持各类别的条件特征分布不变，只改变类别先验；贝叶斯公式的似然比不变，赔率按先验赔率比调整。

$$\frac{p_T(y=1|x)}{p_T(y=0|x)}=\frac{p_S(y=1|x)}{p_S(y=0|x)}\frac{\pi_T/(1-\pi_T)}{\pi_S/(1-\pi_S)}$$
$$p_T=\frac{a p_S}{1-p_S+a p_S}$$

研究应用与成立条件

训练违约率0.5、部署率0.2，源概率0.5调整为0.2。若条件分布本身改变或源模型未校准，单纯先验修正不能恢复真实后验。

含并列分数的ROC-AUC概率解释

模型与推导

AUC是正例排名超过负例的概率，平局计半。实现按分数排序，在同分组累计低分负例数，复杂度O(n log n)，无需成对枚举。

$$\mathrm{AUC}=\Pr(s^+>s^-)+\tfrac12\Pr(s^+=s^-)$$
$$\widehat{\mathrm{AUC}}=(n_+n_-)^{-1}\sum_{i:y_i=1}\sum_{j:y_j=0}[\mathbf1(s_i>s_j)+\tfrac12\mathbf1(s_i=s_j)]$$

研究应用与成立条件

两正两负，四对中三对严格正确、一对平局，AUC0.875。AUC不评价概率校准及低误报区的成本，稀有事件还需PR曲线。

多分类Brier分数及均匀基准

模型与推导

多分类平方评分对整个概率向量计误差，严格适当性由条件期望的平方分解得到。均匀概率预测每行分数恒1−1／K。

$$\mathrm{BS}=\frac1n\sum_i\sum_{k=1}^K(p_{ik}-\mathbf1\{y_i=k\})^2$$
$$\mathrm{BSS}=1-\mathrm{BS}/(1-1/K)$$

研究应用与成立条件

三种市场状态的两条预测分数0.375与0.24，均值0.3075。技能分数相对均匀基准；实际还可与训练期先验基准比较，不能把事后标签频率作为事前预测。

二元概率预测的成本阈值

模型与推导

逐样本比较正负决策的条件期望成本得到Bayes阈值。阈值固定后，在留出样本计算混淆矩阵和实际成本；不在测试集搜索阈值。

$$L(1|p)=c_{\mathrm{FP}}(1-p),\quad L(0|p)=c_{\mathrm{FN}}p$$
$$a^*(p)=\mathbf1\{p\geq c_{\mathrm{FP}}/(c_{\mathrm{FP}}+c_{\mathrm{FN}})\}$$

研究应用与成立条件

误报成本2、漏报1，阈值2／3；样本仅0.9为正，漏报一例成本1。金融信号成本可随波动和容量变化，应使用动态条件效用而非固定分类成本。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace methods_classification {
using namespace evidence;
inline Report prior_adjustment(const Mat& x,const Vec& p){
    validate(x,1,1,1);
    parameters(p,2);
    require(p[0]>0&&p[0]<1&&p[1]>0&&p[1]<1,"Invalid prior");
    double a=p[1]*(1-p[0])/(p[0]*(1-p[1]));
    Report o{{"SourceProbability","TargetProbability"},{}};
    for(auto&r:x){double z=r[0];
    require(z>=0&&z<=1,"Invalid posterior");
    o.rows.push_back({z,a*z/(1-z+a*z)});
    }return o;
    
}

inline Report pairwise_auc(const Mat& x,const Vec& p){
    validate(x,2,2,2);
    parameters(p,0);
    Mat a=x;
    double pos=0,neg=0;
    for(auto&r:a){require(r[1]==0||r[1]==1,"Invalid event");
    pos+=r[1];
    neg+=1-r[1];
    }positive(pos);
    positive(neg);
    std::sort(a.begin(),a.end(),[](const Vec&u,const Vec&v){return u[0]<v[0];
    });
    double b=0,s=0;
    for(std::size_t i=0;
    i<a.size();
    ){std::size_t j=i;
    double P=0,N=0;
    while(j<a.size()&&a[j][0]==a[i][0]){P+=a[j][1];
    N+=1-a[j][1];
    ++j;
    }s+=P*(b+.5*N);
    b+=N;
    i=j;
    }return scalar({"Positive","Negative","AUC"},{pos,neg,s/(pos*neg)});
    
}

inline Report multiclass_brier(const Mat& x,const Vec& p){
    auto d=validate(x,1,3,64);
    parameters(p,0);
    auto K=d-1;
    double s=0;
    for(auto&r:x){auto y=count(r[0],0,K-1);
    double a=0;
    for(std::size_t j=0;
    j<K;
    ++j){double q=r[j+1];
    require(q>=0&&q<=1,"Invalid probability");
    a+=q;
    double z=q-double(j==y);
    s+=z*z;
    }require(std::abs(a-1)<1e-9,"Probabilities must sum to one");
    }double b=1-1./K,v=s/x.size();
    return scalar({"Brier","UniformBaseline","Skill"},{v,b,1-v/b});
    
}

inline Report binary_cost_frontier(const Mat& x,const Vec& p){
    validate(x,1,2,2);
    parameters(p,2);
    double a=positive(p[0]),b=positive(p[1]),t=a/(a+b),tp=0,fp=0,tn=0,fn=0;
    for(auto&r:x){require(r[0]>=0&&r[0]<=1&&(r[1]==0||r[1]==1),"Invalid input");
    bool z=r[0]>=t;
    if(z){if(r[1])++tp;
    else ++fp;
    }else{if(r[1])++fn;
    else ++tn;
    }}return scalar({"Threshold","TP","FP","TN","FN","TotalCost"},{t,tp,fp,tn,fn,a*fp+b*fn});
    
}
