二元Focal损失与Logit梯度

数学定义与推导

Focal损失在交叉熵前乘难度调制因子，使易分类样本的贡献随正确类别概率趋近1而更快衰减。对t求导使用σ′=σ(1−σ)，再乘类别符号。代码用稳定的log-sigmoid计算，避免极端logit产生log(0)。这里不额外引入类别权重。

$$t=(2y-1)z,\quad p_t=\sigma(t)$$
$$L=- (1-p_t)^\gamma\log p_t$$
$$\frac{\partial L}{\partial z}=(2y-1)(1-p_t)^\gamma[\gamma p_t\log p_t-(1-p_t)]$$

数值演算与金融应用

logit为0时正确类别概率0.5，γ=2损失0.25ln2，正类梯度为−(0.25ln2+0.125)，负类符号相反。适用于极不平衡金融事件训练，但调制损失一般不保证直接获得校准概率。

算法复杂度、输入契约与边界

O(n)，γ≥0，标签二元。γ=0退化为普通交叉熵；过强调制会降低有效训练梯度。比较模型时须固定同一留出样本评分与经济成本。

分位数检查损失的平滑近似

数学定义与推导

检查损失在零残差处不可微。用分段二次—线性函数平滑绝对值，再按残差方向赋予τ或1−τ权重，可保留不对称梯度且在零点连续可微。δ趋零时逐点逼近原pinball损失；有限δ的总体最优点通常不同于精确条件分位数。

$$h_\delta(u)=\begin{cases}u^2/(2\delta)&|u|\le\delta\\|u|-\delta/2&|u|>\delta\end{cases}$$
$$L_{\tau,\delta}(u)=|\tau-\mathbf1\{u<0\}|h_\delta(u)$$
$$\partial_u L_{\tau,\delta}=|\tau-\mathbf1\{u<0\}|\operatorname{clip}(u/\delta,-1,1)$$

数值演算与金融应用

τ=0.75、δ=1，正残差2的损失1.125、梯度0.75，负残差−2损失0.375、梯度−0.25。预测残差定义为y−ŷ，因此对预测值的梯度需取反号。适用于近似分位数神经网络的梯度诊断。

算法复杂度、输入契约与边界

O(n)，τ严格介于0和1、δ>0。δ按收益尺度设定，不能直接在不同计价单位之间复用。此损失不是对精确分位数严格适当的替代评分。

固定预测Logit的校准截距得分

数学定义与推导

固定基础模型logit，校准截距仅改变整体赔率。负对数似然关于截距为凸函数，一阶条件要求预测概率和等于事件数；Newton步骤用曲率缩放梯度。代码报告一次更新，不保证单步达到最优，也不在测试集自动重新校准。

$$p_i(a)=\sigma(z_i+a),\quad L(a)=\sum_i[\log(1+e^{z_i+a})-y_i(z_i+a)]$$
$$L'(a)=\sum_i(p_i-y_i),\quad L''(a)=\sum_i p_i(1-p_i)$$
$$a_{\mathrm{new}}=a-L'(a)/L''(a)$$

数值演算与金融应用

三条基础logit为0，标签1、0、1，截距0时NLL为3ln2，梯度−0.5，信息0.75，更新到2/3。精确最优截距是ln2，因此单步仍有误差。可在独立校准窗纠正类别基准率偏差。

算法复杂度、输入契约与边界

O(n)，至少一条观测，曲率必须为正；全正或全负标签时无有限未正则化最优截距。极端logit下曲率退化应采用阻尼或正则。

多分类逆温度校准的凸性与曲率

数学定义与推导

将温度倒数b作为优化变量，log-sum-exp在b上凸。梯度衡量预测概率加权logit与真实标签logit差，Hessian为条件logit方差。b≥0保持类别排序；b=0给出均匀概率的闭区间边界。校准通常在独立留出集估计。

$$p_{ik}(b)=\frac{\exp(bz_{ik})}{\sum_j\exp(bz_{ij})}$$
$$L(b)=\sum_i[\log\sum_k e^{bz_{ik}}-bz_{i,y_i}]$$
$$L'(b)=\sum_i(\mathbb E_{p_i}z_i-z_{i,y_i}),\quad L''(b)=\sum_i\operatorname{Var}_{p_i}(z_i)\ge0$$

数值演算与金融应用

两个样本logit分别(1,0)、(0,1)，标签均为各自较大者。b=0时均匀概率，NLL=2ln2，梯度−1、曲率0.5。数据完全正确分类时最优逆温度可能趋于无穷，需约束或更多校准信息。

算法复杂度、输入契约与边界

O(nK)，标签为从0开始的整数，至少两类。使用减最大logit后的log-sum-exp稳定归一化；不同模型的温度参数不可直接横向比较。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace depth_loss {
using namespace evidence;
inline Report binary_focal(const Mat& x,const Vec& p){
    validate(x,1,2,2);parameters(p,1);double g=p[0];require(g>=0,"Negative focal gamma");Report o{{"Logit","Label","Loss","Derivative"},{}};
    for(auto&r:x){
        require(r[1]==0||r[1]==1,"Binary label required");
        double sign=2*r[1]-1,t=sign*r[0],lp=t>=0?-std::log1p(std::exp(-t)):t-std::log1p(std::exp(t));
        double q=-std::expm1(lp),pt=std::exp(lp),f=g==0?1:std::pow(q,g);
        o.rows.push_back({r[0],r[1],-f*lp,sign*f*(g*pt*lp-q)});
    }return o;
}

inline Report huberized_pinball(const Mat& x,const Vec& p){
    validate(x,1,1,1);parameters(p,2);require(p[0]>0&&p[0]<1,"Invalid quantile");double d=positive(p[1]);Report o{{"Residual","Loss","ResidualGradient"},{}};
    for(auto&r:x){double u=r[0],a=std::abs(u),w=u<0?1-p[0]:p[0],h=a<=d?a*a/(2*d):a-d/2,g=std::max(-1.,std::min(1.,u/d));o.rows.push_back({u,w*h,w*g});}return o;
}

inline Report logit_intercept_score(const Mat& x,const Vec& p){
    validate(x,1,2,2);parameters(p,1);double L=0,g=0,h=0;
    for(auto&r:x){require(r[1]==0||r[1]==1,"Binary label required");double z=r[0]+p[0],q=z>=0?1/(1+std::exp(-z)):std::exp(z)/(1+std::exp(z));L+=std::max(z,0.)-r[1]*z+std::log1p(std::exp(-std::abs(z)));g+=q-r[1];h+=q*(1-q);}
    return scalar({"NLL","Score","Information","NewtonStep"},{L,g,h,p[0]-g/positive(h)});
}

inline Report temperature_curvature(const Mat& x,const Vec& p){
    auto K=validate(x,1,3,64)-1;parameters(p,1);double b=p[0];require(b>=0,"Negative inverse temperature");double L=0,g=0,h=0;
    for(auto&r:x){auto y=count(r[0],0,K-1);double m=*std::max_element(r.begin()+1,r.end()),s=0,u=0,v=0;
        for(std::size_t j=0;j<K;++j){double z=r[j+1]-m,w=std::exp(b*z);s+=w;u+=w*z;v+=w*z*z;}
        L+=std::log(s)-b*(r[y+1]-m);u/=s;g+=u-(r[y+1]-m);h+=std::max(0.,v/s-u*u);
    }return scalar({"InverseTemperature","NLL","Gradient","Curvature"},{b,L,g,h});
}
} }
