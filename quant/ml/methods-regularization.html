正交设计Lasso软阈值路径

模型与推导

正交设计的目标可分离为一维二次加绝对值。分别在正、负和零区间使用次梯度条件得到软阈值。输入充分统计量c_j=Xᵀy与列平方范数，不含截距。

$$\min_\beta\frac12\|y-X\beta\|_2^2+\lambda\|\beta\|_1,\quad X^\top X=\operatorname{diag}(d_j)$$
$$\hat\beta_j=\operatorname{sign}(c_j)(|c_j|-\lambda)_+/d_j$$

研究应用与成立条件

三个因子内积3、−1、0.5，惩罚1，仅第一个保留系数2。非正交设计必须用坐标下降等联合求解，不能逐列套用该闭式。

Ridge有效自由度与谱收缩

模型与推导

将X代入SVD，帽子矩阵沿左奇异向量的特征值为s²／（s²＋λ）。迹是拟合对观测的总线性敏感度，惩罚增加时单调下降。

$$H_\lambda=X(X^\top X+\lambda I)^{-1}X^\top$$
$$\operatorname{df}(\lambda)=\operatorname{tr}(H_\lambda)=\sum_j s_j^2/(s_j^2+\lambda)$$

研究应用与成立条件

谱9、1、0，λ＝1，自由度1.4。若截距不惩罚，应另加相应自由度。比较不同尺度的因子时需统一训练标准化。

高斯线性平滑器SURE

模型与推导

Stein恒等式将噪声与拟合误差的交叉项化为散度。线性平滑器散度为迹，因此SURE无偏估计同一设计下均值估计风险，不是新设计点的预测误差。

$$y=\mu+\varepsilon,\quad\varepsilon\sim N(0,\sigma^2I),\quad \hat\mu=Hy$$
$$\mathrm{SURE}=\|y-\hat\mu\|^2+2\sigma^2\operatorname{tr}H-n\sigma^2$$

研究应用与成立条件

样本残差平方和1.25、噪声方差1、自由度1，SURE为1.25。方差及自由度需由模型给出；对数据依赖的模型选择，固定矩阵公式可能不足。

重采样选择频率与稳定性阈值

模型与推导

每次子样本训练输出二元入选指标，列均值为经验选择频率。稳定性选择的理论错误控制还要求特定子抽样与交换性等条件；单独频率不能自动转换成FDR。

$$\hat\pi_j=B^{-1}\sum_{b=1}^{B}\mathbf1\{j\in\hat S_b\}$$
$$\hat S_{\mathrm{stable}}=\{j:\hat\pi_j\geq\pi_{\mathrm{thr}}\}$$

研究应用与成立条件

四次金融因子筛选，两因子入选频率0.75、0.5，阈值0.75保留第一项。重抽样要维护时间及资产依赖结构，不能泄露留出期。

C++17实现

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace methods_regularization {
using namespace evidence;
inline Report orthogonal_lasso(const Mat& x,const Vec& p){
    validate(x,1,2,2);
    parameters(p,1);
    require(p[0]>=0,"Negative penalty");
    Report o{{"Feature","Coefficient","Active"},{}};
    for(std::size_t i=0;
    i<x.size();
    ++i){auto&r=x[i];
    double v=std::copysign(std::max(0.,std::abs(r[0])-p[0]),r[0])/positive(r[1]);
    o.rows.push_back({double(i+1),v,double(v!=0)});
    }return o;
    
}

inline Report ridge_effective_df(const Mat& x,const Vec& p){
    validate(x,1,1,1);
    parameters(p,1);
    positive(p[0]);
    Report o{{"Mode","Shrinkage","EffectiveDF"},{}};
    double total=0;
    for(std::size_t i=0;
    i<x.size();
    ++i){double s=x[i][0];
    require(s>=0,"Negative squared singular value");
    double v=s/(s+p[0]);
    total+=v;
    o.rows.push_back({double(i+1),v,0});
    }for(auto&r:o.rows)r.back()=total;
    return o;
    
}

inline Report sure_linear(const Mat& x,const Vec& p){
    validate(x,1,2,2);
    parameters(p,2);
    require(p[0]>=0&&p[1]>=0&&p[1]<=double(x.size()),"Invalid variance or effective df");
    double s=0;
    for(auto&r:x)s+=(r[0]-r[1])*(r[0]-r[1]);
    double v=s+2*p[0]*p[1]-x.size()*p[0];
    return scalar({"ResidualSS","SURE","PerObservation"},{s,v,v/x.size()});
    
}

inline Report stability_frequency(const Mat& x,const Vec& p){
    auto d=validate(x,1,1,64);
    parameters(p,1);
    require(p[0]>.5&&p[0]<=1,"Threshold must be above one half");
    Report o{{"Feature","Frequency","Retained"},{}};
    for(std::size_t j=0;
    j<d;
    ++j){double s=0;
    for(auto&r:x){require(r[j]==0||r[j]==1,"Selection indicator must be binary");
    s+=r[j];
    }double v=s/x.size();
    o.rows.push_back({double(j+1),v,double(v>=p[0])});
    }return o;
    
}
} }
