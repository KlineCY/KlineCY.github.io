一元回归HC3稳健方差

带截距的一元回归帽子矩阵由常数项与中心化解释变量投影组成。HC3把残差除以1减杠杆值，再代入三明治方差公式，对高杠杆点的残差给予更大修正。

$$\hat\beta=S_{xy}/S_{xx},\quad h_i=1/n+(x_i-\bar x)^2/S_{xx}$$
$$\widehat V_{\mathrm{HC3}}(\hat\beta)=S_{xx}^{-2}\sum_i (x_i-\bar x)^2e_i^2/(1-h_i)^2$$

同期资产收益对市场因子回归，斜率0.9、截距0.9、端点杠杆0.7。HC3适用于独立异方差误差，不能替代序列相关下的HAC或聚类估计。

删除一预测残差与PRESS

删除观测对正规方程形成秩一变化，由Sherman–Morrison公式得到留一残差，无需反复拟合。杠杆为1时删除后模型退化。

$$\hat y=Hy,\quad H=X(X^\top X)^{-1}X^\top$$
$$e_{i,(-i)}=e_i/(1-h_{ii}),\quad \mathrm{PRESS}=\sum_i e_{i,(-i)}^2$$

案例首尾留一残差1／3和4／3。横截面模型可据此诊断单个资产影响；时间序列随机留一使用未来数据，不能代替滚动预测。

嵌套回归偏决定系数

在相同观测上拟合嵌套模型，以受限模型剩余平方和衡量新增变量解释比例。F统计量按限制数及剩余自由度缩放，经典分布依赖同方差正态误差。

$$R^2_{\mathrm{partial}}=1-\mathrm{SSE}_U/\mathrm{SSE}_R$$
$$F=\frac{(\mathrm{SSE}_R-\mathrm{SSE}_U)/q}{\mathrm{SSE}_U/(n-k_U)}$$

残差算术案例给定平方和6与1.5，限制数1、参数数3，偏决定系数0.75、F为9。实际研究可检验新增行业因子的联合贡献，输入必须来自真实嵌套拟合。

两变量方差膨胀因子

带截距的两变量模型中辅助回归决定系数等于相关系数平方。条件斜率方差相对正交设计放大VIF倍；完全共线时个别系数无法识别。

$$\rho=S_{xz}/\sqrt{S_{xx}S_{zz}}$$
$$\mathrm{VIF}=(1-\rho^2)^{-1}$$

趋势与动量暴露的重叠诊断：相关系数1／√5，VIF为1.25。标准化不改变VIF；多变量模型需对全部其他解释变量回归。

C++17完整实现

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace applied_linear {
using namespace evidence;
inline Report hc3(const Mat& x,const Vec& p){
    validate(x,3,2,2);
    parameters(p,0);
    double n=x.size(),a=mean(column(x,0)),b=mean(column(x,1)),s=0,c=0;
    for(auto&r:x){s+=(r[0]-a)*(r[0]-a);
    c+=(r[0]-a)*(r[1]-b);
    }positive(s);
    double beta=c/s,alpha=b-beta*a,v=0;
    for(auto&r:x){double d=r[0]-a,e=r[1]-alpha-beta*r[0],h=1/n+d*d/s;
    positive(1-h);
    v+=d*d*e*e/((1-h)*(1-h));
    }return scalar({"Intercept","Slope","HC3SE"},{alpha,beta,std::sqrt(v)/s});
    
}

inline Report press(const Mat& x,const Vec& p){
    validate(x,3,2,2);
    parameters(p,0);
    double n=x.size(),a=mean(column(x,0)),b=mean(column(x,1)),s=0,c=0;
    for(auto&r:x){s+=(r[0]-a)*(r[0]-a);
    c+=(r[0]-a)*(r[1]-b);
    }positive(s);
    double beta=c/s,alpha=b-beta*a;
    Report o{{"Index","Fitted","Residual","Leverage","LOOResidual"},{}};
    for(std::size_t i=0;
    i<x.size();
    ++i){double d=x[i][0]-a,f=alpha+beta*x[i][0],e=x[i][1]-f,h=1/n+d*d/s;
    positive(1-h);
    o.rows.push_back({double(i+1),f,e,h,e/(1-h)});
    }return o;
    
}

inline Report partial_r2(const Mat& x,const Vec& p){
    validate(x,3,2,2);
    parameters(p,2);
    auto q=count(p[0],1,x.size()-1),k=count(p[1],q+1,x.size()-1);
    double a=0,b=0;
    for(auto&r:x){a+=r[0]*r[0];
    b+=r[1]*r[1];
    }positive(a);
    positive(b);
    require(a>=b,"Nested SSE required");
    return scalar({"RestrictedSSE","FullSSE","PartialR2","F"},{a,b,1-b/a,(a-b)/q/(b/(x.size()-k))});
    
}

inline Report vif(const Mat& x,const Vec& p){
    validate(x,3,2,2);
    parameters(p,0);
    double a=mean(column(x,0)),b=mean(column(x,1)),v=0,w=0,c=0;
    for(auto&r:x){double d=r[0]-a,e=r[1]-b;
    v+=d*d;
    w+=e*e;
    c+=d*e;
    }double rho=c/std::sqrt(positive(v)*positive(w)),r2=rho*rho;
    require(1-r2>1e-14,"Collinear regressors");
    return scalar({"Correlation","R2","VIF"},{rho,r2,1/(1-r2)});
    
}
} }
