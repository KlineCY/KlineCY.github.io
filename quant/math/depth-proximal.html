分组稀疏惩罚的块软阈值

数学定义与推导

组间惩罚可分离。对非零组，驻点要求b和z同向，解出范数收缩；在零组，二范数次梯度为单位球，故当原组范数不超过λ时整组归零。不同组必须不重叠；重叠组需不同优化结构。

$$\min_b\frac12\|b-z\|_2^2+\lambda\sum_g\|b_g\|_2$$
$$0=b_g-z_g+\lambda b_g/\|b_g\|\quad(b_g\ne0)$$
$$b_g^*=(1-\lambda/\|z_g\|)_+z_g$$

数值演算与金融应用

组1向量(3,4)，范数5、惩罚2，缩放因子0.6，结果(1.8,2.4)。组2范数1低于惩罚而清零。适用于按经济主题成组选择因子、行业交互项或多任务特征组。

算法复杂度、输入契约与边界

组ID为整数，输入可不排序。复杂度O(n log G)（有序映射），存储O(G)。λ为非负；λ=0时应返回原向量，零范数组保持零。

单线性等式的欧氏投影

数学定义与推导

将等式约束的拉格朗日驻点代回约束，得到唯一乘子。修正量与超平面法向量平行，因此候选点到投影点的方向与可行切空间正交。这里没有盒约束、非负约束或多个线性约束。

$$\min_w\tfrac12\|w-z\|^2\quad\mathrm{s.t.}\ a^\top w=b$$
$$w-z+\eta a=0$$
$$w=z-\frac{a^\top z-b}{a^\top a}a$$

数值演算与金融应用

候选(3,1)、总权重目标1，法向量(1,1)，乘子1.5，投影(1.5,−0.5)。用于去除单一市场beta或预算偏差，投影后的空头是数学允许结果，并非自动满足投资约束。

算法复杂度、输入契约与边界

O(d)时间。法向量非零，目标b与输入单位一致。多约束可用矩阵投影，秩亏时需伪逆并检查可行性；直接连续投影通常不是交集的最短距离。

盒约束预算二次规划及KKT证书

数学定义与推导

目标严格凸。固定预算乘子后各坐标独立最小化，得到截断闭式；总权重随乘子单调不增，可二分求根。KKT要求内点梯度为零、下界梯度非负、上界梯度非正，固定坐标可任意梯度。程序报告违反这些条件的正部。

$$\min_w\sum_i(\tfrac12d_iw_i^2-c_iw_i),\quad l_i\le w_i\le u_i,\quad \sum_iw_i=B$$
$$w_i(\eta)=\operatorname{clip}((c_i-\eta)/d_i,l_i,u_i)$$
$$\sum_iw_i(\eta)=B,\quad g_i=d_iw_i-c_i+\eta$$

数值演算与金融应用

两资产原无约束权重0.7、0.3，第一资产上限0.6，预算1。解0.6、0.4，乘子−0.1，第一资产梯度−0.2满足上界符号。该方法可以作为对角风险近似或分块优化的投影步骤。

算法复杂度、输入契约与边界

必须满足Σl≤B≤Σu、曲率严格正。O(80d)时间，端点预算可能乘子不唯一但权重唯一。若协方差存在非对角项，此逐坐标闭式不再直接成立。

Huber损失的标量近端映射

数学定义与推导

将近端目标按Huber的二次区与线性区求导。二次区候选z/(1+α)须满足|v|≤δ；线性区候选向零移动αδ。边界上两解连续，目标的强凸性保证唯一。

$$h_\delta(v)=\begin{cases}v^2/2&|v|\le\delta\\ \delta|v|-\delta^2/2&|v|>\delta\end{cases}$$
$$\operatorname{prox}_{\alpha h_\delta}(z)=\arg\min_v\{\tfrac12(v-z)^2+\alpha h_\delta(v)\}$$
$$v^*=\begin{cases}z/(1+\alpha)&|z|\le(1+\alpha)\delta\\z-\alpha\delta\operatorname{sign}(z)&\text{otherwise}\end{cases}$$

数值演算与金融应用

α=1、δ=1，输入−3、0.5、3，近端值−2、0.25、2。与平方损失的无限线性梯度不同，Huber对大误差的惩罚梯度有界，可用于稳健残差更新。

算法复杂度、输入契约与边界

独立标量近端的时间O(n)。输入不是完整回归模型；完整Huber回归还需对设计矩阵与残差变量联合优化。α≥0且δ>0，边界及零惩罚均有明确解。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace depth_proximal {
using namespace evidence;
inline Report group_prox(const Mat& x,const Vec& p){
    validate(x,1,2,2);parameters(p,1);require(p[0]>=0,"Negative penalty");
    std::map<double,double> n;
    for(auto&r:x){require(r[0]==std::floor(r[0]),"Integer group required");n[r[0]]=std::hypot(n[r[0]],r[1]);}
    Report o{{"Group","Value","Prox","GroupNorm"},{}};
    for(auto&r:x){double v=n[r[0]],s=v==0?0:std::max(0.,1-p[0]/v);o.rows.push_back({r[0],r[1],s*r[1],v});}
    return o;
}

inline Report affine_projection(const Mat& x,const Vec& p){
    validate(x,1,2,2);parameters(p,1);
    double s=0,t=0;
    for(auto&r:x){s+=r[0]*r[1];t+=r[1]*r[1];}
    double u=(s-p[0])/positive(t);
    Report o{{"Index","Projected","Multiplier"},{}};
    for(std::size_t i=0;i<x.size();++i)o.rows.push_back({double(i+1),x[i][0]-u*x[i][1],u});
    return o;
}

inline Report bounded_budget(const Mat& x,const Vec& p){
    validate(x,1,4,4);parameters(p,1);
    double lsum=0,usum=0,lo=std::numeric_limits<double>::infinity(),hi=-lo;
    for(auto&r:x){
        positive(r[1]);require(r[2]<=r[3],"Invalid bounds");
        lsum+=r[2];usum+=r[3];
        lo=std::min(lo,r[0]-r[1]*r[3]);hi=std::max(hi,r[0]-r[1]*r[2]);
    }
    require(p[0]>=lsum-1e-12&&p[0]<=usum+1e-12,"Infeasible budget");
    auto w=[](const Vec&r,double e){return std::max(r[2],std::min(r[3],(r[0]-e)/r[1]));};
    for(int k=0;k<80;++k){double mid=lo/2+hi/2,s=0;for(auto&r:x)s+=w(r,mid);if(s>p[0])lo=mid;else hi=mid;}
    double eta=lo/2+hi/2;
    Report o{{"Asset","Weight","Multiplier","StationarityGap"},{}};
    for(std::size_t i=0;i<x.size();++i){
        auto&r=x[i];double z=w(r,eta),g=r[1]*z-r[0]+eta;
        double err=r[2]==r[3]?0:z==r[2]?std::max(0.,-g):z==r[3]?std::max(0.,g):std::abs(g);
        o.rows.push_back({double(i+1),z,eta,err});
    }
    return o;
}

inline Report huber_prox(const Mat& x,const Vec& p){
    validate(x,1,1,1);parameters(p,2);require(p[0]>=0,"Negative proximal weight");double d=positive(p[1]),a=p[0];
    Report o{{"Input","Prox","Residual"},{}};
    for(auto&r:x){double z=r[0],v=std::abs(z)<=(1+a)*d?z/(1+a):z-std::copysign(a*d,z);o.rows.push_back({z,v,z-v});}
    return o;
}
