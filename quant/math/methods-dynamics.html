标量Kalman稳态Riccati迭代

模型与推导

线性高斯随机状态预测方差增加过程噪声；增益由最小均方误差确定，Joseph形式的方差更新避免数值负值。输入行只确定更新步数，观测值不参与方差。

$$P_t^-=\phi^2P_{t-1}+Q,\quad K_t=P_t^-/(P_t^-+R)$$
$$P_t=(1-K_t)^2P_t^-+K_t^2R$$

研究应用与成立条件

局部水平模型φ＝1，过程与测量方差均1，初始方差0，三步后方差0.5、0.6、8／13，展示趋向稳态。模型错设会影响滤波可信度。

OU过程精确条件转移矩

模型与推导

积分因子将均值回复SDE化为确定项加Itô积分，后者条件均值0，方差由Itô等距得到。实现使用expm1稳定计算小时间间隔。

$$dX_t=\kappa(\theta-X_t)dt+\sigma dW_t$$
$$\mathbb E[X_{t+h}|X_t=x]=\theta+(x-\theta)e^{-\kappa h},\quad V_h=\frac{\sigma^2}{2\kappa}(1-e^{-2\kappa h})$$

研究应用与成立条件

回复速度ln2、长期均值1、波动2、当前状态3，一期条件均值2，两期1.5。对利差或均值回复价差，参数应以同一时间单位估计；模型允许状态为负。

两状态Markov占用概率

模型与推导

状态1概率由状态0转入及状态1存留两部分相加，形成一阶递推。平稳概率由固定点方程得到，若a、b均正且不同时为1，则收敛。

$$P=\begin{pmatrix}1-a&a\\b&1-b\end{pmatrix},\quad p_{t+1}=a+(1-a-b)p_t$$
$$p_t=\frac a{a+b}+(p_0-\frac a{a+b})(1-a-b)^t$$

研究应用与成立条件

低波动向高波动概率0.2、反向0.4、初始高波动概率1，下一期0.6、两期0.44，长期1／3。状态定义和转移概率应由训练样本估计。

高斯状态空间创新似然

模型与推导

条件观测密度分解为逐期创新密度，联合对数似然为各项相加。标准化创新平方和用于模型拟合诊断；方差必须严格正且来自当期预测而非平滑。

$$\nu_t=y_t-\hat y_{t|t-1},\quad S_t=\operatorname{Var}(\nu_t|\mathcal F_{t-1})$$
$$\ell=-\tfrac12\sum_t[\log(2\pi S_t)+\nu_t^2/S_t]$$

研究应用与成立条件

创新0、2和方差1、4的标准化平方和1。可比较状态空间模型，但必须在相同观测及初始化约定下比较，训练似然不代表样本外表现。

C++17实现

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace methods_dynamics {
using namespace evidence;
inline Report scalar_riccati(const Mat& x,const Vec& p){
    validate(x,1,1,1);
    parameters(p,4);
    double phi=p[0],q=positive(p[1]),r=positive(p[2]),v=p[3];
    require(v>=0,"Negative initial variance");
    Report o{{"Time","PredictionVariance","Gain","PosteriorVariance"},{}};
    for(std::size_t i=0;
    i<x.size();
    ++i){double a=phi*phi*v+q,k=a/(a+r);
    v=(1-k)*(1-k)*a+k*k*r;
    o.rows.push_back({double(i+1),a,k,v});
    }return o;
    
}

inline Report ou_transition(const Mat& x,const Vec& p){
    validate(x,1,1,1);
    parameters(p,4);
    double k=positive(p[0]),theta=p[1],s=positive(p[2]),z=p[3];
    Report o{{"Horizon","Mean","Variance"},{}};
    for(auto&r:x){require(r[0]>=0,"Negative horizon");
    o.rows.push_back({r[0],theta+(z-theta)*std::exp(-k*r[0]),-s*s*std::expm1(-2*k*r[0])/(2*k)});
    }return o;
    
}

inline Report markov_occupation(const Mat& x,const Vec& p){
    validate(x,1,1,1);
    parameters(p,3);
    double a=p[0],b=p[1],z=p[2];
    require(a>=0&&a<=1&&b>=0&&b<=1&&a+b>0&&z>=0&&z<=1,"Invalid transition or initial probability");
    double s=a/(a+b);
    Report o{{"Horizon","StateOne","StationaryOne"},{}};
    for(auto&r:x){auto h=count(r[0],0,1000000);
    o.rows.push_back({double(h),s+(z-s)*std::pow(1-a-b,double(h)),s});
    }return o;
    
}

inline Report innovation_likelihood(const Mat& x,const Vec& p){
    validate(x,1,2,2);
    parameters(p,0);
    double l=0,s=0;
    for(auto&r:x){double v=positive(r[1]),q=r[0]*r[0]/v;
    s+=q;
    l-=.5*(std::log(2*std::acos(-1.))+std::log(v)+q);
    }return scalar({"LogLikelihood","StandardizedSS"},{l,s});
    
}
} }
