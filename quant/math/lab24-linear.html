1．修正Gram–Schmidt薄QR最小二乘

模型结构与数学定义

以逐列正交化构造薄QR分解，对剩余列进行两次投影以减轻正交性损失，再以逆序三角回代求系数。相比直接形成正规方程，QR避免将设计矩阵的条件数平方。输入前三列分别是两个解释变量及响应；截距由常数列显式传入。输出两个回归系数与残差平方和。

$$X=QR,\quad R\widehat\beta=Q^\top y$$

推导、最优性条件与数值结构

$$\|y-X\beta\|_2^2=\|Q^\top y-R\beta\|_2^2+\|(I-QQ^\top)y\|_2^2$$

将最小化问题在正交子空间及其正交补中分解。正交补项与β无关，故只需令三角系统的残差为零。程序的两次正交化是在同一列上重新投影，数学上与修正Gram–Schmidt一致，并非Householder反射。

完整计算案例

两列完全正交的设计矩阵使投影系数可直接由内积求出；给定响应为两个解释变量的线性组合，理论残差为零。

$$\mathrm{Output}\approx\left(2,\ 3,\ 0\right)$$

输出顺序：回归系数1、回归系数2、残差平方和。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

2．对称矩阵的Jacobi特征分解

模型结构与数学定义

二维对称矩阵的特征根由特征多项式的两个实根得到。最大特征向量沿旋转角θ的一阶轴排列，其中2θ的正弦、余弦方向由非对角项和对角差共同决定。输出两个特征值、第一特征向量的两个坐标以及两根之差。

$$A=\begin{pmatrix}a&b\\b&d\end{pmatrix},\quad \lambda_\pm=\tfrac12(a+d)\pm\sqrt{((a-d)/2)^2+b^2}$$

推导、最优性条件与数值结构

$$\det(A-\lambda I)=(a-\lambda)(d-\lambda)-b^2=0,\qquad \tan(2\theta)=\frac{2b}{a-d}$$

特征多项式的判别式非负。用atan2确定象限，即使对角差为零也能避免直接除零；当特征值重合时，任意正交旋转都满足分解。

完整计算案例

矩阵[[2,1],[1,2]]的主轴是45度方向，特征根为3、1，主特征向量两个坐标均为1/√2。

$$\mathrm{Output}\approx\left(3,\ 1,\ 0.707106781,\ 0.707106781,\ 2\right)$$

输出顺序：最大特征值、最小特征值、主特征向量第一分量、第二分量、谱间距。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

3．中心化双因子Ridge回归与有效自由度

模型结构与数学定义

以样本均值去除截距影响，在二维Gram矩阵上加入正则项；解析逆矩阵求两项斜率，随后恢复未受惩罚的截距。利用迹恒等式计算斜率的有效自由度并加上截距的一维。参数λ以未除以样本量的残差平方和为目标尺度。

$$\widehat\beta=(X_c^\top X_c+\lambda I)^{-1}X_c^\top y_c,\quad d_{\rm eff}=1+\operatorname{tr}[(G+\lambda I)^{-1}G]$$

推导、最优性条件与数值结构

$$\min_{\beta_0,\beta}\|y-\beta_0\mathbf1-X\beta\|^2+\lambda\|\beta\|^2,\quad \beta_0=\bar y-\bar x^\top\beta$$

截距的一阶条件给出均值关系。代入后目标只含中心化样本，斜率正规方程中的λI对应二次惩罚；帽子矩阵的迹表征拟合复杂度。

完整计算案例

四行设计为两个相互正交的±1变量，响应为2X1+4X2；λ=4时两斜率缩半为1、2，截距为0，有效自由度为2。

$$\mathrm{Output}\approx\left(0,\ 1,\ 2,\ 2\right)$$

输出顺序：截距、斜率1、斜率2、含截距有效自由度。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

4．Sherman–Morrison秩一协方差更新

模型结构与数学定义

在单位基准协方差中加入一项公共因子的秩一冲击；利用Sherman–Morrison公式计算逆矩阵作用于右端向量，无需构造稠密矩阵。每行是因子载荷与目标向量的对应维度，返回完整解向量。

$$(I+\gamma uu^\top)^{-1}b=b-\frac{\gamma u(u^\top b)}{1+\gamma u^\top u}$$

推导、最优性条件与数值结构

$$(I+\gamma uu^\top)\left(b-\frac{\gamma u(u^\top b)}{1+\gamma u^\top u}\right)=b$$

直接左乘验证恒等式，所有与u平行的增量相互抵消。复杂度仅与向量长度线性相关，可用于对单位基准协方差的单因子压力调整。

完整计算案例

载荷u=(1,1)，右端b=(3,1)，γ=1时分母为3、内积为4，解为(5/3,−1/3)。

$$\mathrm{Output}\approx\left(1.66666667,\ -0.333333333\right)$$

输出顺序：线性系统解的各坐标。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

5．三维协方差矩阵幂迭代与残差证书

模型结构与数学定义

从全一归一化初值开始，交替进行矩阵向量乘法和归一化。在对称正定且主特征方向具有非零初始投影的前提下，迭代逐渐集中于主特征方向；Rayleigh商估计特征值，残差范数衡量所得近似特征对是否满足方程。返回特征值、残差。

$$v_{k+1}=\frac{Av_k}{\|Av_k\|_2},\quad \lambda=v^\top Av,\quad e=\|Av-\lambda v\|_2$$

推导、最优性条件与数值结构

$$A^kv_0=\sum_jc_j\lambda_j^k e_j,\qquad |\lambda_j/\lambda_1|^k\to0\ (j>1)$$

若最大特征值严格大于其他特征值且对应初始系数非零，反复乘矩阵后其余方向的相对分量指数衰减。残差证书只检验当前特征对。

完整计算案例

对角矩阵diag(4,2,1)，40次迭代后主特征值趋近4，特征残差趋近零。

$$\mathrm{Output}\approx\left(4,\ 0\right)$$

输出顺序：Rayleigh商、特征残差的二范数。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

#pragma once
#include "lab24_common.hpp"
#include <functional>

namespace kline { namespace lab24 {
inline Vec qr_solve(const Mat& x,const Vec& p){
    inputs(x,p,3,0,2);
    Vec a=col(x,0),b=col(x,1),y=col(x,2);
    double r11=positive(std::sqrt(dot(a,a)));
    for(double& z:a)z/=r11;
    double r12=dot(a,b),b0=std::sqrt(dot(b,b));
    for(std::size_t i=0;i<b.size();++i)b[i]-=r12*a[i];
    double corr=dot(a,b);r12+=corr;
    for(std::size_t i=0;i<b.size();++i)b[i]-=corr*a[i];
    double r22=std::sqrt(dot(b,b));
    require(r22>1e-12*b0&&r22>0,"Rank-deficient design");
    for(double& z:b)z/=r22;
    double v=dot(b,y)/r22,u=(dot(a,y)-r12*v)/r11,sse=0;
    for(const auto& row:x){double e=row[2]-row[0]*u-row[1]*v;sse+=e*e;}
    return checked({u,v,sse});
}

inline Vec spectral2(const Mat& x,const Vec& p){
    inputs(x,p,2,0,2);require(x.size()==2,"A 2 by 2 matrix is required");
    require(std::abs(x[0][1]-x[1][0])<=1e-12*std::max(1.0,std::abs(x[0][1])),"Matrix must be symmetric");
    double a=x[0][0],b=x[0][1],d=x[1][1];
    double mid=0.5*a+0.5*d,gap=std::hypot(0.5*a-0.5*d,b);
    double theta=0.5*std::atan2(b,0.5*a-0.5*d);
    return checked({mid+gap,mid-gap,std::cos(theta),std::sin(theta),2*gap});
}

inline Vec ridge2(const Mat& x,const Vec& p){
    inputs(x,p,3,1,2);double l=positive(p[0]);
    double m1=mean(col(x,0)),m2=mean(col(x,1)),my=mean(col(x,2));
    double a=0,b=0,d=0,u=0,v=0;
    for(const auto& r:x){
        double q=r[0]-m1,s=r[1]-m2,t=r[2]-my;
        a+=q*q;b+=q*s;d+=s*s;u+=q*t;v+=s*t;
    }
    double aa=a+l,dd=d+l,det=positive(aa*dd-b*b);
    double c1=(dd*u-b*v)/det,c2=(aa*v-b*u)/det;
    double df=1+(dd*a+aa*d-2*b*b)/det;
    return checked({my-c1*m1-c2*m2,c1,c2,df});
}

inline Vec woodbury_rank1(const Mat& x,const Vec& p){
    inputs(x,p,2,1);require(p[0]>=0,"Rank-one variance must be nonnegative");
    Vec u=col(x,0),b=col(x,1);
    double scale=p[0]*dot(u,b)/positive(1+p[0]*dot(u,u));
    for(std::size_t i=0;i<b.size();++i)b[i]-=scale*u[i];
    return checked(b);
}

inline Vec power_iteration(const Mat& x,const Vec& p){
    inputs(x,p,3,1,3);require(x.size()==3,"A 3 by 3 matrix is required");
    for(std::size_t i=0;i<3;++i)for(std::size_t j=0;j<3;++j)
        require(std::abs(x[i][j]-x[j][i])<1e-12,"Symmetric matrix required");
    require(x[0][0]>0&&x[0][0]*x[1][1]-x[0][1]*x[0][1]>0,"Positive leading minors required");
    double det=x[0][0]*(x[1][1]*x[2][2]-x[1][2]*x[2][1])-x[0][1]*(x[1][0]*x[2][2]-x[1][2]*x[2][0])+x[0][2]*(x[1][0]*x[2][1]-x[1][1]*x[2][0]);
    positive(det);
    auto multiply=[&](const Vec& v){Vec z;for(const auto& r:x)z.push_back(dot(r,v));return z;};
    Vec v(3,1/std::sqrt(3.0));auto steps=integer(p[0],1,10000);
    for(std::size_t k=0;k<steps;++k){v=multiply(v);double n=positive(std::sqrt(dot(v,v)));for(double& q:v)q/=n;}
    Vec a=multiply(v);double lambda=dot(v,a);for(std::size_t i=0;i<3;++i)a[i]-=lambda*v[i];
    return checked({lambda,std::sqrt(dot(a,a))});
}

namespace kline { namespace lab24 {
using Vec=std::vector<double>;
using Mat=std::vector<Vec>;

inline void inputs(const Mat& x,const Vec& p,std::size_t cols,std::size_t params,
                   std::size_t min_rows=1) {
    require(x.size()>=min_rows&&x.size()<=250000,"Invalid number of observations");
    require(p.size()==params,"Incorrect scalar parameter count");
    for(double v:p)require(std::isfinite(v),"Nonfinite scalar parameter");
    for(const auto& row:x){
        require(row.size()==cols,"Unexpected CSV column count");
        for(double v:row)require(std::isfinite(v),"Nonfinite matrix entry");
    }
}
inline std::size_t integer(double x,std::size_t low,std::size_t high){
    require(std::isfinite(x)&&x>=double(low)&&x<=double(high)&&std::floor(x)==x,
            "Integer parameter outside allowed range");
    return std::size_t(x);
}
inline double dot(const Vec& a,const Vec& b){
    require(a.size()==b.size(),"Dot product dimension mismatch");
    return std::inner_product(a.begin(),a.end(),b.begin(),0.0);
}
inline Vec col(const Mat& x,std::size_t j){
    Vec out;out.reserve(x.size());
    for(const auto& row:x)out.push_back(row.at(j));
    return out;
}
inline double positive(double x){require(x>0&&std::isfinite(x),"Positive finite quantity required");return x;}
inline Vec checked(Vec v){check_finite(v);return v;}
inline double logistic(double x){
    if(x>=0)return 1/(1+std::exp(-x));
    double e=std::exp(x);return e/(1+e);
}
inline double normal_cdf(double x){return 0.5*std::erfc(-x/std::sqrt(2.0));}
inline double sum(const Vec& v){return std::accumulate(v.begin(),v.end(),0.0);}
