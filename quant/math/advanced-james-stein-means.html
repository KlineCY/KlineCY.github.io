正部James–Stein估计：多资产均值收缩与平方损失

高级研究方法　完整模型源码　公共数值函数

模型定义与识别条件

在独立、等方差、已知方差的正态均值估计中，维数至少3时，普通样本均值在联合平方损失下可被收缩估计改进。James–Stein把向量整体向事先固定目标m收缩；其风险性质是对联合损失的结论，不保证每一个坐标或每一个有限样本都改善。

数学推导与求解机制

收缩强度由估计向量与目标的平方距离决定；正部版本在距离过小时将系数截断为0。输入方差是每个均值估计量的方差，不是单期收益方差。目标为输入给定的共同固定标量，不能将由同一观测估计的目标直接套用d−2公式。

$$Y\sim N_d(\theta,\sigma^2I),\quad d\ge3$$
$$\widehat\theta_{\mathrm{JS}+}=m+\left(1-\frac{(d-2)\sigma^2}{\|Y-m\|^2}\right)_+(Y-m)$$
$$R(\theta,\delta)=\mathbb E_\theta\|\delta(Y)-\theta\|^2$$
$$R(\theta,Y)=d\sigma^2$$

独立解析基准

例Y=(1,2,3)、方差1、目标0，距离14，d=3，乘数13/14，输出每项收缩值。若目标距离为0，直接返回目标并报告乘数0。

计算复杂度与研究边界

O(d)，d至少3。多资产收益估计常有不等方差和相关性，原始Stein风险结论不能直接推广；可先建立适合的协方差模型或使用经验Bayes方法，并通过训练期预测及独立样本检查。

C++17完整实现

inline Report james_stein_means(const Mat& x,const Vec& p){
    validate(x,3,1,1);parameters(p,2);double v=positive(p[0]),target=p[1],dist=0;
    for(auto&r:x)dist+=(r[0]-target)*(r[0]-target);
    double a=dist==0?0:std::max(0.,1-(x.size()-2)*v/dist);
    Report o{{"Index","RawEstimate","ShrunkEstimate","ShrinkMultiplier","RawSquaredDistance","KnownVariance"},{}};
    for(std::size_t j=0;j<x.size();++j)o.rows.push_back({double(j+1),x[j][0],target+a*(x[j][0]-target),a,dist,v});
    return o;
}
