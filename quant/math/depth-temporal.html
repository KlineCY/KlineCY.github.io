AR(1)冲击响应与累计乘数

数学定义与推导

将AR(1)反复代入，当前一次单位创新对未来水平的影响按φ的幂衰减。累计响应是有限几何级数，平稳条件|φ|<1保证长期乘数有限。负φ使响应交替符号，不能只以绝对值描述动态。

$$x_t=\phi x_{t-1}+\varepsilon_t$$
$$\psi_h=\partial x_{t+h}/\partial\varepsilon_t=\phi^h$$
$$\sum_{j=0}^{h}\psi_j=\frac{1-\phi^{h+1}}{1-\phi}$$

数值演算与金融应用

φ=0.5时冲击从1降至0.5、0.25，三时点累计1.75，长期2。可分析风险溢价、利差或流动性冲击的持续性，但相关创新不自动具有结构因果解释。

算法复杂度、输入契约与边界

O(n)时间，h为非负整数；使用闭式，φ接近1时存在相消，极端参数可用递推或更高精度。此处为单位创新的理论响应，不是实现收益路径。

AR(1)条件预测误差方差

数学定义与推导

条件预测仅未知未来创新，历史状态已知。独立同方差创新的交叉项消失，预测误差方差等于创新方差乘平方系数和。该量描述单个未来水平的预测误差，与累积多个未来收益的方差不同。

$$x_{t+h}-\mathbb E_t x_{t+h}=\sum_{j=0}^{h-1}\phi^j\varepsilon_{t+h-j}$$
$$V_h=\sigma_\varepsilon^2\sum_{j=0}^{h-1}\phi^{2j}$$
$$V_\infty=\sigma_\varepsilon^2/(1-\phi^2)$$

数值演算与金融应用

φ=0.5、创新方差2，预测误差方差由2增至2.5和2.625，极限8/3。用于确定预测区间宽度的动态部分，若估计参数不确定或创新厚尾，简单正态区间并不充分。

算法复杂度、输入契约与边界

O(n)闭式。要求|φ|<1、创新方差正、预测期限≥1；以expm1稳定计算接近单位根的几何和。模型假设创新独立或至少条件不相关。

有限冲击响应滤波器的频率增益

数学定义与推导

复指数是线性时不变滤波器的特征函数，输入e^{iωt}经过滤波只改变复振幅。对平稳输入，频谱按增益平方缩放，因而移动平均往往抑制高频但引入相位延迟。这里不使用未来数据，系数顺序从当前到更早。

$$y_t=\sum_{j=0}^{m-1}a_jx_{t-j}$$
$$H(\omega)=\sum_{j=0}^{m-1}a_je^{-i\omega j}$$
$$S_y(\omega)=|H(\omega)|^2S_x(\omega)$$

数值演算与金融应用

两点平均a0=a1=0.5，在ω=π时两项相消，增益0；在ω=0时增益1。用于研究平滑后的信号响应，不把低噪声直接等同于更强的收益预测。

算法复杂度、输入契约与边界

O(m)，ω以弧度/样本计，限定[0,π]；周期采样不等距时应重建时间轴。浮点π的高频相消可能留下极小残差。

滞后交叉协方差的共同样本口径

数学定义与推导

定义正滞后为X当前与Y未来配对，每个滞后采用其自身共同样本均值和总体型分母。不同文献可能固定全样本均值或使用n分母，数值不完全相同，必须事先固定口径。

$$C_{XY}(h)=\operatorname{Cov}(X_t,Y_{t+h})$$
$$\bar x_h=(n-h)^{-1}\sum_{t=1}^{n-h}x_t,\quad \bar y_h=(n-h)^{-1}\sum_{t=1}^{n-h}y_{t+h}$$
$$\widehat C(h)=(n-h)^{-1}\sum_{t=1}^{n-h}(x_t-\bar x_h)(y_{t+h}-\bar y_h)$$

数值演算与金融应用

X为1、2、3，Y为0、1、2，h=1时匹配(1,1)、(2,2)，均值均1.5，协方差0.25。用于信号和未来收益的对齐诊断；相关不是可交易性，标签重叠与交易成本仍需处理。

算法复杂度、输入契约与边界

O(n)两遍，非负整数滞后且至少两对。数据按共同时间轴排序，不能将有缺口的行索引当固定交易时间；检查负滞后可交换列。

C++17完整实现

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace depth_temporal {
using namespace evidence;
inline Report ar_impulse(const Mat& x,const Vec& p){
    validate(x,1,1,1);parameters(p,1);double a=p[0];require(std::abs(a)<1,"Stationary AR required");Report o{{"Horizon","Impulse","Cumulative"},{}};
    for(auto&r:x){auto h=count(r[0],0,1000000);double z=std::pow(a,double(h));o.rows.push_back({double(h),z,(1-std::pow(a,double(h+1)))/(1-a)});}return o;
}

inline Report ar_forecast_variance(const Mat& x,const Vec& p){
    validate(x,1,1,1);parameters(p,2);double a=p[0],v=positive(p[1]);require(std::abs(a)<1,"Stationary AR required");double z=a*a,L=v/(1-z);Report o{{"Horizon","ForecastErrorVariance","LongRunVariance"},{}};
    for(auto&r:x){auto h=count(r[0],1,1000000);double q=z==0?1:-std::expm1(h*std::log(z));o.rows.push_back({double(h),L*q,L});}return o;
}

inline Report filter_frequency(const Mat& x,const Vec& p){
    validate(x,1,1,1);parameters(p,1);double w=p[0];require(w>=0&&w<=std::acos(-1.),"Frequency outside Nyquist interval");double a=0,b=0;
    for(std::size_t j=0;j<x.size();++j){a+=x[j][0]*std::cos(w*j);b-=x[j][0]*std::sin(w*j);}
    double v=std::hypot(a,b);return scalar({"Frequency","Real","Imag","Gain","GainSquared"},{w,a,b,v,v*v});
}

inline Report lag_aligned_cov(const Mat& x,const Vec& p){
    validate(x,2,2,2);parameters(p,1);auto h=count(p[0],0,x.size()-2),n=x.size()-h;double a=0,b=0;
    for(std::size_t i=0;i<n;++i){a+=x[i][0]/n;b+=x[i+h][1]/n;}double c=0;
    for(std::size_t i=0;i<n;++i)c+=(x[i][0]-a)*(x[i+h][1]-b)/n;
    return scalar({"Lag","Pairs","MeanX","MeanY","Covariance"},{double(h),double(n),a,b,c});
}
} }
