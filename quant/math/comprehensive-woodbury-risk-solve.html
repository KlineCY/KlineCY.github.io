低秩结构

风险模型常将协方差表示为正的特异风险对角矩阵和少数公共因子的外积。令B为已包含因子协方差平方根的加载矩阵，则不需要假定因子本身方差为1；只需特异风险严格正。对资产数远大于因子数的情形，直接求逆整个协方差矩阵会浪费结构。

$$\Sigma=D+BB^\top,\qquad D=\operatorname{diag}(d_1,\ldots,d_n),\quad d_i>0$$

Woodbury推导

令z=B^ op x。由(D+BB^ op)x=y得到x=D^{-1}(y-Bz)，代回z方程，因子维度的系统为(I+B^ op D^{-1}B)z=B^ op D^{-1}y。该系统对称正定，使用Cholesky求解；无需形成n×n矩阵。

$$K=I+B^\top D^{-1}B,\quad \Sigma^{-1}y=D^{-1}y-D^{-1}BK^{-1}B^\top D^{-1}y$$

行列式与证书

矩阵行列式引理使对数行列式分解为特异方差之和及小型因子系统的对数行列式。二次型y'Σ^{-1}y是Mahalanobis距离或精度风险计算的重要组成。使用加载矩阵直接回代原始方程，不通过再次求逆来检查误差。

$$\log|\Sigma|=\sum_i\log d_i+\log|K|,\quad \log|K|=2\sum_j\log L_{jj},\quad \|\Sigma x-y\|_\infty$$

数值例与规模

例中Σ=(3,2;2,7)，行列式17，右端(1,2)，解(3/17,4/17)，二次型11/17。实际时间O(nk²+k³)，存储O(nk+k²)。当因子数接近资产数时优势消失，极小特异风险仍可能导致消减误差，应同时查看原始残差及条件数。

$$y^\top\Sigma^{-1}y=\sum_i y_ix_i$$

C++17完整实现

inline Report woodbury_risk_solve(const Mat& x,const Vec& p){
    auto k=validate(x,1,3,34)-2,n=x.size();
    parameters(p,0);
    require(double(n)*k*k<=5e7,"Factor solve work limit");
    Mat K=identity(k);
    Vec rhs(k,0),base(n),diag(n);
    double ld=0;
    for(std::size_t i=0;i<n;++i){
        diag[i]=positive(x[i][0]);base[i]=x[i].back()/diag[i];ld+=std::log(diag[i]);
        Vec b(x[i].begin()+1,x[i].end()-1);
        add_outer(K,b,1/diag[i]);
        for(std::size_t j=0;j<k;++j)rhs[j]+=b[j]*base[i];
    }
    Vec z=solve_spd(K,rhs),w(n),btx(k,0);
    Mat L(k,Vec(k,0));
    for(std::size_t i=0;i<k;++i)for(std::size_t j=0;j<=i;++j){
        double v=K[i][j];for(std::size_t h=0;h<j;++h)v-=L[i][h]*L[j][h];
        L[i][j]=i==j?std::sqrt(positive(v)):v/L[j][j];
        if(i==j)ld+=2*std::log(L[i][j]);
    }
    double quad=0,err=0;
    for(std::size_t i=0;i<n;++i){
        Vec b(x[i].begin()+1,x[i].end()-1);
        w[i]=base[i]-dot(b,z)/diag[i];
        quad+=x[i].back()*w[i];
        for(std::size_t j=0;j<k;++j)btx[j]+=b[j]*w[i];
    }
    for(std::size_t i=0;i<n;++i){
        Vec b(x[i].begin()+1,x[i].end()-1);
        err=std::max(err,std::abs(diag[i]*w[i]+dot(b,btx)-x[i].back()));
    }
    Report out{{"Asset","Solution","LogDet","QuadraticForm","Residual"},{}};
    for(std::size_t i=0;i<n;++i)out.rows.push_back({double(i+1),w[i],ld,quad,err});
    return out;
}
