从函数值到正交基

多项式拟合在等距高阶节点上容易产生Runge振荡。Chebyshev节点在区间两端密集，对解析函数可获得良好逼近。这里输入是按余弦节点顺序采样的函数值，区间已归一化到[−1,1]；若原始变量有不同范围，应先做仿射变换。

$$x_j=\cos\theta_j,\quad\theta_j=\pi(j+1/2)/n,\quad T_k(\cos\theta)=\cos(k\theta)$$

离散余弦系数

在n个Chebyshev根节点上，余弦列正交。将函数值投影得到系数，其中常数项使用1/n，其余项使用2/n。所有系数均来自节点值，不在测试点重新拟合。系数的衰减可用于观察逼近难度，但有限样本中不能直接证明区间外误差。

$$c_0=\frac1n\sum_jf_j,\quad c_k=\frac2n\sum_jf_j\cos(k\theta_j),\quad p(x)=\sum_{k=0}^{n-1}c_kT_k(x)$$

稳定求值

Clenshaw反向递推避免逐项计算高阶幂或显式三角反函数，对区间内多项式求值具有良好数值性质。用末端的b1,b2重构值。由于采用完整n个系数，理想算术下在输入节点插值；含噪数据不应盲目采用全阶，而应独立选择截断或正则化。

$$b_k=c_k+2xb_{k+1}-b_{k+2},\quad b_n=b_{n+1}=0,\quad p(x)=c_0+xb_1-b_2$$

可复算例与复杂度

对f(x)=1+2x的三节点采样，系数(1,2,0)，查询−1、0、1得−1、1、3。独立实验以低阶多项式及光滑函数比较节点和非节点误差。计算O(n²+nq)，最多128节点；大规模可使用FFT或DCT算法。

$$\max_{x\in[-1,1]}|f(x)-p(x)|\quad\text{and}\quad\sum_{k\ge m}|c_k|$$

C++17完整实现

inline Report chebyshev_interpolant(const Mat& x,const Vec& p){
    validate(x,2,1,1);auto n=x.size();
    require(n<=128&&!p.empty()&&double(n)*p.size()<=5e7,"Chebyshev work limit");
    parameters(p,p.size());
    Vec c(n,0);
    const double pi=std::acos(-1.);
    for(std::size_t k=0;k<n;++k){
        for(std::size_t j=0;j<n;++j)c[k]+=x[j][0]*std::cos(pi*k*(j+.5)/n);
        c[k]*=(k==0?1.:2.)/n;
    }
    Report out{{"Query","Approximation"},{}};
    for(std::size_t k=0;k<n;++k)out.header.push_back("Coefficient"+std::to_string(k));
    for(double z:p){
        require(z>=-1&&z<=1,"Chebyshev query outside support");
        double b1=0,b2=0;
        for(std::size_t k=n;k-->1;){
            double b=c[k]+2*z*b1-b2;b2=b1;b1=b;
        }
        Vec row{z,c[0]+z*b1-b2};row.insert(row.end(),c.begin(),c.end());out.rows.push_back(row);
    }
    return out;
}
