重要性权重的有效样本量

模型与推导

归一化权重集中度的倒数给出Kish有效样本量，Cauchy–Schwarz保证上界n。权重相等达到n，单个非零权重达到1；不等同于自相关调整有效样本量。

$$\tilde w_i=w_i/\sum_jw_j,\qquad n_{\mathrm{eff}}=(\sum_i\tilde w_i^2)^{-1}$$
$$1\le n_{\mathrm{eff}}\le n$$

研究应用与成立条件

跨市场分布迁移权重1、2、3，有效样本约2.57，最大权重0.5。极端权重提示方差问题；裁剪会改变目标分布，必须记录。

分层总体均值及抽样方差

模型与推导

各层独立简单随机不放回，层均值估计无偏，方差按总体比例平方加权并乘有限总体修正。输入层总体量、样本量、样本均值与样本方差。

$$\hat\mu=\sum_h W_h\bar y_h,\quad W_h=N_h/\sum_jN_j$$
$$\widehat V(\hat\mu)=\sum_h W_h^2(1-n_h/N_h)s_h^2/n_h$$

研究应用与成立条件

两层权重0.25及0.75，均值5。若对不等层直接等权，估计对象改变；样本应按设计随机抽取，不适用于任意金融观察样本的因果解释。

分块Median-of-Means稳健均值

模型与推导

先将数据划分成等大块计算均值，再对块均值取中位数。独立有限方差情形可通过Chebyshev与二项尾界获得稳健集中；分块数量和依赖会影响理论。

$$\bar X_b=|B_b|^{-1}\sum_{i\in B_b}X_i,\quad \hat\mu_{\mathrm{MoM}}=\operatorname{median}_b\bar X_b$$
$$\Pr(|\hat\mu_{\mathrm{MoM}}-\mu|>\epsilon)\leq\Pr(\text{at least half the block means fail})$$

研究应用与成立条件

三块均值1、2、100，MoM为2，普通均值约34.33。用于重尾收益均值的稳健诊断；时间序列依赖需按块结构设计，不能任意打乱。

自归一化重要性抽样与比率误差

模型与推导

将加权均值写为两个样本均值之比，Delta方法的一阶影响量与w_i(f_i−μ)成比例。代码用有限样本修正计算估计误差，并同时报告权重集中度。

$$\hat\mu=\frac{\sum_iw_i f_i}{\sum_iw_i}$$
$$\widehat{\mathrm{se}}^2=\frac{n}{n-1}\sum_i\tilde w_i^2(f_i-\hat\mu)^2$$

研究应用与成立条件

权重1、3，对应值1、3，估计2.5，有效样本1.6。比率估计有限样本有偏，Delta近似需要独立样本和有限二阶矩，极端权重时不可机械依赖正态区间。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace methods_sampling {
using namespace evidence;
inline Report weighted_effective_n(const Mat& x,const Vec& p){
    validate(x,1,1,1);
    parameters(p,0);
    double s=0,m=0;
    for(auto&r:x){require(r[0]>=0,"Negative weight");
    s+=r[0];
    m=std::max(m,r[0]);
    }positive(s);
    double q=0;
    for(auto&r:x){double v=r[0]/s;
    q+=v*v;
    }return scalar({"SumWeight","EffectiveN","MaxNormalized"},{s,1/q,m/s});
    
}

inline Report stratified_mean(const Mat& x,const Vec& p){
    validate(x,1,4,4);
    parameters(p,0);
    double N=0;
    for(auto&r:x){count(r[0],2,1000000000);
    count(r[1],2,std::size_t(r[0]));
    require(r[3]>=0,"Negative sample variance");
    N+=r[0];
    }double a=0,v=0;
    for(auto&r:x){double w=r[0]/N;
    a+=w*r[2];
    v+=w*w*(1-r[1]/r[0])*r[3]/r[1];
    }return scalar({"Estimate","Variance","SE"},{a,v,std::sqrt(v)});
    
}

inline Report median_of_means(const Mat& x,const Vec& p){
    validate(x,2,1,1);
    parameters(p,1);
    auto B=count(p[0],1,x.size());
    require(x.size()%B==0,"Equal block lengths required");
    auto n=x.size()/B;
    Vec v(B,0);
    double s=0;
    for(std::size_t i=0;
    i<x.size();
    ++i){v[i/n]+=x[i][0]/n;
    s+=x[i][0];
    }std::sort(v.begin(),v.end());
    double med=(v[(B-1)/2]+v[B/2])/2;
    return scalar({"Blocks","RobustMean","OrdinaryMean"},{double(B),med,s/x.size()});
    
}

inline Report self_normalized_is(const Mat& x,const Vec& p){
    validate(x,2,2,2);
    parameters(p,0);
    double s=0,a=0;
    for(auto&r:x){require(r[0]>=0,"Negative weight");
    s+=r[0];
    a+=r[0]*r[1];
    }double m=a/positive(s),q=0,v=0;
    for(auto&r:x){double w=r[0]/s;
    q+=w*w;
    v+=w*w*(r[1]-m)*(r[1]-m);
    }return scalar({"Estimate","EffectiveN","DeltaSE"},{m,1/q,std::sqrt(v*x.size()/(x.size()-1))});
    
}
