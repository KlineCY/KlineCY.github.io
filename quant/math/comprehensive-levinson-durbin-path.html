线性预测与Toeplitz结构

平稳中心化序列的最优线性一步预测由自协方差确定，p阶Yule–Walker系统的矩阵元素依赖滞后差。逐阶重新解密集系统需要重复大量运算。Levinson–Durbin递推把上一阶系数和预测误差方差扩展到下一阶，反射系数同时给出偏自相关。

$$\Gamma_p\phi^{(p)}=\gamma_{1:p},\quad(\Gamma_p)_{ij}=\gamma_{|i-j|}$$

递推推导

从v0=γ0开始，新滞后系数用剩余协方差除以上一阶创新方差。原有系数按逆序反射项调整，创新方差乘1−κ²。每步必须满足|κ|<1及正创新方差，这与扩展Toeplitz正定性相联系；非正定输入不应通过截断负方差掩盖。

$$\kappa_p=\frac{\gamma_p-\sum_{j=1}^{p-1}\phi^{(p-1)}_j\gamma_{p-j}}{v_{p-1}},\quad \phi_j^{(p)}=\phi_j^{(p-1)}-\kappa_p\phi_{p-j}^{(p-1)},\quad v_p=v_{p-1}(1-\kappa_p^2)$$

独立残差

程序输出每阶所有系数及共同创新方差、反射系数，并重新以原始协方差回代Yule–Walker方程。递推本身O(P²)，完整逐阶残差审计为O(P³)。创新方差是指定线性预测空间下的均方误差，而不是自动等同于真实条件方差。

$$v_p=\gamma_0-(\phi^{(p)})^\top\gamma_{1:p},\qquad r_p=\|\Gamma_p\phi^{(p)}-\gamma_{1:p}\|_\infty$$

参考与边界

γ0=1、γ1=0.5、γ2=0.25来自理论AR(1)协方差。第一阶系数0.5、创新方差0.75，第二反射系数0，额外滞后不改善线性预测。估计样本协方差时应固定一致分母或检查Toeplitz正定性；样本PACF波动不等同真实模型阶数。

$$\gamma_k=\gamma_0\rho^{|k|}\Longrightarrow\phi^{(p)}=(\rho,0,\ldots,0)$$

inline Report levinson_durbin_path(const Mat& x,const Vec& p){
    validate(x,2,1,1);parameters(p,1);auto P=count(p[0],1,std::min<std::size_t>(x.size()-1,256));
    Vec gamma=column(x,0),phi;double v=positive(gamma[0]);
    Report out{{"Order","Lag","Coefficient","Reflection","InnovationVariance","NormalResidual"},{}};
    for(std::size_t k=1;k<=P;++k){
        double a=gamma[k];for(std::size_t j=1;j<k;++j)a-=phi[j-1]*gamma[k-j];
        double reflection=a/v;require(std::abs(reflection)<1,"Toeplitz covariance not positive definite");
        Vec next(k);next[k-1]=reflection;
        for(std::size_t j=1;j<k;++j)next[j-1]=phi[j-1]-reflection*phi[k-j-1];
        v=positive(v*(1-reflection*reflection));phi=next;
        double err=0;
        for(std::size_t i=1;i<=k;++i){
            double z=-gamma[i];for(std::size_t j=1;j<=k;++j)z+=gamma[i>j?i-j:j-i]*phi[j-1];
            err=std::max(err,std::abs(z));
        }
        for(std::size_t j=0;j<k;++j)out.rows.push_back({double(k),double(j+1),phi[j],reflection,v,err});
    }
    return out;
}
