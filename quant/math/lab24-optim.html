组合优化需要区分目标函数、可行域与优化算法。欧氏投影直接解决最小扰动问题，并可作为其他凸优化方法的一个步骤，而软阈值对应可分离正则化项的近端映射。

1．排序阈值法投影至概率单纯形

模型结构与数学定义

由KKT条件，正权重坐标具有相同拉格朗日乘子θ，其他坐标被截断为零。将原向量降序排序，逐步确定有效支持并求满足权重和为1的阈值。计算复杂度为O(n log n)，可用于投影梯度法的每一步。

$$\min_{w\ge0,\ \mathbf1^\top w=1}\tfrac12\|w-z\|_2^2,\quad w_i=(z_i-\theta)_+$$

推导、最优性条件与数值结构

$$\mathcal L=\tfrac12\|w-z\|^2+\theta(\mathbf1^\top w-1)-\nu^\top w,\quad \nu_iw_i=0$$

一阶条件给出w_i=z_i−θ+ν_i；互补松弛使正权重坐标的ν_i为零，零权重坐标的z_i不超过θ。排序定位满足支持集合条件的θ。

完整计算案例

z=(0.2,1.2,−0.3)，有效支持只有第二项，投影为(0,1,0)。

$$\mathrm{Output}\approx\left(0,\ 1,\ 0\right)$$

输出顺序：每个资产投影后的权重。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

2．绝对敞口L1球投影

模型结构与数学定义

若原始头寸绝对和不超过总敞口预算，则原始向量已经可行；否则将绝对值投影到和为B的单纯形，再恢复原始方向。这一操作自然允许多空头寸并约束gross exposure。

$$\min_{\|w\|_1\le B}\|w-z\|_2^2,\quad w_i=\operatorname{sgn}(z_i)(|z_i|-\theta)_+$$

推导、最优性条件与数值结构

$$\theta=\frac{\sum_{j=1}^k|z|_{(j)}-B}{k},\qquad \sum_i|w_i|=B$$

对固定绝对值，恢复原始符号使欧氏误差最小。若预算绑定，绝对值的最优支持由排序后的阈值确定；若预算不绑定，则原头寸已经是最优解。

完整计算案例

z=(2,−1,0.5)，预算B=2，阈值0.5，有效投影为(1.5,−0.5,0)。

$$\mathrm{Output}\approx\left(1.5,\ -0.5,\ 0\right)$$

输出顺序：每个资产的带符号投影权重。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

3．带上下界的预算约束欧氏投影

模型结构与数学定义

对带上下限的凸二次目标，固定乘子θ时各坐标可独立截断。权重总和关于θ单调不增，因此可在所有可能断点之间二分搜索，并通过最终预算残差判断数值精度。

$$w_i=\min(u_i,\max(l_i,z_i-\theta)),\quad \sum_iw_i=B$$

推导、最优性条件与数值结构

$$F(\theta)=\sum_i\operatorname{clip}(z_i-\theta,l_i,u_i)-B=0$$

F连续、分段线性且单调不增。边界由z_i−u_i和z_i−l_i确定；中点若使总量过大，增大乘子即可降低全部自由坐标。

完整计算案例

三个目标头寸为0.8、0.6、0.2，范围均为[0,0.7]，预算为1，乘子为0.2，解为(0.6,0.4,0)。

$$\mathrm{Output}\approx\left(0.6,\ 0.4,\ 0\right)$$

输出顺序：各资产的最终可行权重。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

4．正交特征Elastic Net近端坐标解

模型结构与数学定义

当标准化或变换后的设计矩阵具有正交列时，Elastic Net目标可以按坐标分离。对每个坐标求次梯度的零点，得到软阈值加二次收缩的闭式解。输入c为X_jᵀy、g为X_jᵀX_j；参数为L1和L2惩罚系数。

$$\widehat\beta_j=\frac{\operatorname{sgn}(c_j)(|c_j|-\lambda_1)_+}{g_j+\lambda_2}$$

推导、最优性条件与数值结构

$$0\in(g_j+\lambda_2)\beta_j-c_j+\lambda_1\partial|\beta_j|$$

正、负、零三种情形分别代入次梯度条件。当绝对交叉乘积不超过L1惩罚时，零系数满足最优条件；超过时得到软阈值。

完整计算案例

c=(3,−1,0.2)、g=(2,2,2)，λ1=1、λ2=1时，系数为(2/3,0,0)。

$$\mathrm{Output}\approx\left(0.666666667,\ 0,\ 0\right)$$

输出顺序：各坐标最优系数。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

5．指数倾斜下的概率重加权

模型结构与数学定义

最大化给定特征的期望，同时用相对熵惩罚偏离先验概率，可从拉格朗日一阶条件得到指数倾斜形式。数值实现先计算对数权重并减去最大值，再归一化以降低溢出风险；输出重加权期望与KL距离。

$$q_i=\frac{p_i e^{\eta f_i}}{\sum_jp_j e^{\eta f_j}},\quad D_{\rm KL}(q\Vert p)=\sum_iq_i\log(q_i/p_i)$$

推导、最优性条件与数值结构

$$\max_q\left\{\eta\sum_iq_if_i-\sum_iq_i\log(q_i/p_i)\right\},\quad \mathbf1^\top q=1$$

对概率q的一阶条件取指数，并用预算约束归一化。对数配分函数的导数是倾斜特征的期望，第二导数是其方差，因此可进一步反解给定矩条件。

完整计算案例

先验概率相等，特征为0、1，η=log(3)时后验权重为1/4、3/4，期望0.75，KL为0.25log(0.5)+0.75log(1.5)。

$$\mathrm{Output}\approx\left(0.75,\ 0.130812036\right)$$

输出顺序：倾斜后的特征期望、相对熵。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

#pragma once
#include "lab24_common.hpp"
#include <functional>

namespace kline { namespace lab24 {
inline Vec simplex_projection(const Mat& x,const Vec& p){
    inputs(x,p,1,0);Vec z=col(x,0),u=z;
    std::sort(u.begin(),u.end(),std::greater<double>());
    double s=0,theta=0;std::size_t active=0;
    for(std::size_t j=0;j<u.size();++j){s+=u[j];double t=(s-1)/double(j+1);if(u[j]>t){theta=t;active=j+1;}}
    require(active>0,"Numerically empty simplex support");
    for(double& v:z)v=std::max(0.0,v-theta);
    require(std::abs(sum(z)-1)<1e-8,"Simplex projection lost precision");
    return checked(z);
}

inline Vec l1_ball(const Mat& x,const Vec& p){
    inputs(x,p,1,1);require(p[0]>=0,"Gross budget must be nonnegative");
    Vec z=col(x,0),u;for(double v:z)u.push_back(std::abs(v));
    if(sum(u)<=p[0])return z;
    if(p[0]==0)return Vec(z.size(),0);
    std::sort(u.begin(),u.end(),std::greater<double>());
    double s=0,t=0;
    for(std::size_t j=0;j<u.size();++j){s+=u[j];double q=(s-p[0])/double(j+1);if(u[j]>q)t=q;}
    for(double& v:z)v=std::copysign(std::max(0.0,std::abs(v)-t),v);
    double gross=0;for(double v:z)gross+=std::abs(v);
    require(std::abs(gross-p[0])<=1e-8*std::max(1.0,p[0]),"L1 projection lost precision");
    return checked(z);
}

inline Vec box_budget(const Mat& x,const Vec& p){
    inputs(x,p,3,1);double lo=std::numeric_limits<double>::infinity(),hi=-lo,L=0,U=0;
    for(const auto& r:x){require(r[1]<=r[2],"Reversed box bounds");L+=r[1];U+=r[2];lo=std::min(lo,r[0]-r[2]);hi=std::max(hi,r[0]-r[1]);}
    require(p[0]>=L-1e-12&&p[0]<=U+1e-12,"Infeasible budget");
    Vec w(x.size());
    for(int k=0;k<100;++k){double mid=lo+(hi-lo)/2,s=0;for(const auto& r:x)s+=std::clamp(r[0]-mid,r[1],r[2]);if(s>p[0])lo=mid;else hi=mid;}
    for(std::size_t i=0;i<x.size();++i)w[i]=std::clamp(x[i][0]-(lo+(hi-lo)/2),x[i][1],x[i][2]);
    require(std::abs(sum(w)-p[0])<=1e-8*std::max(1.0,std::abs(p[0])),"Budget residual too large");
    return checked(w);
}

inline Vec elastic_coordinate(const Mat& x,const Vec& p){
    inputs(x,p,2,2);require(p[0]>=0&&p[1]>=0,"Penalty must be nonnegative");
    Vec w;
    for(const auto& r:x){positive(r[1]);w.push_back(std::copysign(std::max(0.0,std::abs(r[0])-p[0]),r[0])/(r[1]+p[1]));}
    return checked(w);
}

inline Vec entropy_tilt(const Mat& x,const Vec& p){
    inputs(x,p,2,1);Vec logw;double total=0;
    for(const auto& r:x){positive(r[0]);total+=r[0];logw.push_back(std::log(r[0])+p[0]*r[1]);}
    require(std::abs(total-1)<1e-10,"Prior probabilities must sum to one");
    check_finite(logw);double m=*std::max_element(logw.begin(),logw.end()),z=0;
    for(double q:logw)z+=std::exp(q-m);
    double expectation=0,kl=0;
    for(std::size_t i=0;i<x.size();++i){double q=std::exp(logw[i]-m)/z;expectation+=q*x[i][1];if(q>0)kl+=q*(std::log(q)-std::log(x[i][0]));}
    return checked({expectation,kl});
}
} }

#pragma once

namespace kline { namespace lab24 {
using Vec=std::vector<double>;
using Mat=std::vector<Vec>;

inline void inputs(const Mat& x,const Vec& p,std::size_t cols,std::size_t params,
                   std::size_t min_rows=1) {
    require(x.size()>=min_rows&&x.size()<=250000,"Invalid number of observations");
    require(p.size()==params,"Incorrect scalar parameter count");
    for(double v:p)require(std::isfinite(v),"Nonfinite scalar parameter");
    for(const auto& row:x){
        require(row.size()==cols,"Unexpected CSV column count");
        for(double v:row)require(std::isfinite(v),"Nonfinite matrix entry");
    }
}
inline std::size_t integer(double x,std::size_t low,std::size_t high){
    require(std::isfinite(x)&&x>=double(low)&&x<=double(high)&&std::floor(x)==x,
            "Integer parameter outside allowed range");
    return std::size_t(x);
}
inline double dot(const Vec& a,const Vec& b){
    require(a.size()==b.size(),"Dot product dimension mismatch");
    return std::inner_product(a.begin(),a.end(),b.begin(),0.0);
}
inline Vec col(const Mat& x,std::size_t j){
    Vec out;out.reserve(x.size());
    for(const auto& row:x)out.push_back(row.at(j));
    return out;
}
inline double positive(double x){require(x>0&&std::isfinite(x),"Positive finite quantity required");return x;}
inline Vec checked(Vec v){check_finite(v);return v;}
inline double logistic(double x){
    if(x>=0)return 1/(1+std::exp(-x));
    double e=std::exp(x);return e/(1+e);
}
inline double normal_cdf(double x){return 0.5*std::erfc(-x/std::sqrt(2.0));}
inline double sum(const Vec& v){return std::accumulate(v.begin(),v.end(),0.0);}
} }
