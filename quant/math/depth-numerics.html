线性方程的残差与范数后向误差

数学定义与推导

对非奇异系统Ax=b，将近似解代回原方程得到残差。若允许A及b同时有相对范数扰动，则分母按二者尺度相加，给出范数后向误差。前向误差还取决于A的条件数；因此小残差不能直接证明权重或回归系数准确。无穷范数的矩阵范数取各行绝对值和的最大值。

$$r=b-A\hat x$$
$$\eta_\infty=\frac{\|r\|_\infty}{\|A\|_\infty\|\hat x\|_\infty+\|b\|_\infty}$$
$$\frac{\|\hat x-x\|}{\|x\|}\leq \kappa(A)\frac{\|r\|}{\|b\|}$$

数值演算与金融应用

样本A的行和为3与4，近似解为(1,2)，Ax=(4,7)，而b=(4,8)，残差无穷范数1。相对残差1/8，后向误差1/(4×2+8)=1/16。适用于均值方差优化的线性方程或隐式定价系统。

算法复杂度、输入契约与边界

输入最后两列依次是近似解和右端，前面列为方阵；O(d²)时间、O(d)附加存储。零右端时相对残差没有通常定义，程序要求正的右端范数。条件数需要独立估计，不能由本诊断推断。

线性方程组的行尺度均衡

数学定义与推导

非零行的最大绝对元素作为尺度，左乘D的逆不改变精确解集合，却使每一行的最大元素为1。舍入误差及迭代收敛对尺度敏感，均衡可作为预处理；它不保证条件数必然下降。与列缩放不同，行缩放不会改变未知量的单位。

$$s_i=\max_j|a_{ij}|,\quad D=\operatorname{diag}(s_i)$$
$$D^{-1}Ax=D^{-1}b$$
$$\|D^{-1}A\|_\infty\le d$$

数值演算与金融应用

原方程2x+4y=6、x=3，第一行除以4得0.5x+y=1.5，第二行不变，解仍是x=3、y=0。对不同金额单位的风险约束，均衡使求解器避免仅由数值量级支配容差。

算法复杂度、输入契约与边界

最后一列为右端，前面为系数。零系数行意味着冗余或不一致，必须在均衡前单独处理。O(nd)时间，输出保留各行尺度以便还原原始残差。

实对称二阶矩阵的稳定谱分解

数学定义与推导

二阶特征多项式配方后得到迹的一半加减谱半径。hypot避免直接对差值和非对角元素平方造成不必要的上溢。特征值和及积分别与迹和行列式一致；接近奇异时小特征值的相消仍可能损失精度，需要更高精度或稳定分解。

$$A=\begin{pmatrix}a&b\\b&d\end{pmatrix},\quad \det(A-\lambda I)=0$$
$$\lambda_{\pm}=\tfrac12(a+d)\pm\operatorname{hypot}(\tfrac12(a-d),b)$$
$$\lambda_++\lambda_-=\operatorname{tr}(A),\quad \lambda_+\lambda_-=\det A$$

数值演算与金融应用

对协方差(2,1;1,2)，共同方向(1,1)的特征值3，反向方向(1,−1)的特征值1。该例说明相关性使总风险集中到共同方向，谱均为正才支持严格正定二次目标。

算法复杂度、输入契约与边界

仅针对实对称2×2矩阵，复杂度O(1)。对更高维协方差应采用对称特征分解；数值对称容差不意味着原始观测协方差估计无误。

精度矩阵对角与高斯条件方差

数学定义与推导

在联合高斯模型中，将协方差按变量j与其余变量分块。条件方差为Schur补，而分块逆的对应对角恰为Schur补的倒数。实现逐列解SPD系统而不显式进行通用矩阵求逆，并以单位向量残差检验每列。对非高斯分布，该量通常仅表示线性预测残差方差。

$$\Omega=\Sigma^{-1},\quad \Sigma z_j=e_j$$
$$\operatorname{Var}(X_j\mid X_{-j})=\Omega_{jj}^{-1}$$
$$\Sigma_{jj}-\Sigma_{j,-j}\Sigma_{-j,-j}^{-1}\Sigma_{-j,j}=\Omega_{jj}^{-1}$$

数值演算与金融应用

协方差对角均2、交叉项1，精度对角2/3，因此条件方差1.5，低于边际方差2。可解释因子残差风险或资产之间的条件依赖，但条件关系不是因果关系。

算法复杂度、输入契约与边界

输入须为严格正定对称矩阵。使用共享Cholesky求解器逐列求解，当前实现约O(d⁴)时间；大规模生产宜复用一次分解或稀疏精度估计。d≤64。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace depth_numerics {
using namespace evidence;
inline Report backward_error(const Mat& x,const Vec& p){
    auto m=validate(x,1,3,64);
    parameters(p,0);
    auto d=m-2;
    require(x.size()==d,"Square system required");
    Vec z=column(x,d),b=column(x,d+1);
    double an=0,xn=0,bn=0,rn=0;
    for(double v:z)xn=std::max(xn,std::abs(v));
    for(std::size_t i=0;i<d;++i){
        double a=0,v=0;
        for(std::size_t j=0;j<d;++j){a+=std::abs(x[i][j]);v+=x[i][j]*z[j];}
        an=std::max(an,a);bn=std::max(bn,std::abs(b[i]));rn=std::max(rn,std::abs(b[i]-v));
    }
    return scalar({"ResidualInf","RelativeResidual","BackwardError","MatrixInfNorm"},{rn,rn/positive(bn),rn/positive(an*xn+bn),an});
}

inline Report row_equilibration(const Mat& x,const Vec& p){
    auto d=validate(x,1,2,64)-1;
    parameters(p,0);
    Report o{{"Row","Scale"},{}};
    for(std::size_t j=0;j<d;++j)o.header.push_back("A"+std::to_string(j+1));
    o.header.push_back("B");
    for(std::size_t i=0;i<x.size();++i){
        double s=0;
        for(std::size_t j=0;j<d;++j)s=std::max(s,std::abs(x[i][j]));
        positive(s);
        Vec r{double(i+1),s};
        for(double v:x[i])r.push_back(v/s);
        o.rows.push_back(r);
    }
    return o;
}

inline Report two_by_two_spectrum(const Mat& x,const Vec& p){
    validate(x,2,2,2);parameters(p,0);
    require(x.size()==2,"Two by two matrix required");
    require(std::abs(x[0][1]-x[1][0])<=1e-12*std::max({1.,std::abs(x[0][1]),std::abs(x[1][0])}),"Symmetric matrix required");
    double a=x[0][0],d=x[1][1],b=x[0][1]/2+x[1][0]/2;
    double m=a/2+d/2,h=std::hypot(a/2-d/2,b);
    return scalar({"EigenLow","EigenHigh","Trace","Determinant"},{m-h,m+h,a+d,a*d-b*b});
}

inline Report precision_conditional(const Mat& x,const Vec& p){
    auto d=validate(x,1,1,64);parameters(p,0);
    require(x.size()==d,"Square covariance required");
    Report o{{"Variable","PrecisionDiagonal","ConditionalVariance","ResidualInf"},{}};
    for(std::size_t j=0;j<d;++j){
        Vec e(d,0);e[j]=1;
        Vec z=solve_spd(x,e),r=mul(x,z);
        double err=0;
        for(std::size_t i=0;i<d;++i)err=std::max(err,std::abs(r[i]-e[i]));
        o.rows.push_back({double(j+1),z[j],1/positive(z[j]),err});
    }
    return o;
}
