1．具有逐期测量误差的Kalman滤波

模型结构与数学定义

假设潜在状态服从随机游走，每期观测由状态与独立测量噪声组成。预测方差加上过程方差Q，按测量精度形成Kalman增益。使用Joseph形式计算后验方差，以非负平方项减轻舍入误差。返回最终后验均值、方差及累计预测对数似然。

$$P_t^-=P_{t-1}+Q,\quad K_t=P_t^-/(P_t^-+R_t),\quad m_t=m_{t-1}+K_t(y_t-m_{t-1})$$

推导、最优性条件与数值结构

$$P_t=(1-K_t)^2P_t^-+K_t^2R_t,\quad \log L=-\frac12\sum_t\{\log(2\pi S_t)+e_t^2/S_t\}$$

预测误差e_t是观测与先验均值之差，方差S_t是过程预测方差与测量方差的和。根据正态条件分布，后验均值线性更新，Joseph形式则显式保留两个非负方差贡献。

完整计算案例

初始均值0、方差1、过程方差0；观测2、测量方差1，则增益1/2，后验均值1、方差0.5。观测边际方差为2，似然为正态密度。

$$\mathrm{Output}\approx\left(1,\ 0.5,\ -2.26551212\right)$$

输出顺序：最后一期状态均值、后验方差、观测累计对数似然。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

2．双状态隐马尔可夫模型的缩放前向算法

模型结构与数学定义

输入每期两个状态下的观测似然。先使用行随机转移矩阵推进上一期状态分布，再逐状态乘似然并归一化；记录每次归一化常数的对数，避免对长时间序列直接连乘概率。首期只使用先验与观测似然。输出最后一期两状态过滤概率和对数似然。

$$\widetilde\alpha_t(j)=b_j(y_t)\sum_i\alpha_{t-1}(i)P_{ij},\quad \alpha_t=\widetilde\alpha_t/c_t,\quad \log L=\sum_t\log c_t$$

推导、最优性条件与数值结构

$$c_t=\sum_j b_j(y_t)\sum_i\alpha_{t-1}(i)P_{ij},\qquad \sum_j\alpha_t(j)=1$$

缩放常数恰为给定历史观测的当期边际似然。联合似然按条件概率的乘积展开，因此累加对数缩放常数即可恢复完整样本似然，而不用保存极小的联合概率。

完整计算案例

初始概率各0.5，首期观测似然为0.8、0.2，最终状态概率为0.8、0.2，边际似然为0.5。

$$\mathrm{Output}\approx\left(0.8,\ 0.2,\ -0.693147181\right)$$

输出顺序：状态0过滤概率、状态1过滤概率、累计对数似然。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

3．双状态Viterbi最可能状态路径

模型结构与数学定义

将状态路径的联合概率最大化转化为对数域动态规划。每期为两个终点状态保存最大累计对数得分及其前驱，最后从得分较大的终点反向恢复整个路径。与逐时点最大过滤概率不同，Viterbi优化的是联合路径。

$$\delta_t(j)=\max_i\{\delta_{t-1}(i)+\log P_{ij}\}+\log b_j(y_t)$$

推导、最优性条件与数值结构

$$\psi_t(j)=\arg\max_i[\delta_{t-1}(i)+\log P_{ij}],\quad z_{t-1}^*=\psi_t(z_t^*)$$

最优路径若在给定终点之前包含非最优子路径，则可替换子路径提高整体联合概率，产生矛盾。动态规划利用这一最优子结构，前向只保留两个状态得分，反向使用前驱数组恢复路径。

完整计算案例

两期状态似然分别为(0.9,0.1)、(0.8,0.2)，初始状态概率0.5且两状态留存率0.9，最大联合概率路径为(0,0)。

$$\mathrm{Output}\approx\left(0,\ 0\right)$$

输出顺序：每个观测时点对应的最优状态编号。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

4．等距采样OU过程的条件矩估计

模型结构与数学定义

OU过程的离散精确转移均值为θ+(X_t−θ)e^(−κΔ)。在等距样本中对下一期状态回归当前状态，获得截距与斜率，再反解均值回复速度、长期均值与扩散系数。创新方差采用条件高斯极大似然的n分母，按精确转移方差反推σ。

$$X_{t+\Delta}=\alpha+\phi X_t+\epsilon_t,\quad \kappa=-\log\phi/\Delta,\quad \theta=\alpha/(1-\phi)$$

推导、最优性条件与数值结构

$$\operatorname{Var}(\epsilon_t)=\frac{\sigma^2}{2\kappa}(1-e^{-2\kappa\Delta}),\qquad \widehat\sigma^2=\frac{2\widehat\kappa\,\widehat{\operatorname{Var}}(\epsilon)}{1-\widehat\phi^2}$$

对OU随机微分方程使用积分因子可得到条件正态转移，其确定性部分是指数回复，随机积分的方差由Itô等距性质获得。回归的创新方差由此转换为连续时间扩散系数。

完整计算案例

序列1、0.5、0.25、0.125，Δ=1，回归斜率0.5、截距0，回复速度log2、长期均值0、扩散系数0。

$$\mathrm{Output}\approx\left(0.693147181,\ 0,\ 0\right)$$

输出顺序：均值回复速度κ、长期均值θ、扩散系数σ。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

5．双状态吸收前的有限期首次命中概率

模型结构与数学定义

将正常状态视为尚未触发事件，压力状态定义为首次命中的目标。每个时段若仍留在正常状态，路径乘以P00；补事件即有限期限内至少一次命中。命中时间为几何分布，故其均值为单期退出概率的倒数。返回有限期限首次命中概率、期望命中期数。

$$h_0(t)=1-P_{00}^{\,t},\quad E_0[\tau]=1/(1-P_{00})$$

推导、最优性条件与数值结构

$$\Pr(\tau=k)=s^{k-1}(1-s),\qquad \Pr(\tau>h)=s^h$$

从正常状态出发，首次命中在第k期意味着前k−1期持续正常且第k期退出。将几何概率求和得到累计命中概率；由非负整数变量的尾和公式得到期望时间。

完整计算案例

正常状态单期留存概率0.8，期限2期，首次命中概率0.36，期望命中时间5期。

$$\mathrm{Output}\approx\left(0.36,\ 5\right)$$

输出顺序：期限内首次命中概率、期望首次命中期数。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

#pragma once
#include "lab24_common.hpp"
#include <map>

namespace kline { namespace lab24 {
inline Vec scalar_kalman(const Mat& x,const Vec& p){
    inputs(x,p,2,3);double m=p[0],v=p[1],q=p[2],ll=0;
    require(v>=0&&q>=0,"Invalid state variance");
    for(const auto& r:x){
        positive(r[1]);double prior=v+q,s=positive(prior+r[1]),e=r[0]-m,k=prior/s;
        m+=k*e;v=(1-k)*(1-k)*prior+k*k*r[1];
        ll-=0.5*(std::log(2*std::acos(-1.0)*s)+e*e/s);
    }
    return checked({m,v,ll});
}

inline Vec hmm_forward(const Mat& x,const Vec& p){
    inputs(x,p,2,3);for(double q:p)require(q>=0&&q<=1,"Invalid probability");
    double a=p[0],b=1-a,ll=0;
    for(std::size_t t=0;t<x.size();++t){
        if(t){double z=a*p[1]+b*(1-p[2]);b=a*(1-p[1])+b*p[2];a=z;}
        require(x[t][0]>=0&&x[t][1]>=0,"Negative observation likelihood");
        a*=x[t][0];b*=x[t][1];double z=positive(a+b);ll+=std::log(z);a/=z;b/=z;
    }
    return checked({a,b,ll});
}

inline Vec viterbi(const Mat& x,const Vec& p){
    inputs(x,p,2,3);for(double q:p)require(q>0&&q<1,"Transition and prior must lie in (0,1)");
    for(const auto& r:x){positive(r[0]);positive(r[1]);}
    double a=std::log(p[0])+std::log(x[0][0]),b=std::log(1-p[0])+std::log(x[0][1]);
    std::vector<std::pair<int,int>> back(x.size());
    for(std::size_t t=1;t<x.size();++t){
        double aa=a+std::log(p[1]),ba=b+std::log(1-p[2]),ab=a+std::log(1-p[1]),bb=b+std::log(p[2]);
        back[t]={aa>=ba?0:1,ab>=bb?0:1};a=std::max(aa,ba)+std::log(x[t][0]);b=std::max(ab,bb)+std::log(x[t][1]);
    }
    Vec states(x.size());int z=a>=b?0:1;
    for(std::size_t t=x.size();t-->0;){states[t]=z;if(t)z=z==0?back[t].first:back[t].second;}
    return states;
}

inline Vec ou_transition_fit(const Mat& x,const Vec& p){
    inputs(x,p,1,1,4);double dt=positive(p[0]);Vec a,b;
    for(std::size_t i=1;i<x.size();++i){a.push_back(x[i-1][0]);b.push_back(x[i][0]);}
    double phi=covariance(a,b,false)/positive(variance(a,false));
    require(phi>0&&phi<1,"OU autoregressive coefficient must lie in (0,1)");
    double alpha=mean(b)-phi*mean(a),k=-std::log(phi)/dt,sse=0;
    for(std::size_t i=0;i<a.size();++i){double e=b[i]-alpha-phi*a[i];sse+=e*e;}
    return checked({k,alpha/(1-phi),std::sqrt(2*k*(sse/a.size())/(1-phi*phi))});
}

inline Vec markov_hitting(const Mat& x,const Vec& p){
    inputs(x,p,1,1);require(x.size()==1,"Single normal-state probability required");
    auto h=integer(p[0],1,1000000);double s=x[0][0];require(s>=0&&s<1,"Stay probability must be in [0,1)");
    double hit=s==0?1:-std::expm1(double(h)*std::log(s));
    return checked({hit,1/(1-s)});
}
} }

using Vec=std::vector<double>;
using Mat=std::vector<Vec>;

inline void inputs(const Mat& x,const Vec& p,std::size_t cols,std::size_t params,
                   std::size_t min_rows=1) {
    require(x.size()>=min_rows&&x.size()<=250000,"Invalid number of observations");
    require(p.size()==params,"Incorrect scalar parameter count");
    for(double v:p)require(std::isfinite(v),"Nonfinite scalar parameter");
    for(const auto& row:x){
        require(row.size()==cols,"Unexpected CSV column count");
        for(double v:row)require(std::isfinite(v),"Nonfinite matrix entry");
    }
}
inline std::size_t integer(double x,std::size_t low,std::size_t high){
    require(std::isfinite(x)&&x>=double(low)&&x<=double(high)&&std::floor(x)==x,
            "Integer parameter outside allowed range");
    return std::size_t(x);
}
inline double dot(const Vec& a,const Vec& b){
    require(a.size()==b.size(),"Dot product dimension mismatch");
    return std::inner_product(a.begin(),a.end(),b.begin(),0.0);
}
inline Vec col(const Mat& x,std::size_t j){
    Vec out;out.reserve(x.size());
    for(const auto& row:x)out.push_back(row.at(j));
    return out;
}
inline double positive(double x){require(x>0&&std::isfinite(x),"Positive finite quantity required");return x;}
inline Vec checked(Vec v){check_finite(v);return v;}
inline double logistic(double x){
    if(x>=0)return 1/(1+std::exp(-x));
    double e=std::exp(x);return e/(1+e);
}
inline double normal_cdf(double x){return 0.5*std::erfc(-x/std::sqrt(2.0));}
inline double sum(const Vec& v){return std::accumulate(v.begin(),v.end(),0.0);}
