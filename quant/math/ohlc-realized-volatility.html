日内区间波动率与跨时段风险

同一条OHLC记录同时包含交易时段价格区间、开盘与收盘位置及隔夜跳变。不同估计量对连续交易、漂移、开盘跳空和微观结构噪声的假设各不相同，因此宜分别报告估计对象，不把区间波动率与收盘收益方差混作同一个参数。

1．Parkinson极差估计

$$\widehat{\sigma}_{P}^{2}=\frac{1}{4n\ln2}\sum_{t=1}^{n}\left[\ln(H_t/L_t)\right]^2$$

统计定义与推导

布朗运动连续交易且漂移可以忽略时，最高价与最低价包含比收盘差更充分的日内价格路径信息。取对数极差平方并除以\(4\ln2\)，得到每个交易时段的扩散方差近似；跨时段取平均时权重相同。

数值复算与经济含义

单日\(H=110,L=90\)，则对数极差为\(\ln(11/9)\\)，对应估计量约为\(0.0145\)；该数值是时段方差，年化前应与所用交易日数及交易时段长度对应。

输入口径与适用范围

极差估计不直接包含开盘前风险；价格涨跌停、稀疏交易和数据中混用复权价会破坏其统计含义。

2．Garman–Klass区间估计

$$\widehat{\sigma}_{GK}^{2}=\frac1n\sum_t\left[\tfrac12\ln^2(H_t/L_t)-(2\ln2-1)\ln^2(C_t/O_t)\right]$$

统计定义与推导

该估计在极差平方基础上减去收盘相对于开盘的对数变动平方，利用价格区间与端点共同识别连续扩散波动。两项系数来自特定几何布朗运动假设下的矩关系，数值结果不是对收益协方差的直接估计。

数值复算与经济含义

取\(O=C=100,H=110,L=90\)，收开盘项为零，故该日估计量等于极差平方的一半，约为\(0.0201\)。这与Parkinson估计数值不同，说明它们有不同的样本路径权重。

输入口径与适用范围

非零漂移、跳跃和离散报价可能造成偏差；程序严格校验每条记录满足\(L\le O,C\le H\)，避免非法K线被纳入计算。

命令行读取具有对应列名的CSV数据；所有计算入口均在range_volatility_lab.hpp中实现。

3．Rogers–Satchell漂移鲁棒估计

$$\widehat{\sigma}_{RS}^{2}=\frac1n\sum_t\left[\ln(H_t/C_t)\ln(H_t/O_t)+\ln(L_t/C_t)\ln(L_t/O_t)\right]$$

统计定义与推导

该估计分别比较最高价、最低价与开收盘端点的位置。对于连续对数价格过程，它能够在常数漂移存在的情况下估计扩散方差，因而适合分析日内明显趋势的价格区间。

数值复算与经济含义

若\(O=C=100,H=110,L=90\)，两项依次是\(\ln^2(1.1)\)和\(\ln^2(0.9)\)，合计约为\(0.02018\)。其结构与Garman–Klass有所不同，不能在选择后追溯更改风险口径。

输入口径与适用范围

该估计仍依赖完整日内高低价与一致的复权规则；不包含隔夜跳跃，也不直接提供参数置信区间。

实际数据命令

./kline_quant range-rs market.csv Open High Low Close

4．隔夜跳空的二阶矩

$$\widehat{m}_{ON,2}=\frac1n\sum_t\left[\ln(O_t/C_{t-1})\right]^2$$

统计定义与推导

开盘相对上一交易日收盘的跳空连接两个交易时段，它的风险机制受到隔夜消息、市场休市制度和盘前流动性的影响。这里计算未去均值的平方对数跳空，精确名称为二阶原点矩，与去均值的样本方差不同。

数值复算与经济含义

前收盘价为100、次日开盘价为110，单次隔夜对数收益约为\(0.09531\)，平方约为\(0.009084\)。正向与负向跳空对二阶矩产生相同的非负贡献。

输入口径与适用范围

遇到分红、拆股和不同币种报价时，应先对齐前收与开盘口径；不能直接把这一矩与日内方差相加并声称得到已校正的Yang–Zhang估计。

#pragma once
#include "stats.hpp"
#include <algorithm>
#include <cmath>
#include <vector>

namespace kline {
inline void validate_ohlc(const std::vector<double>& open,
                          const std::vector<double>& high,
                          const std::vector<double>& low,
                          const std::vector<double>& close) {
    check_finite(open); check_finite(high); check_finite(low); check_finite(close);
    require(open.size()==high.size() && open.size()==low.size() &&
            open.size()==close.size(),"OHLC columns must align");
    for(std::size_t i=0;i<open.size();++i)
        require(low[i]>0 && open[i]>0 && close[i]>0 &&
                high[i]>=std::max(open[i],close[i]) &&
                low[i]<=std::min(open[i],close[i]) && high[i]>=low[i],
                "Invalid positive OHLC price range");
}
inline double parkinson_intraday_variance(const std::vector<double>& high,
                                          const std::vector<double>& low) {
    check_finite(high);check_finite(low);
    require(high.size()==low.size(),"High and low must align");
    double sum=0;
    for(std::size_t i=0;i<high.size();++i){
        require(low[i]>0&&high[i]>=low[i],"Invalid price range");
        const double x=std::log(high[i]/low[i]);sum+=x*x;
    }
    return sum/(4*std::log(2.0)*high.size());
}
inline double garman_klass_intraday_variance(
    const std::vector<double>& open,const std::vector<double>& high,
    const std::vector<double>& low,const std::vector<double>& close){
    validate_ohlc(open,high,low,close);
    double sum=0;
    for(std::size_t i=0;i<open.size();++i){
        const double range=std::log(high[i]/low[i]);
        const double closeOpen=std::log(close[i]/open[i]);
        sum+=0.5*range*range-(2*std::log(2.0)-1)*closeOpen*closeOpen;
    }
    return std::max(0.0,sum/open.size());
}
inline double rogers_satchell_intraday_variance(
    const std::vector<double>& open,const std::vector<double>& high,
    const std::vector<double>& low,const std::vector<double>& close){
    validate_ohlc(open,high,low,close);
    double sum=0;
    for(std::size_t i=0;i<open.size();++i)
        sum+=std::log(high[i]/close[i])*std::log(high[i]/open[i])+
             std::log(low[i]/close[i])*std::log(low[i]/open[i]);
    return std::max(0.0,sum/open.size());
}
inline double overnight_gap_second_moment(const std::vector<double>& open,
                                           const std::vector<double>& previousClose){
    check_finite(open);check_finite(previousClose);
    require(open.size()==previousClose.size(),"Open and previous close must align");
    double sum=0;
    for(std::size_t i=0;i<open.size();++i){
        require(open[i]>0&&previousClose[i]>0,"Invalid overnight price");
        const double gap=std::log(open[i]/previousClose[i]);sum+=gap*gap;
    }
    return sum/open.size();
}
} // namespace kline
