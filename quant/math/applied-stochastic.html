正负实现半方差

路径平方增量按符号分解。连续半鞅在适当高频极限下连续部分对正负半方差各贡献一半，跳跃按符号进入相应项；有限样本分解无分布要求。

$$RV^+=\sum_i(\Delta X_i)^2\mathbf1_{\Delta X_i>0},\quad RV^-=\sum_i(\Delta X_i)^2\mathbf1_{\Delta X_i<0}$$
$$RV=RV^++RV^-$$

日内对数价格增量的下行波动案例：正0.1、负0.05。注意微观结构噪声和不同收益尺度。

Brownian桥条件矩

将Brownian运动分解为终点线性投影及独立桥，联合正态保证零协方差意味着独立。条件方差为σ²t（1－t／T），本实现固定T＝1。

$$\mathbb E[X_t\mid X_0=a,X_T=b]=a+t(b-a)/T$$
$$\operatorname{Cov}(X_s,X_t\mid X_T)=\sigma^2(\min(s,t)-st/T)$$

起点0、终点1、扩散系数2，中央时点条件方差1。已知未来终点的桥仅作条件模拟，不能直接构成事前交易信号。

嵌套分割的二次协变差

在给定分割上累计同步增量乘积。粗细分割的有限样本值不同，连续半鞅在网格趋零的适当条件下收敛到二次协变差。

$$[X,Y]_\pi=\sum_{[t_i,t_{i+1}]\in\pi}\Delta X_i\Delta Y_i$$
$$[X+Y]_\pi=[X]_\pi+[Y]_\pi+2[X,Y]_\pi$$

案例细分割协变差2，两步粗分割为0。高频估计需真实时间同步及噪声控制，两种步长比较不能证明一致性。

平稳AR(1)累积收益方差

展开累积方差，滞后k的协方差出现h−k次。平稳条件为自回归系数绝对值小于1，参数是无条件单期方差。

$$\gamma_k=\gamma_0\phi^{|k|},\quad \operatorname{Var}(\sum_{t=1}^h r_t)=h\gamma_0+2\sum_{k=1}^{h-1}(h-k)\gamma_k$$
$$\operatorname{Var}(\sum_{t=1}^h r_t)/(h\gamma_0)=1+\frac2h\sum_{k=1}^{h-1}(h-k)\phi^k$$

φ＝0.5、单期方差2，1、2、3期方差2、6、11。正自相关提高长期风险；简单收益复利不能直接代入加法公式。

C++17完整实现

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace applied_stochastic {
using namespace evidence;
inline Report semivariance(const Mat& x,const Vec& p){
    validate(x,1,1,1);
    parameters(p,0);
    double a=0,b=0;
    for(auto&r:x){double v=r[0]*r[0];
    if(r[0]>0)a+=v;
    else b+=v;
    }return scalar({"PositiveRV","NegativeRV","TotalRV"},{a,b,a+b});
    
}

inline Report bridge(const Mat& x,const Vec& p){
    validate(x,1,1,1);
    parameters(p,3);
    double sigma=positive(p[2]);
    Report o{{"Time","ConditionalMean","ConditionalVariance"},{}};
    for(auto&r:x){double t=r[0];
    require(t>=0&&t<=1,"Time outside unit interval");
    o.rows.push_back({t,p[0]+t*(p[1]-p[0]),sigma*sigma*t*(1-t)});
    }return o;
    
}

inline Report covariation(const Mat& x,const Vec& p){
    validate(x,3,2,2);
    parameters(p,1);
    auto k=count(p[0],2,x.size()-1);
    require((x.size()-1)%k==0,"Stride must divide interval count");
    Report o{{"Stride","Intervals","QVX","QVY","QCov"},{}};
    for(auto step:{std::size_t(1),k}){double a=0,b=0,c=0;
    for(std::size_t i=step;
    i<x.size();
    i+=step){double u=x[i][0]-x[i-step][0],v=x[i][1]-x[i-step][1];
    a+=u*u;
    b+=v*v;
    c+=u*v;
    }o.rows.push_back({double(step),double((x.size()-1)/step),a,b,c});
    }return o;
    
}

inline Report ar_aggregation(const Mat& x,const Vec& p){
    validate(x,1,1,1);
    parameters(p,2);
    double phi=p[0],v=positive(p[1]);
    require(std::abs(phi)<1,"Stationary AR required");
    Report o{{"Horizon","SingleVariance","SumVariance","IndependentVariance"},{}};
    double work=0;
    for(auto&r:x){auto h=count(r[0],1,100000);
    work+=h;
    require(work<=2e7,"Work limit");
    double z=h*v,power=phi;
    for(std::size_t k=1;
    k<h;
    ++k){z+=2*v*(h-k)*power;
    power*=phi;
    }o.rows.push_back({double(h),v,z,h*v});
    }return o;
    
}
} }
