时间序列研究：条件预测、波动动态与状态空间

研究框架与统一口径

预测与创新

$$\widehat y_{t|t-1}=\mathbb E(y_t\mid\mathcal F_{t-1}),\quad e_t=y_t-\widehat y_{t|t-1}$$

先形成预测再观察当期数据，保证创新是相对于先前信息集定义的误差。回归与过滤应在更新模型之前记录预测；不允许将平滑后的历史潜状态冒充当时可得估计。

损失口径

$$MSE=T^{-1}\sum_te_t^2,\quad QLIKE_t=\log h_t+r_t^2/h_t$$

均值模型评价与方差模型评价不同，后者以当期收益平方作为条件方差的噪声代理。两种模型只在共同有效测试期间进行比较。

1．滚动正则化AR预测

研究问题与经济含义

AR模型将过去p期的观测作为当前预测的解释变量。窗口指的是原始序列长度，而不是构造后的回归样本数；因此每个训练窗口内可用标签行数为L−p。程序按原始时点重建训练设计，避免跨窗口的滞后变量不小心扩大训练范围。

数学定义与推导

$$y_s=a+\sum_{j=1}^p\phi_jy_{s-j}+\epsilon_s,\quad s=t-L+p,\ldots,t-1$$

在窗口内构造滞后向量与响应，使用训练内标准化及正则化回归拟合。截距不受惩罚，系数估计采用均方目标尺度。

$$\widehat y_t=\bar y_{\rm train}+\widehat\beta^\top D_t^{-1}(z_t-\bar z_t),\qquad z_t=(y_{t-1},\ldots,y_{t-p})^\top$$

预测时的滞后向量完全由历史观测构成。训练区间的最后一行标签为y_{t−1}，当前y_t不参与拟合。

$$d_t=(y_t-y_{t-1})^2-(y_t-\widehat y_t)^2$$

可复现样本与运行

52期样例用L=15、p=3、λ=0.1。首期预测索引15，训练响应索引3至14，共12条。输出Persistence表示直接使用上一期观测的朴素基准。

2．多资产正则化VAR预测

研究问题与经济含义

VAR允许一项资产的滞后回报影响其他资产的条件均值。将同一时点的全部资产上一期观测作为特征，对每个响应资产分别拟合正则化线性模型。输出按日期、资产排列，便于随后按资产或截面汇总误差。

数学定义与推导

$$r_t=a+A r_{t-1}+\varepsilon_t,\qquad A\in\mathbb R^{d\times d}$$

每行系数对应一个被预测资产，各列对应滞后解释资产。不同响应共享相同训练时间范围和特征矩阵，但目标变量不同。

$$\widehat B=(Z^\top Z/n+\lambda I)^{-1}Z^\top Y_c/n$$

多响应Ridge在二次惩罚下可按响应列分解，逐个线性系统的解与一次求解多右端系统等价。这里以逐响应形式实现，便于清晰核查。

$$MSE_j=\frac1T\sum_t(r_{t,j}-\widehat r_{t,j})^2$$

可复现样本与运行

四资产48期样例使用15期窗口。首个预测日期索引15，每个资产使用14条训练响应；同一日期形成4条预测结果。

结果解释与实证研究设计

先按资产计算均方误差，再基于事先确定的风险或经济权重汇总。不能仅以整体误差掩盖个别资产的失败。

模型假设与适用边界

VAR预测关联并不意味着因果关系；高维样本需要更强正则化、稳定性检查和多期预测检验。当前为VAR(1)的一步预测，不是协整VECM。

3．EWMA与GARCH逐期波动预测

研究问题与经济含义

波动聚集意味着相邻时点的条件方差并非恒定。EWMA以指数权重传播过去平方收益；GARCH(1,1)在更新方程中增加常数与独立的滞后方差项，使长期方差能够围绕有限均值回复。

数学定义与推导

$$h_{t+1}^{E}=d h_t^E+(1-d)r_t^2,\qquad h_{t+1}^{G}=\omega+\alpha r_t^2+\beta h_t^G$$

两模型都先输出h_t，再使用r_t更新下一期预测。对于零条件均值、单位创新方差的GARCH，α+β<1是有限无条件二阶矩的常见条件。

$$\mathbb E(h_t^G)=\frac{\omega}{1-\alpha-\beta},\qquad z_t=r_t/\sqrt{h_t}$$

长期方差从无条件方差递推的固定点得到。标准化创新有助于检查剩余波动聚集，但模型参数需先估计，不应利用测试段调节。

$$\ell_t(h)=\log h+r_t^2/h$$

可复现样本与运行

样例初始方差0.0001、EWMA衰减0.94，GARCH参数ω=0.000002、α=0.08、β=0.90；GARCH的无条件方差恰为0.0001。冲击日的平方收益只改变下一期方差。

模型假设与适用边界

代码只评估给定参数，不进行GARCH极大似然估计。假设条件均值为零，若存在均值过程，应输入相应创新序列。

4．滚动状态转换及条件收益预测

研究问题与经济含义

可观测制度变量例如事先定义的压力指标，可以作为离散状态。使用历史状态转移频数估计一步转移概率，并对各状态的历史回报求条件均值。当前收益预测对可能的下一状态加权，显式考虑制度切换的不确定性。

数学定义与推导

$$\widehat P_{ij,t}=\frac{N_{ij,t}+a}{\sum_kN_{ik,t}+2a}$$

伪计数避免没有观察到某种转移时直接得到零概率。窗口只有L个状态，因此转移计数共有L−1个相邻状态对。

$$\widehat\mu_{j,t}=\frac{\sum_{s<t}r_s\mathbf1_{\{Z_s=j\}}}{\sum_{s<t}\mathbf1_{\{Z_s=j\}}},\quad \widehat r_t=\sum_j\widehat P_{Z_{t-1},j,t}\widehat\mu_{j,t}$$

状态条件均值只使用同一历史窗口；若某状态未出现，用窗口总体均值作为明确定义的回退值。

$$BS_t=(\widehat P_{Z_{t-1},1,t}-Z_t)^2$$

可复现样本与运行

40期构造样例使用窗口10、每格伪计数1。预测中同时输出下一状态概率和收益预测，二者各自具有评价标准。

./build/kline_quant flow-regime-forecast quant/research/examples/regimes.csv 10 1

结果解释与实证研究设计

通过逐期概率校准和条件回报误差比较制度模型与无条件均值。状态标签如果来自未来收益或事后全样本聚类，将使这种测试失去时点有效性。

模型假设与适用边界

当前状态必须可观测且定义于历史时点。这不是隐马尔可夫状态估计，不能从未来制度标签反推当前状态。

5．状态空间预测与Kalman更新

研究问题与经济含义

状态空间模型区分不可直接观测的潜在状态与含噪声的测量值。随机游走模型将前一期后验均值作为本期先验均值，并将过程噪声加入先验方差。观测的测量方差可以逐期变化。

数学定义与推导

$$X_t=X_{t-1}+u_t,\quad Y_t=X_t+v_t,\quad u_t\sim N(0,Q),\ v_t\sim N(0,R_t)$$

假设过程与测量噪声相互独立且跨期独立。给定历史，先验分布为正态，观测边际方差为预测状态方差加测量方差。

$$P_t^-=P_{t-1}+Q,\quad S_t=P_t^-+R_t,\quad K_t=P_t^-/S_t,\quad m_t=m_t^-+K_t(Y_t-m_t^-)$$

条件正态协方差公式给出Kalman增益。状态不确定性越大、测量越精确，增益越接近1；反之更依赖历史先验。

$$P_t=(1-K_t)^2P_t^-+K_t^2R_t,\quad \log p(Y_t\mid\mathcal F_{t-1})=-\tfrac12[\log(2\pi S_t)+e_t^2/S_t]$$

可复现样本与运行

30行样例初始m=0、P=1、Q=0.05。第一行观测0、R=0.2，先验方差1.05，创新方差1.25、后验方差0.168。程序输出两类方差供核对。

输出结构

结果解释与实证研究设计

若参数从训练样本估计，可将预测对数密度按共同测试日期相加评价；创新标准化后应检查其相关性及方差，以识别模型遗漏。

模型假设与适用边界

模型只进行前向过滤而不做全样本平滑；使用后验状态做下一期预测是合法的，但将本期后验当作本期观测前预测会造成信息泄漏。

完整C++17算法实现

实际算法使用标准C++17，输入为带表头的有序数值CSV，输出为具名字段的CSV。命令在仓库根目录执行；模型不会隐式读取外部行情或自动填补缺失数据。

#pragma once
#include "researchflow_ml.hpp"

namespace kline { namespace researchflow {
inline Report rolling_ar(const Mat& x,const Vec& p){
    validate(x,5,1,1);parameters(p,3);
    auto look=count(p[0],4,x.size()-1),order=count(p[1],1,std::min<std::size_t>(look-2,63));
    double lambda=positive(p[2]);require(double(x.size()-look)*look*order*order<=2e8,"AR work limit exceeded");Vec y=column(x,0);
    Mat design;for(std::size_t t=order;t<y.size();++t){
        Vec row;for(std::size_t j=1;j<=order;++j)row.push_back(y[t-j]);row.push_back(y[t]);design.push_back(row);
    }
    Report out{{"Period","Prediction","Actual","Persistence","SquaredError","PersistenceSquaredError"},{}};
    for(std::size_t t=look;t<y.size();++t){
        auto f=ridge_fit(design,t-look,t-order,lambda);
        double v=predict(f,design[t-order]),e=v-y[t],b=y[t-1]-y[t];
        out.rows.push_back({double(t),v,y[t],y[t-1],e*e,b*b});
    }
    return out;
}
inline Report rolling_var(const Mat& x,const Vec& p){
    std::size_t d=validate(x,5,2,16);parameters(p,2);
    auto look=count(p[0],3,x.size()-1);double lambda=positive(p[1]);
    require(double(x.size())*d*(d+1)<=5000000&&double(x.size()-look)*look*d*d*d<=2e8,"VAR work limit exceeded");
    std::vector<Mat> design(d);
    for(std::size_t t=1;t<x.size();++t){
        for(std::size_t j=0;j<d;++j){Vec row=x[t-1];row.push_back(x[t][j]);design[j].push_back(std::move(row));}
    }
    Report out{{"Period","Asset","Prediction","Actual","Persistence","SquaredError","PersistenceSquaredError"},{}};
    for(std::size_t t=look;t<x.size();++t){
        for(std::size_t j=0;j<d;++j){
            auto f=ridge_fit(design[j],t-look,t-1,lambda);
            double v=predict(f,design[j][t-1]),e=v-x[t][j],b=x[t-1][j]-x[t][j];
            out.rows.push_back({double(t),double(j+1),v,x[t][j],x[t-1][j],e*e,b*b});
        }
    }
    return out;
}
inline Report volatility_forecast(const Mat& x,const Vec& p){
    validate(x,2,1,1);parameters(p,5);
    double e=positive(p[0]),g=e,decay=p[1],omega=positive(p[2]),alpha=p[3],beta=p[4];
    require(decay>=0&&decay<1&&alpha>=0&&beta>=0&&alpha+beta<1,"Invalid variance dynamics");
    Report out{{"Period","Return","EWMAForecastVariance","GARCHForecastVariance","EWMAStandardized","GARCHStandardized","EWMAQLIKE","GARCHQLIKE"},{}};
    for(std::size_t t=0;t<x.size();++t){
        double r=x[t][0],q=r*r;
        positive(e);positive(g);
        out.rows.push_back({double(t),r,e,g,r/std::sqrt(e),r/std::sqrt(g),std::log(e)+q/e,std::log(g)+q/g});
        e=decay*e+(1-decay)*q;g=omega+alpha*q+beta*g;
    }
    return out;
}
inline Report regime_forecast(const Mat& x,const Vec& p){
    validate(x,4,2,2);parameters(p,2);
    auto look=count(p[0],2,x.size()-1);double prior=positive(p[1]);
    for(const auto& row:x)require(row[0]==0||row[0]==1,"State must be binary");
    Report out{{"Period","PreviousState","State","State1Probability","Brier","ConditionalReturnPrediction","ActualReturn","SquaredError"},{}};
    for(std::size_t t=look;t<x.size();++t){
        double transitions[2][2]={{prior,prior},{prior,prior}},amount[2]={0,0},n[2]={0,0};
        for(std::size_t i=t-look;i<t;++i){
            int s=int(x[i][0]);amount[s]+=x[i][1];n[s]+=1;
            if(i>t-look)transitions[int(x[i-1][0])][s]+=1;
        }
        int prev=int(x[t-1][0]);double q=transitions[prev][1]/(transitions[prev][0]+transitions[prev][1]);
        // The pooled mean is used when a state has no historical return observations.
        double pooled=(amount[0]+amount[1])/look,m0=n[0]?amount[0]/n[0]:pooled,m1=n[1]?amount[1]/n[1]:pooled;
        double pred=(1-q)*m0+q*m1;
        out.rows.push_back({double(t),double(prev),x[t][0],q,std::pow(q-x[t][0],2),pred,x[t][1],std::pow(pred-x[t][1],2)});
    }
    return out;
}
inline Report filter_forecast(const Mat& x,const Vec& p){
    validate(x,2,2,2);parameters(p,3);double state=p[0],v=p[1],q=p[2];
    require(v>=0&&q>=0,"Negative state variance");
    Report out{{"Period","PriorMean","PriorVariance","Observation","Innovation","InnovationVariance","PosteriorMean","PosteriorVariance","LogPredictiveDensity"},{}};
    for(std::size_t t=0;t<x.size();++t){
        double obs=x[t][0],r=positive(x[t][1]),a=v+q,s=positive(a+r),err=obs-state,k=a/s;
        double m=state+k*err,b=(1-k)*(1-k)*a+k*k*r;
        double ll=-.5*(std::log(2*std::acos(-1.0)*s)+err*err/s);
        out.rows.push_back({double(t),state,a,obs,err,s,m,b,ll});state=m;v=b;
    }
    return out;
}
