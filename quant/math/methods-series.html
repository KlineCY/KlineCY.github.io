MA(1)理论自协方差

模型与推导

展开乘积，白噪声跨期协方差为零，只在0和1阶存在共享创新。平稳MA不要求可逆；可逆性是从观测唯一恢复创新的额外条件。

$$X_t=\varepsilon_t+\theta\varepsilon_{t-1},\quad \operatorname{Var}\varepsilon_t=\sigma^2$$
$$\gamma_0=(1+\theta^2)\sigma^2,\quad\gamma_1=\theta\sigma^2,\quad\gamma_k=0\ (|k|>1)$$

研究应用与成立条件

报价反弹等短期结构可用MA模型解释。θ＝0.5、创新方差2，方差2.5，一阶相关0.4。实际估计须处理非平稳和交易时间间隔。

离散傅里叶单频功率与Parseval

模型与推导

离散傅里叶基在整数频率上正交，复指数内积给出实部和虚部，Parseval连接频域能量与时域平方和。本实现计算给定频点，不对完整谱平滑。

$$X_k=\sum_{t=0}^{n-1}x_te^{-2\pi ikt/n}$$
$$I_k=|X_k|^2/n,\qquad n^{-1}\sum_t x_t^2=n^{-2}\sum_k|X_k|^2$$

研究应用与成立条件

四点周期1、0、−1、0，在频点1的实部2，功率1。金融频域研究要区分趋势、非等距采样和谱泄漏；单峰不足以证明可交易周期。

重叠收益窗口的机械相关

模型与推导

独立单期收益的重叠累积和共享h−k项，机械地产生移动平均型相关。即使原始收益独立，重叠标签也不独立，故估计误差需按依赖调整。

$$Y_t=\sum_{j=0}^{h-1}r_{t-j},\quad \operatorname{Var}(r_t)=\sigma^2$$
$$\operatorname{Cov}(Y_t,Y_{t-k})=(h-|k|)_+\sigma^2$$

研究应用与成立条件

三日收益的相邻窗口共享两日，相关2／3；训练和验证切分应依据标签区间而非单纯行号。假设是加法收益、独立同方差。

季节差分与样本对齐

模型与推导

季节差分消除固定周期水平项，滞后算子的分解说明它也包含普通一阶差分。实现严格从首个可用滞后开始，不填补缺失行。

$$\Delta_s x_t=(1-L^s)x_t=x_t-x_{t-s}$$
$$(1-L^s)=(1-L)(1+L+\cdots+L^{s-1})$$

研究应用与成立条件

使用周期2的样本差分3、4、4。对财报同比可按实际季度对齐，而不是对有缺失的行机械差分；过度差分可能引入额外负自相关。

C++17实现

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace methods_series {
using namespace evidence;
inline Report ma_autocov(const Mat& x,const Vec& p){
    validate(x,1,1,1);
    parameters(p,2);
    double t=p[0],v=positive(p[1]),g=(1+t*t)*v;
    Report o{{"Lag","Autocovariance","Autocorrelation"},{}};
    for(auto&r:x){auto k=count(r[0],0,1000000);
    double a=k==0?g:k==1?t*v:0;
    o.rows.push_back({double(k),a,a/g});
    }return o;
    
}

inline Report harmonic_power(const Mat& x,const Vec& p){
    validate(x,2,1,1);
    parameters(p,1);
    auto n=x.size(),k=count(p[0],0,n-1);
    double a=0,b=0,s=0;
    for(std::size_t i=0;
    i<n;
    ++i){double w=2*std::acos(-1.)*k*i/n,z=x[i][0];
    a+=z*std::cos(w);
    b-=z*std::sin(w);
    s+=z*z;
    }return scalar({"Real","Imaginary","Periodogram","MeanSquare"},{a,b,(a*a+b*b)/n,s/n});
    
}

inline Report overlap_mean(const Mat& x,const Vec& p){
    validate(x,1,1,1);
    parameters(p,1);
    double v=positive(p[0]);
    Report o{{"Horizon","Variance","LagOneCovariance","LagOneCorrelation"},{}};
    for(auto&r:x){auto h=count(r[0],1,1000000);
    o.rows.push_back({double(h),h*v,(h-1)*v,double(h-1)/h});
    }return o;
    
}

inline Report seasonal_difference(const Mat& x,const Vec& p){
    validate(x,2,1,1);
    parameters(p,1);
    auto k=count(p[0],1,x.size()-1);
    Report o{{"Time","Current","Lagged","Difference"},{}};
    for(std::size_t i=k;
    i<x.size();
    ++i)o.rows.push_back({double(i+1),x[i][0],x[i-k][0],x[i][0]-x[i-k][0]});
    return o;
    
}
} }
