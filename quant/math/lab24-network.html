1．加权图拉普拉斯能量

模型结构与数学定义

以无向边的连接权重刻画节点之间的依赖强度。图拉普拉斯二次型衡量节点风险或因子得分在相连资产间的不一致程度。输入边表中的节点编号、连接权重和两个端点的标量状态，逐边计算能量贡献。

$$f^\top Lf=\sum_{i<j}w_{ij}(f_i-f_j)^2$$

推导、最优性条件与数值结构

$$L=D-W,\quad f^\top Df-f^\top Wf=\tfrac12\sum_{i,j}w_{ij}(f_i-f_j)^2$$

每条无向边在双重求和中出现两次，边列表只录入一次时不需要二分之一系数。能量为零表示每个连通分量内部状态恒定。

完整计算案例

两条边的权重为2、1，对应状态差为1、2，能量为2+4=6。

$$\mathrm{Output}\approx\left(6\right)$$

输出顺序：加权边状态差的平方和。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

2．带悬挂节点修正的PageRank

模型结构与数学定义

对有向加权图构造每个节点的出边归一化概率。每次迭代把现有概率质量沿出边分配，出度为零的节点将其质量均匀返还所有节点，再加入均匀随机跳转。输出节点排名概率。

$$\pi^{(k+1)}=(1-d)\mathbf1/n+dP^\top\pi^{(k)}$$

推导、最优性条件与数值结构

$$P_{ij}=w_{ij}/\sum_kw_{ik},\quad \mathbf1^\top\pi^{(k)}=1$$

所有非悬挂行通过归一化获得转移概率；悬挂节点对应均匀转移。阻尼参数小于1使迭代映射具有收缩性质，而概率总质量在每步保持为1。

完整计算案例

两个节点彼此连接，权重相同；无论阻尼0.85还是其他合法值，稳定分布均为(0.5,0.5)。

$$\mathrm{Output}\approx\left(0.5,\ 0.5\right)$$

输出顺序：按节点编号排列的稳定概率近似。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

3．图上热扩散的守恒离散演化

模型结构与数学定义

将每一条无向边上的状态差视为离散热通量。按同步更新计算相邻节点之间的净传递，在步长与最大加权度的乘积不超过1时，各节点更新为原状态与邻居状态的非负加权平均。输出演化后的全部节点状态。

$$f^{k+1}=f^k-hLf^k$$

推导、最优性条件与数值结构

$$f_i^{k+1}=(1-hd_i)f_i^k+h\sum_jw_{ij}f_j^k$$

当步长满足稳定性条件时，系数均非负且和为1，单步不会产生超过原最大值的状态。无向边上的净流在两个端点相互抵消，总质量守恒。

完整计算案例

两节点初始值分别为1、0，边权1，步长0.25，一步以后得到0.75、0.25，总和仍为1。

$$\mathrm{Output}\approx\left(0.75,\ 0.25\right)$$

输出顺序：每个节点演化后的状态。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

4．最小瓶颈路径与连通阈值

模型结构与数学定义

普通最短路对边距离求和；瓶颈路径则沿路径取最大边距离，再在候选路径间最小化。采用Dijkstra式松弛，将加法替换为max运算；每次确定尚未访问的最小瓶颈节点。它与单链接聚类的连通阈值等价。

$$b(s,t)=\min_{\gamma:s\leadsto t}\max_{e\in\gamma}d_e$$

推导、最优性条件与数值结构

$$b_v\leftarrow\min\{b_v,\max(b_u,d_{uv})\}$$

将最小化总长度的加法松弛替换为最大边权松弛，路径延伸不会降低已形成的瓶颈。已确定最小瓶颈的节点可安全完成标记。

完整计算案例

边0—1距离2、1—2距离3、0—2距离5，从0到2的最佳路径经节点1，瓶颈值为3。

$$\mathrm{Output}\approx\left(3\right)$$

5．Kruskal最小生成树

模型结构与数学定义

将所有无向边按距离从小到大排序。利用并查集跟踪连通分量，只有连接两个不同分量的边才被加入生成树，从而避免环并逐步构造最小总距离的树。输出树的总距离及最大选中边距离。

$$\min_{T\ {\rm spanning\ tree}}\sum_{(i,j)\in T}d_{ij}$$

推导、最优性条件与数值结构

$$|E(T)|=n-1,\qquad \text{weight}(T)=\sum_{e\in E(T)}w_e$$

切分性质保证跨越任一连通分量切分的最轻边可属于某个最小生成树。并查集仅连接不同分量，选入n−1条边后恰好获得连通无环图。

完整计算案例

三节点距离为2、3、5，选中前两条边，总距离5，最大边距离3。

$$\mathrm{Output}\approx\left(5,\ 3\right)$$

输出顺序：生成树总距离、选中边的最大距离。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

#pragma once
#include "lab24_common.hpp"
#include <functional>

namespace kline { namespace lab24 {
inline Vec laplacian_energy(const Mat& x,const Vec& p){
    inputs(x,p,5,0);double s=0;
    for(const auto& r:x){integer(r[0],0,100000);integer(r[1],0,100000);require(r[2]>=0,"Negative edge weight");double d=r[3]-r[4];s+=r[2]*d*d;}
    return checked({s});
}

inline Vec pagerank(const Mat& x,const Vec& p){
    inputs(x,p,3,3);auto n=integer(p[0],1,5000),steps=integer(p[2],1,10000);
    double d=p[1];require(d>=0&&d<1,"Invalid damping");
    Vec out(n,0),v(n,1.0/n);
    for(const auto& r:x){auto i=integer(r[0],0,n-1);integer(r[1],0,n-1);require(r[2]>=0,"Negative graph weight");out[i]+=r[2];}
    for(std::size_t k=0;k<steps;++k){
        double dangling=0;for(std::size_t i=0;i<n;++i)if(out[i]==0)dangling+=v[i];
        Vec z(n,(1-d+d*dangling)/n);
        for(const auto& r:x){auto i=std::size_t(r[0]),j=std::size_t(r[1]);if(out[i]>0)z[j]+=d*v[i]*r[2]/out[i];}
        v=std::move(z);
    }
    return checked(v);
}

inline Vec diffusion(const Mat& x,const Vec& p){
    require(p.size()>=3&&p.size()<=502,"Initial state and two parameters required");
    inputs(x,p,3,p.size());std::size_t n=p.size()-2;double h=p[0];auto steps=integer(p[1],1,10000);
    require(h>=0,"Negative diffusion step");Vec v(p.begin()+2,p.end()),degree(n,0);
    for(const auto& r:x){auto i=integer(r[0],0,n-1),j=integer(r[1],0,n-1);require(i!=j&&r[2]>=0,"Invalid edge");degree[i]+=r[2];degree[j]+=r[2];}
    require(h*(*std::max_element(degree.begin(),degree.end()))<=1,"Explicit diffusion violates stability bound");
    for(std::size_t k=0;k<steps;++k){Vec z=v;for(const auto& r:x){auto i=std::size_t(r[0]),j=std::size_t(r[1]);double flow=h*r[2]*(v[j]-v[i]);z[i]+=flow;z[j]-=flow;}v=std::move(z);}
    return checked(v);
}

inline Vec minimax_path(const Mat& x,const Vec& p){
    inputs(x,p,3,3);auto n=integer(p[0],1,1000),s=integer(p[1],0,n-1),t=integer(p[2],0,n-1);
    std::vector<std::vector<std::pair<std::size_t,double>>> adj(n);
    for(const auto& r:x){auto i=integer(r[0],0,n-1),j=integer(r[1],0,n-1);require(r[2]>=0,"Negative distance");adj[i].push_back({j,r[2]});adj[j].push_back({i,r[2]});}
    Vec d(n,std::numeric_limits<double>::infinity());d[s]=0;std::vector<bool> done(n,false);
    for(std::size_t k=0;k<n;++k){std::size_t u=n;for(std::size_t i=0;i<n;++i)if(!done[i]&&(u==n||d[i]<d[u]))u=i;if(u==n||!std::isfinite(d[u]))break;done[u]=true;if(u==t)break;for(auto e:adj[u])d[e.first]=std::min(d[e.first],std::max(d[u],e.second));}
    require(std::isfinite(d[t]),"Target unreachable");
    return {d[t]};
}

inline Vec minimum_spanning_tree(const Mat& x,const Vec& p){
    inputs(x,p,3,1);auto n=integer(p[0],2,10000);Mat edges=x;
    for(const auto& r:edges){integer(r[0],0,n-1);integer(r[1],0,n-1);require(r[2]>=0,"Negative edge distance");}
    std::sort(edges.begin(),edges.end(),[](const Vec& a,const Vec& b){return a[2]<b[2];});
    std::vector<std::size_t> parent(n);std::iota(parent.begin(),parent.end(),0);
    auto root=[&](std::size_t i){while(parent[i]!=i){parent[i]=parent[parent[i]];i=parent[i];}return i;};
    std::size_t used=0;double total=0,last=0;
    for(const auto& r:edges){auto a=root(std::size_t(r[0])),b=root(std::size_t(r[1]));if(a==b)continue;parent[a]=b;total+=r[2];last=r[2];if(++used==n-1)break;}
    require(used==n-1,"Graph disconnected");return checked({total,last});
}
} }

using Vec=std::vector<double>;
using Mat=std::vector<Vec>;

inline void inputs(const Mat& x,const Vec& p,std::size_t cols,std::size_t params,
                   std::size_t min_rows=1) {
    require(x.size()>=min_rows&&x.size()<=250000,"Invalid number of observations");
    require(p.size()==params,"Incorrect scalar parameter count");
    for(double v:p)require(std::isfinite(v),"Nonfinite scalar parameter");
    for(const auto& row:x){
        require(row.size()==cols,"Unexpected CSV column count");
        for(double v:row)require(std::isfinite(v),"Nonfinite matrix entry");
    }
}
inline std::size_t integer(double x,std::size_t low,std::size_t high){
    require(std::isfinite(x)&&x>=double(low)&&x<=double(high)&&std::floor(x)==x,
            "Integer parameter outside allowed range");
    return std::size_t(x);
}
inline double dot(const Vec& a,const Vec& b){
    require(a.size()==b.size(),"Dot product dimension mismatch");
    return std::inner_product(a.begin(),a.end(),b.begin(),0.0);
}
inline Vec col(const Mat& x,std::size_t j){
    Vec out;out.reserve(x.size());
    for(const auto& row:x)out.push_back(row.at(j));
    return out;
}
inline double positive(double x){require(x>0&&std::isfinite(x),"Positive finite quantity required");return x;}
inline Vec checked(Vec v){check_finite(v);return v;}
inline double logistic(double x){
    if(x>=0)return 1/(1+std::exp(-x));
    double e=std::exp(x);return e/(1+e);
}
inline double normal_cdf(double x){return 0.5*std::erfc(-x/std::sqrt(2.0));}
inline double sum(const Vec& v){return std::accumulate(v.begin(),v.end(),0.0);}
