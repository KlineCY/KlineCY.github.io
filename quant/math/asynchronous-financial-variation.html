1．Hayashi–Yoshida异步收益协方差

数学对象与估计量

$$\widehat{[X,Y]}=\sum_{i,j}\Delta X_i\Delta Y_j\,\mathbf 1\{(t_{i-1},t_i]\cap(s_{j-1},s_j]\ne\varnothing\}$$

统计结构与推导

两个资产的收益以各自上次成交与本次成交间隔定义。只要两个收益区间的时间内部存在重合，协方差估计就纳入这两个增量的乘积。算法用两个指针遍历已排序且无自重叠的区间，不必强行把成交时钟同步到固定频率。

数值计算与经济解释

资产A两个收益区间为(0,1]与(1,2]，收益分别为0.1和0.2；资产B区间为(0,0.5]与(0.5,2]，收益分别为0.3和0.4。三组有效重叠贡献为0.03、0.04和0.08，合计0.15。

识别条件、数据口径与边界

此方法的时间标签表示区间端点，收益需与各自价格增量准确对应。异步协变差对微观结构噪声、交易不同步及跳跃的统计性质有所不同；算法计算估计量本身，不代替噪声修正或显著性检验。

CSV或参数复算

./kline_quant hy-cov async.csv StartA EndA RetA StartB EndB RetB

2．已实现四次变差

数学对象与估计量

$$\widehat{IQ}=\frac{n}{3}\sum_{i=1}^n(\Delta_iX)^4$$

统计结构与推导

在固定日内窗口与适当高频渐近条件下，四次收益幂能够识别连续扩散波动的积分四次变差。高阶幂对极端价格跳跃更加敏感，在研究中常与已实现方差共同检视风险测度的渐近不确定性。

数值计算与经济解释

观察两个收益增量1与2的纯数学例子，对应四次幂求和为17，因此该定义得到2×17／3，即约11.3333。实际收益为百分数或小数时，四次方尺度相差八个数量级，需要统一单位。

识别条件、数据口径与边界

当存在大跳跃时，未截断的四次幂会受到跳跃主导；不同文献对四次变差的标准化和采样间隔有不同口径，应按研究使用的估计量确定解释。

CSV或参数复算

./kline_quant realized-quarticity ticks.csv Return

3．一阶Bartlett权重的已实现核

数学对象与估计量

$$\widehat K_1=\sum_{i=1}^nr_i^2+\sum_{i=2}^nr_ir_{i-1}$$

统计结构与推导

已实现核通过对相邻收益乘积赋权，把微观结构噪声导致的短期负自相关纳入计算。这里采用单个滞后、Bartlett权重为二分之一的简化核，二倍加权项最终恰为相邻收益乘积之和。

数值计算与经济解释

收益序列为1、2、3时，平方和为14，滞后一阶乘积和为2+6=8，因此核估计值为22。例子突出估计量的代数结构，不将其视为实际资产方差的合理数值。

识别条件、数据口径与边界

实际噪声稳健已实现核通常还涉及端点修正、带宽选择、不同滞后核与交易时钟抽样。单滞后形式用于理解序列相关项，无法自动消除所有高频噪声。

CSV或参数复算

./kline_quant kernel-1 ticks.csv Return

4．阈值截断已实现方差

数学对象与估计量

$$\mathrm{TRV}(u)=\sum_{i=1}^nr_i^2\mathbf1\{|r_i|\le u\}$$

统计结构与推导

以固定阈值过滤绝对收益过大的观测，再对其余收益平方求和，可以把可能由稀疏跳跃驱动的极端增量与日常连续波动区分。截断决定规则应先于样本外比较确定。

数值计算与经济解释

收益为0.1、0.3和-0.2，阈值为0.2时，中间的0.3被排除，其余两项平方和为0.01+0.04=0.05。阈值等于绝对增量时仍予以保留。

识别条件、数据口径与边界

阈值应随价格尺度、采样频率与波动状态调整。若把任意固定阈值直接用于不同市场，可能把正常波动错误识别为跳跃；该实现报告确定性的截断平方和。

CSV或参数复算

./kline_quant truncated-rv ticks.csv Return 0.02

#pragma once
#include "stats.hpp"
#include <algorithm>
#include <cmath>
#include <vector>
namespace kline {
inline double hayashi_yoshida_covariance(
 const std::vector<double>& startA,const std::vector<double>& endA,
 const std::vector<double>& returnA,const std::vector<double>& startB,
 const std::vector<double>& endB,const std::vector<double>& returnB) {
 check_finite(startA);check_finite(endA);check_finite(returnA);
 check_finite(startB);check_finite(endB);check_finite(returnB);
 require(startA.size()==endA.size()&&startA.size()==returnA.size()&&
         startB.size()==endB.size()&&startB.size()==returnB.size(),
         "Timestamp and asynchronous returns disagree");
 for(std::size_t i=0;i<startA.size();++i)
   require(startA[i]<endA[i]&&(i==0||startA[i]>=endA[i-1]),
           "Intervals A must be disjoint, sorted and positive");
 for(std::size_t i=0;i<startB.size();++i)
   require(startB[i]<endB[i]&&(i==0||startB[i]>=endB[i-1]),
           "Intervals B must be disjoint, sorted and positive");
 double sum=0;std::size_t i=0,j=0;
 while(i<startA.size()&&j<startB.size()) {
   if(std::min(endA[i],endB[j])>std::max(startA[i],startB[j]))
      sum+=returnA[i]*returnB[j];
   if(endA[i]<=endB[j])++i; else ++j;
 }
 return sum;
}
inline double realized_quarticity(const std::vector<double>& logReturns) {
 check_finite(logReturns);
 double sum=0;
 for(double r:logReturns)sum+=r*r*r*r;
 return double(logReturns.size())/3.0*sum;
}
inline double one_lag_bartlett_realized_kernel(const std::vector<double>& logReturns){
 check_finite(logReturns);
 require(logReturns.size()>=2,"Two returns required for realized kernel");
 double gamma0=0,gamma1=0;
 for(double r:logReturns)gamma0+=r*r;
 for(std::size_t i=1;i<logReturns.size();++i)
   gamma1+=logReturns[i]*logReturns[i-1];
 return gamma0+gamma1;
}
inline double truncated_realized_variance(
 const std::vector<double>& logReturns,double threshold) {
 check_finite(logReturns);
 require(std::isfinite(threshold)&&threshold>0,
         "Truncation threshold must be positive");
 double sum=0;
 for(double r:logReturns)if(std::abs(r)<=threshold)sum+=r*r;
 return sum;
}
}
