概率单纯形欧氏投影

模型与推导

拉格朗日乘子θ对应预算约束，非负约束互补松弛得到截断形式。排序后遍历活跃集，最大满足排序值大于临时阈值的位置决定唯一θ，复杂度O(d log d)。

$$\min_{w\ge0,\ \mathbf1^\top w=1}\frac12\|w-z\|^2$$
$$w_i=(z_i-\theta)_+,\qquad \sum_i(z_i-\theta)_+=1$$

研究应用与成立条件

目标权重0.8、0.6、−0.2投影为0.6、0.4、0。适合投影梯度法中的无空头预算步骤；有上下限、行业约束或交易成本时须另外处理。

预算约束对角二次规划KKT

模型与推导

对每个权重求梯度并引入预算乘子，得到线性驻点；代入预算解出η。所有d_i正且γ正，目标严格凸，驻点为全局唯一最优。允许负权重。

$$\min_{\mathbf1^\top w=1}\tfrac{\gamma}{2}\sum_i d_iw_i^2-\sum_i\mu_iw_i$$
$$w_i=(\mu_i-\eta)/(\gamma d_i),\quad \eta=\frac{\sum_i\mu_i/d_i-\gamma}{\sum_i1/d_i}$$

研究应用与成立条件

均值0.3、0.1与对角风险1、2，风险厌恶1，解11／15与4／15；驻点残差应为零。无空头约束时需另做活跃集优化。

熵正则化线性决策

模型与推导

内点一阶条件使权重与指数效用成比例，归一化得到Softmax；熵严格凹保证唯一解。参数为逆温度，减去最大效用后计算指数防溢出。

$$\max_{w\in\Delta}\ u^\top w-\tau\sum_iw_i\log w_i$$
$$w_i=e^{u_i/\tau}/\sum_j e^{u_j/\tau},\quad V=\tau\log\sum_i e^{u_i/\tau}$$

研究应用与成立条件

三个相同信号、逆温度2，权重各1／3。温度降低使配置更集中；该模型未包含资产协方差、交易约束，不能直接替代均值方差配置。

二次目标的精确步长

模型与推导

沿下降方向的目标是一维严格凸二次函数，导数置零得到精确步长。需gᵀd负且曲率正，目标下降量为方向导数平方除以两倍曲率。

$$f(x+\alpha d)=f(x)+\alpha g^\top d+\tfrac12\alpha^2d^\top Qd$$
$$\alpha^*=-g^\top d/(d^\top Qd)$$

研究应用与成立条件

对角曲率2、4，梯度2、4，取负梯度方向，导数−20、曲率72，步长5／18。非二次目标仅是局部近似，宜使用Armijo等回溯。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace methods_optimization {
using namespace evidence;
inline Report simplex_projection(const Mat& x,const Vec& p){
    validate(x,1,1,1);
    parameters(p,0);
    Vec z=column(x,0),s=z;
    std::sort(s.begin(),s.end(),std::greater<double>());
    double sum=0,theta=0;
    for(std::size_t i=0;
    i<s.size();
    ++i){sum+=s[i];
    double t=(sum-1)/(i+1);
    if(s[i]>t)theta=t;
    }Report o{{"Index","Weight","Threshold"},{}};
    for(std::size_t i=0;
    i<z.size();
    ++i)o.rows.push_back({double(i+1),std::max(0.,z[i]-theta),theta});
    return o;
    
}

inline Report diagonal_kkt(const Mat& x,const Vec& p){
    validate(x,1,2,2);
    parameters(p,1);
    double g=positive(p[0]),a=0,b=0;
    for(auto&r:x){a+=r[0]/positive(r[1]);
    b+=1/r[1];
    }double eta=(a-g)/b;
    Report o{{"Asset","Weight","Multiplier","StationarityResidual"},{}};
    for(std::size_t i=0;
    i<x.size();
    ++i){auto&r=x[i];
    double w=(r[0]-eta)/(g*r[1]);
    o.rows.push_back({double(i+1),w,eta,g*r[1]*w-r[0]+eta});
    }return o;
    
}

inline Report entropic_prox(const Mat& x,const Vec& p){
    validate(x,1,1,1);
    parameters(p,1);
    double b=positive(p[0]);
    Vec u=column(x,0);
    double m=*std::max_element(u.begin(),u.end()),s=0;
    Vec w;
    for(double z:u){w.push_back(std::exp(b*(z-m)));
    s+=w.back();
    }double v=m+std::log(s)/b;
    Report o{{"Asset","Weight","Objective"},{}};
    for(std::size_t i=0;
    i<u.size();
    ++i)o.rows.push_back({double(i+1),w[i]/s,v});
    return o;
    
}

inline Report quadratic_line_search(const Mat& x,const Vec& p){
    validate(x,1,3,3);
    parameters(p,0);
    double a=0,b=0;
    for(auto&r:x){positive(r[0]);
    a+=r[1]*r[2];
    b+=r[0]*r[2]*r[2];
    }require(a<0,"Descent direction required");
    positive(b);
    return scalar({"Step","DirectionalDerivative","Curvature","ObjectiveDecrease"},{-a/b,a,b,a*a/(2*b)});
    
}
