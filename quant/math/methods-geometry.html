改进Gram–Schmidt正交分解

模型与推导

逐列对当前残差而非原列投影，构成改进Gram–Schmidt；对每列记录残差范数和与已有正交列的最大内积。秩亏或接近秩亏时拒绝，避免除以极小范数。复杂度为O(nd²)，空间O(nd)。

$$v_j=a_j-\sum_{i<j}q_i(q_i^\top v_j),\quad r_{jj}=\|v_j\|_2,\quad q_j=v_j/r_{jj}$$
$$A=QR,\quad Q^\top Q=I$$

研究应用与成立条件

在横截面多因子暴露中，第一列和第二列的范数分别√2和√3且正交。正交分解可减少正规方程的条件数平方问题，但列顺序影响分解，近秩亏时应使用带主元QR或SVD。

Sherman–Morrison秩一逆矩阵

模型与推导

对角正定矩阵加一个因子外积时，逆矩阵修正仍为秩一。将候选逆左乘原矩阵，外积项相消；行列式引理由同一标量给出。输出逆矩阵对角和行列式倍率，时间O(d)。

$$(D+uu^\top)^{-1}=D^{-1}-\frac{D^{-1}uu^\top D^{-1}}{1+u^\top D^{-1}u}$$
$$\det(D+uu^\top)=\det(D)(1+u^\top D^{-1}u)$$

研究应用与成立条件

对角特异风险2、3与单因子载荷1、2，倍率17／6。可快速计算低秩风险模型的精度矩阵对角，输入必须正定，不能将一般多因子矩阵直接代入对角公式。

Gershgorin谱区间与正定充分条件

模型与推导

对特征向量选绝对值最大的分量并展开对应行，得到圆盘约束。实对称矩阵的特征值为实数，圆盘退化为实轴区间；所有下界严格正即正定充分条件。

$$\lambda(A)\subseteq\bigcup_i\{z:|z-a_{ii}|\leq\sum_{j\ne i}|a_{ij}|\}$$
$$A=A^\top,\ \min_i(a_{ii}-\sum_{j\ne i}|a_{ij}|)>0\Longrightarrow A\succ0$$

研究应用与成立条件

协方差矩阵对角占优时可用此廉价证书诊断，例中全局下界1。下界非正不证明非正定，应使用Cholesky或精确谱分解。

协方差特征值有效秩

模型与推导

对非负谱归一化为概率，平方集中度的倒数与熵的指数分别刻画有效维数。谱全相等时等于维数，单一非零谱时等于1；它们不等于代数秩。

$$p_i=\lambda_i/\sum_j\lambda_j,\qquad r_{\mathrm{PR}}=1/\sum_i p_i^2$$
$$r_H=\exp(-\sum_{i:p_i>0}p_i\log p_i)$$

研究应用与成立条件

谱4、1、1的参与秩2，说明能量集中。可比较不同资产集合的风险维度，但需统一变量尺度；非PSD输入不具有该概率解释。

C++17实现

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace methods_geometry {
using namespace evidence;
inline Report gram_schmidt(const Mat& x,const Vec& p){
    auto d=validate(x,2,1,64);
    parameters(p,0);
    require(x.size()>=d,"Tall matrix required");
    Mat Q;
    Report out{{"Column","RDiagonal","OrthogonalityError"},{}};
    for(std::size_t j=0;
    j<d;
    ++j){Vec v=column(x,j);
    double scale=std::sqrt(dot(v,v));
    for(const auto&q:Q){double r=dot(q,v);
    for(std::size_t i=0;
    i<v.size();
    ++i)v[i]-=r*q[i];
    }double n=std::sqrt(dot(v,v));
    require(n>1e-12*positive(scale),"Rank deficient column");
    for(auto&z:v)z/=n;
    double e=std::abs(dot(v,v)-1);
    for(const auto&q:Q)e=std::max(e,std::abs(dot(v,q)));
    Q.push_back(v);
    out.rows.push_back({double(j+1),n,e});
    }return out;
    
}

inline Report rank_one_inverse(const Mat& x,const Vec& p){
    validate(x,1,2,2);
    parameters(p,0);
    double den=1;
    for(auto&r:x)den+=r[1]*r[1]/positive(r[0]);
    Report o{{"Index","InverseDiagonal","DetRatio"},{}};
    for(std::size_t i=0;
    i<x.size();
    ++i){auto&r=x[i];
    double a=1/r[0],b=a*r[1];
    o.rows.push_back({double(i+1),a-b*b/den,den});
    }return o;
    
}

inline Report gershgorin(const Mat& x,const Vec& p){
    auto d=validate(x,1,1,64);
    parameters(p,0);
    require(x.size()==d,"Square matrix required");
    Report o{{"Row","Lower","Upper","GlobalLower"},{}};
    double low=std::numeric_limits<double>::infinity();
    for(std::size_t i=0;
    i<d;
    ++i){double r=0;
    for(std::size_t j=0;
    j<d;
    ++j){require(std::abs(x[i][j]-x[j][i])<=1e-10*std::max({1.,std::abs(x[i][j]),std::abs(x[j][i])}),"Symmetric matrix required");
    if(i!=j)r+=std::abs(x[i][j]);
    }low=std::min(low,x[i][i]-r);
    o.rows.push_back({double(i+1),x[i][i]-r,x[i][i]+r,0});
    }for(auto&r:o.rows)r.back()=low;
    return o;
    
}

inline Report spectral_participation(const Mat& x,const Vec& p){
    validate(x,1,1,1);
    parameters(p,0);
    double s=0;
    for(auto&r:x){require(r[0]>=0,"Negative eigenvalue");
    s+=r[0];
    }positive(s);
    double q=0,h=0;
    for(auto&r:x){double v=r[0]/s;
    q+=v*v;
    if(v>0)h-=v*std::log(v);
    }return scalar({"Trace","ParticipationRank","EntropyRank"},{s,1/q,std::exp(h)});
    
}
