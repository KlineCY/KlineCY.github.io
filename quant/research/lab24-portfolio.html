多资产组合构建必须将风险模型、目标头寸与执行可行性放入同一数学框架。线性因子约束与风险预算解决暴露和风险分配问题，交易成本则通过近端映射改变无成本目标权重。

1．双约束最小扰动的因子中性投影

模型结构与数学定义

将目标头寸向量投影到指定净敞口和单因子暴露的线性约束集合。根据拉格朗日条件，最小二乘扰动必位于两行约束向量的张成空间内。求解二维Gram系统得到乘子，并减去相应调整量。

$$w=z-A^\top(AA^\top)^{-1}(Az-b),\quad A=\begin{pmatrix}\mathbf1^\top\\f^\top\end{pmatrix}$$

推导、最优性条件与数值结构

$$AA^\top=\begin{pmatrix}n&\sum_i f_i\\ \sum_i f_i&\sum_i f_i^2\end{pmatrix},\quad \det(AA^\top)=n\sum_i(f_i-\bar f)^2$$

从目标权重扣除约束行向量的线性组合，使新权重满足约束。两个乘子由Gram矩阵确定；若因子载荷完全相同，第二个约束与预算约束线性相关，矩阵不可逆。

完整计算案例

三个资产的原始头寸为(1,1,1)，因子载荷为(−1,0,1)，要求净敞口和因子暴露均为0，最小扰动解为三个零头寸。

$$\mathrm{Output}\approx\left(0,\ 0,\ 0\right)$$

输出顺序：各资产投影后的带符号权重。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

2．对角协方差下的风险预算组合

模型结构与数学定义

无相关资产的波动风险贡献比例为w_i²σ_i²除以组合方差。令这一比例等于预算b_i，直接反解w_i与√b_i/σ_i成正比。归一化后输出满足全额投资的组合权重。

$$w_i=\frac{\sqrt{b_i}/\sigma_i}{\sum_j\sqrt{b_j}/\sigma_j}$$

推导、最优性条件与数值结构

$$RC_i=\frac{w_i^2\sigma_i^2}{\sigma_p},\qquad b_i=\frac{RC_i}{\sigma_p}=\frac{w_i^2\sigma_i^2}{\sum_jw_j^2\sigma_j^2}$$

由Euler齐次函数分解，波动率对资产权重的边际贡献为w_iσ_i²除以组合波动率。乘权重后得到绝对风险贡献，再除以总风险即为风险预算比例。

完整计算案例

两个资产波动率为1和2，风险预算均为0.5，权重比例为2:1，得到(2/3,1/3)。两项加权波动率相等，风险预算也相等。

$$\mathrm{Output}\approx\left(0.666666667,\ 0.333333333\right)$$

输出顺序：各资产满足目标风险预算的权重。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

3．单公共因子模型的系统性与特质风险

模型结构与数学定义

由因子收益模型r_i=β_if+ε_i以及特质残差互不相关、与因子不相关的假设，组合收益方差可分为因子暴露平方乘因子方差与各特质方差加权平方。返回净因子载荷、系统性方差、特质方差和总波动率。

$$\Sigma=\sigma_f^2\beta\beta^\top+\operatorname{diag}(\sigma_{\epsilon,i}^2),\quad \sigma_p^2=\sigma_f^2(w^\top\beta)^2+\sum_iw_i^2\sigma_{\epsilon,i}^2$$

推导、最优性条件与数值结构

$$r_p=(\sum_iw_i\beta_i)f+\sum_iw_i\epsilon_i,\quad \operatorname{Cov}(f,\epsilon_i)=\operatorname{Cov}(\epsilon_i,\epsilon_j)=0\ (i\ne j)$$

把持仓加权收益代入因子结构，方差的交叉项在零协方差假设下消失。系统性风险由所有资产的净载荷共同决定，特质风险则由各资产权重平方相加决定。

完整计算案例

两资产各权重0.5，载荷均为1，特质方差均为1，公共因子方差为1。系统性方差1，特质方差0.5，总波动√1.5。

$$\mathrm{Output}\approx\left(1,\ 1,\ 0.5,\ 1.22474487\right)$$

输出顺序：因子净暴露、系统性方差、特质方差、总波动率。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

4．交易成本下的逐资产不交易区间

模型结构与数学定义

将每资产目标偏离的平方损失与线性换手成本相加，目标函数按资产分离。通过对增量头寸求次梯度，交易量为原目标变动经成本阈值软缩减后的结果。输出新头寸向量。

$$w_i=w_i^{old}+\operatorname{sgn}(z_i-w_i^{old})\left(|z_i-w_i^{old}|-\frac{c_i}{a_i}\right)_+$$

推导、最优性条件与数值结构

$$\min_{\Delta w_i}\tfrac{a_i}{2}(\Delta w_i-z_i+w_i^{old})^2+c_i|\Delta w_i|$$

将旧头寸平移为增量变量。在零交易点，L1项的次梯度区间为[−c_i,c_i]，当目标偏移的边际收益不足以超过成本时，零交易满足一阶条件。

完整计算案例

旧权重0.2、0.4，目标0.5、0.35，惩罚曲率均1、成本0.1，则第一资产调至0.4，第二资产差值0.05在不交易区间内，仍为0.4。

$$\mathrm{Output}\approx\left(0.4,\ 0.4\right)$$

输出顺序：每个资产调整后的权重。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

5．再平衡前权重漂移与实现换手

模型结构与数学定义

先利用资产回报推进各持仓的金额，再除以组合总金额得到实际再平衡前权重。将目标与漂移后权重比较，半L1距离给出全额投资长仓组合的单边换手。输出组合期收益、单边换手和全部漂移权重。

$$\widetilde w_{i,t}=\frac{w_{i,t-1}(1+r_{i,t})}{1+\sum_jw_{j,t-1}r_{j,t}},\quad TO_t=\tfrac12\sum_i|w_{i,t}^*-\widetilde w_{i,t}|$$

推导、最优性条件与数值结构

$$V_t=V_{t-1}\sum_i w_{i,t-1}(1+r_{i,t}),\qquad \sum_i\widetilde w_{i,t}=1$$

再平衡前的资产金额各自随回报变化，金额归一化后得到漂移权重。在目标与原权重都和为1时，买入总额等于卖出总额，故总绝对变化量的一半对应单边换手。

完整计算案例

起始等权，两资产回报0.2、0，组合收益0.1；漂移权重分别为6/11、5/11，回归等权的单边换手为1/22。

$$\mathrm{Output}\approx\left(0.1,\ 0.0454545455,\ 0.545454545,\ 0.454545455\right)$$

独立算法

#pragma once
#include "lab24_common.hpp"
#include <map>

namespace kline { namespace lab24 {
inline Vec factor_neutral_two(const Mat& x,const Vec& p){
    inputs(x,p,2,2,2);Vec z=col(x,0),f=col(x,1);
    double n=double(x.size()),sf=sum(f),ff=dot(f,f),d=positive(n*ff-sf*sf);
    double e=sum(z)-p[0],g=dot(z,f)-p[1],a=(ff*e-sf*g)/d,b=(n*g-sf*e)/d;
    for(std::size_t i=0;i<z.size();++i)z[i]-=a+b*f[i];
    return checked(z);
}

inline Vec risk_budget_diag(const Mat& x,const Vec& p){
    inputs(x,p,2,0);double b=0;Vec w;
    for(const auto& r:x){positive(r[0]);require(r[1]>=0,"Negative risk budget");b+=r[1];w.push_back(std::sqrt(r[1])/r[0]);}
    require(std::abs(b-1)<1e-10,"Risk budgets must sum to one");double z=positive(sum(w));
    for(double& q:w){q/=z;}
    return checked(w);
}

inline Vec factor_cov_risk(const Mat& x,const Vec& p){
    inputs(x,p,3,1);require(p[0]>=0,"Negative factor variance");double beta=0,idio=0;
    for(const auto& r:x){require(r[2]>=0,"Negative idiosyncratic variance");beta+=r[0]*r[1];idio+=r[0]*r[0]*r[2];}
    double sys=p[0]*beta*beta;return checked({beta,sys,idio,std::sqrt(sys+idio)});
}

inline Vec turnover_prox(const Mat& x,const Vec& p){
    inputs(x,p,4,0);Vec w;
    for(const auto& r:x){positive(r[2]);require(r[3]>=0,"Negative trading cost");double d=r[1]-r[0];w.push_back(r[0]+std::copysign(std::max(0.0,std::abs(d)-r[3]/r[2]),d));}
    return checked(w);
}

inline Vec rebalance_drift(const Mat& x,const Vec& p){
    inputs(x,p,3,0);double old=0,target=0,ret=0;
    for(const auto& r:x){require(r[0]>=0&&r[2]>=0&&r[1]>=-1,"Invalid long-only return or weight");old+=r[0];target+=r[2];ret+=r[0]*r[1];}
    require(std::abs(old-1)<1e-10&&std::abs(target-1)<1e-10,"Weights must sum to one");double gross=positive(1+ret),to=0;Vec v;
    for(const auto& r:x){double w=r[0]*(1+r[1])/gross;v.push_back(w);to+=std::abs(w-r[2]);}
    Vec out={ret,to/2};out.insert(out.end(),v.begin(),v.end());return checked(out);
}
} }

#pragma once

#include <utility>

namespace kline { namespace lab24 {
using Vec=std::vector<double>;
using Mat=std::vector<Vec>;

inline void inputs(const Mat& x,const Vec& p,std::size_t cols,std::size_t params,
                   std::size_t min_rows=1) {
    require(x.size()>=min_rows&&x.size()<=250000,"Invalid number of observations");
    require(p.size()==params,"Incorrect scalar parameter count");
    for(double v:p)require(std::isfinite(v),"Nonfinite scalar parameter");
    for(const auto& row:x){
        require(row.size()==cols,"Unexpected CSV column count");
        for(double v:row)require(std::isfinite(v),"Nonfinite matrix entry");
    }
}
inline std::size_t integer(double x,std::size_t low,std::size_t high){
    require(std::isfinite(x)&&x>=double(low)&&x<=double(high)&&std::floor(x)==x,
            "Integer parameter outside allowed range");
    return std::size_t(x);
}
inline double dot(const Vec& a,const Vec& b){
    require(a.size()==b.size(),"Dot product dimension mismatch");
    return std::inner_product(a.begin(),a.end(),b.begin(),0.0);
}
inline Vec col(const Mat& x,std::size_t j){
    Vec out;out.reserve(x.size());
    for(const auto& row:x)out.push_back(row.at(j));
    return out;
}
inline double positive(double x){require(x>0&&std::isfinite(x),"Positive finite quantity required");return x;}
inline Vec checked(Vec v){check_finite(v);return v;}
inline double logistic(double x){
    if(x>=0)return 1/(1+std::exp(-x));
    double e=std::exp(x);return e/(1+e);
}
inline double normal_cdf(double x){return 0.5*std::erfc(-x/std::sqrt(2.0));}
inline double sum(const Vec& v){return std::accumulate(v.begin(),v.end(),0.0);}
} }
