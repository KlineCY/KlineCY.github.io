横截面估计噪声

单个资产Alpha的样本估计具有较大标准误，不同资产的估计精度可能差异显著。层级正态模型把真实Alpha视为来自共同分布，观测估计围绕真实Alpha波动。与统一收缩比例不同，异方差经验贝叶斯对高噪声资产进行更强收缩。

$$\hat a_i\mid a_i\sim N(a_i,s_i^2),\qquad a_i\sim N(m,\tau^2),\qquad \hat a_i\sim N(m,s_i^2+\tau^2)$$

边际似然剖面

固定先验方差τ²，均值m的边际MLE为逆总方差加权平均。将m代入边际高斯似然后，在指定非负τ²网格中选最优候选。零先验方差意味着完全池化，是合法边界；此时不应把数值微小的正方差当作必要条件。

$$\hat m(\tau^2)=\frac{\sum_i\hat a_i/(s_i^2+\tau^2)}{\sum_i1/(s_i^2+\tau^2)},\quad \ell=\tfrac12\sum_i\{\log(2\pi(s_i^2+\tau^2))+(\hat a_i-m)^2/(s_i^2+\tau^2)\}$$

后验与预测

由正态共轭得到后验均值m加信号差乘τ²/(τ²+s²)，后验方差为τ²s²/(τ²+s²)。这里输出Shrinkage为向先验收缩的比例s²/(τ²+s²)。后验均值方差仅在估计超参数被视为固定时成立，不包含超参数估计不确定性。

$$E[a_i\mid\hat a_i]=m+\frac{\tau^2}{\tau^2+s_i^2}(\hat a_i-m),\quad V[a_i\mid\hat a_i]=\frac{\tau^2s_i^2}{\tau^2+s_i^2}$$

精确算例

两资产Alpha估计−1、1，抽样方差各1，固定τ²=1时m=0、后验均值±.5、后验方差.5。复杂度O(nG)。相关Alpha估计误差、共同因子和横截面选择会改变独立层级假设；实证必须使用同一历史信息集并与独立留出收益比较。

$$\tau^2=0\Longrightarrow E[a_i\mid\hat a_i]=m,\quad V[a_i\mid\hat a_i]=0$$

inline Report empirical_bayes_alpha_grid(const Mat& x,const Vec& p){
    validate(x,2,2,2);parameters(p,3);auto G=count(p[2],2,100000);
    require(p[0]>=0&&p[1]>=p[0]&&double(G)*x.size()<=5e7,"Invalid EB grid");
    for(auto&r:x)positive(r[1]);double best=std::numeric_limits<double>::infinity(),tau=0,m=0;
    for(std::size_t j=0;j<G;++j){
        double t=p[0]+(p[1]-p[0])*j/(G-1),num=0,den=0;
        for(auto&r:x){double v=r[1]+t;num+=r[0]/v;den+=1/v;}
        double a=num/positive(den),f=0;
        for(auto&r:x){double v=r[1]+t;f+=.5*(std::log(2*std::acos(-1.)*v)+std::pow(r[0]-a,2)/v);}
        if(f<best){best=f;tau=t;m=a;}
    }
    Report out{{"Asset","RawAlpha","SamplingVariance","PriorMean","PriorVariance","PosteriorMean","PosteriorVariance","Shrinkage","NLL"},{}};
    for(std::size_t i=0;i<x.size();++i){
        double a=x[i][0],s=x[i][1],g=tau/(tau+s);
        out.rows.push_back({double(i+1),a,s,m,tau,m+g*(a-m),g*s,1-g,best});
    }
    return out;
}
