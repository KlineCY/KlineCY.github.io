Brinson–Fachler单期归因

配置贡献为主动权重乘相对整体基准的行业收益，选择贡献为基准权重乘行业超额收益，交互项为主动权重与行业超额收益的乘积。两套权重均和为1。

$$A_i=(w_i^P-w_i^B)(r_i^B-R^B),\quad S_i=w_i^B(r_i^P-r_i^B)$$
$$I_i=(w_i^P-w_i^B)(r_i^P-r_i^B),\quad \sum_i(A_i+S_i+I_i)=R^P-R^B$$

两个行业贡献0.014与−0.006，合计主动收益0.008。权重均为同期初口径；现金与未分类资产需纳入分组。

Cariño多期归因链接

局部算术主动贡献乘对数系数后跨期可加，再除以总期系数恢复累计算术差。两收益相同时取连续极限1／（1＋r）。

$$k_t=\frac{\log(1+r_t^P)-\log(1+r_t^B)}{r_t^P-r_t^B},\quad K=\frac{\log(1+R^P)-\log(1+R^B)}{R^P-R^B}$$
$$C_j=\sum_t c_{tj}k_t/K,\quad \sum_j C_j=R^P-R^B$$

组合和基准均累计涨10％，总链接贡献为零，单项仍可非零。每期贡献须先与主动收益核对，避免直接加总日度差。

每日重置杠杆的复利路径

每期重设杠杆L，净值为逐期杠杆收益乘积，静态比较仅对累计收益乘L。差值体现路径和费用；净值非正时拒绝输入。

$$V_t=V_{t-1}(1+Lr_t-c),\quad S_t=S_{t-1}(1+r_t)$$
$$V_t^{\mathrm{static}}=1+L(S_t-1)$$

标的涨10％再跌1／11回到1，2倍每日重置净值约0.9818。趋势路径也可能使日重置结果更高，不能只用波动判断所有路径。

算术主动收益与相对财富

财富差和相对财富比为不同主动表现口径。相对收益每期乘数为组合与基准总收益率之比，基准累计收益非零时一般不同。

$$R_{0,t}^P-R_{0,t}^B=V_t^P-V_t^B$$
$$R_{0,t}^{\mathrm{rel}}=V_t^P/V_t^B-1=(R_{0,t}^P-R_{0,t}^B)/(1+R_{0,t}^B)$$

案例组合0.99、基准1.05，算术差−0.06，相对财富−5.714％。需相同日期、币种、复权和费用口径。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace applied_allocation {
using namespace evidence;
inline Report brinson_fachler(const Mat& x,const Vec& p){
    validate(x,1,4,4);
    parameters(p,0);
    double wp=0,wb=0,rb=0;
    for(auto&r:x){require(r[0]>=0&&r[1]>=0&&r[2]>=-1&&r[3]>=-1,"Invalid group");
    wp+=r[0];
    wb+=r[1];
    rb+=r[1]*r[3];
    }require(std::abs(wp-1)<1e-9&&std::abs(wb-1)<1e-9,"Weights must sum to one");
    Report o{{"Group","Allocation","Selection","Interaction","Total"},{}};
    for(std::size_t i=0;
    i<x.size();
    ++i){auto&r=x[i];
    double d=r[0]-r[1],e=r[2]-r[3],a=d*(r[3]-rb),s=r[1]*e,z=d*e;
    o.rows.push_back({double(i+1),a,s,z,a+s+z});
    }return o;
    
}

inline Report carino(const Mat& x,const Vec& p){
    validate(x,1,4,4);
    parameters(p,0);
    auto k=[](double a,double b){positive(1+a);
    positive(1+b);
    double d=a-b;
    return d==0?1/(1+b):std::log1p(d/(1+b))/d;
    };
    double a=0,b=0;
    for(auto&r:x){positive(1+r[0]);
    positive(1+r[1]);
    require(std::abs(r[2]+r[3]-(r[0]-r[1]))<1e-9,"Contributions do not reconcile");
    a+=std::log1p(r[0]);
    b+=std::log1p(r[1]);
    }double K=k(std::expm1(a),std::expm1(b));
    Report o{{"Period","LocalK","GlobalK","LinkedA","LinkedB"},{}};
    for(std::size_t i=0;
    i<x.size();
    ++i){auto&r=x[i];
    double u=k(r[0],r[1]);
    o.rows.push_back({double(i+1),u,K,r[2]*u/K,r[3]*u/K});
    }return o;
    
}

inline Report daily_leverage(const Mat& x,const Vec& p){
    validate(x,1,1,1);
    parameters(p,2);
    double L=p[0],c=p[1],s=1,v=1;
    require(c>=0&&c<1,"Invalid cost");
    Report o{{"Period","UnderlyingNAV","LeveragedNAV","StaticMultipleNAV","Gap"},{}};
    for(std::size_t i=0;
    i<x.size();
    ++i){double r=x[i][0];
    s*=positive(1+r);
    v*=positive(1+L*r-c);
    double u=1+L*(s-1);
    o.rows.push_back({double(i+1),s,v,u,v-u});
    }return o;
    
}

inline Report active_wealth(const Mat& x,const Vec& p){
    validate(x,1,2,2);
    parameters(p,0);
    double a=1,b=1;
    Report o{{"Period","PortfolioNAV","BenchmarkNAV","ArithmeticActive","RelativeWealth"},{}};
    for(std::size_t i=0;
    i<x.size();
    ++i){a*=positive(1+x[i][0]);
    b*=positive(1+x[i][1]);
    o.rows.push_back({double(i+1),a,b,a-b,a/b-1});
    }return o;
    
}
