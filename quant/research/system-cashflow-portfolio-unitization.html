外部申赎与组合份额：时间加权收益及资产净值守恒

系统化研究与实验　完整源码

经济机制与模型设定

投资组合净值变化同时来自投资收益与外部申赎。份额化核算把期初现金流按申赎前单位净值发行或注销份额，随后投资收益只改变单位价格。该口径适用于现金流发生在每期投资收益之前的明确约定。

推导与计算方法

给定初始资产净值与单位价格，求初始份额。每期按上期价格增加或减少份额，再更新单位净值及资产总值，并与直接现金流公式核对。时间加权收益仅由各期投资收益连乘，不受外部投入规模影响。

$$N_t^+=N_{t-1}+F_t/P_{t-1}$$
$$P_t=P_{t-1}(1+r_t),\quad V_t=N_t^+P_t$$
$$V_t=(V_{t-1}+F_t)(1+r_t)$$
$$R_{\rm TWR}=\prod_{s=1}^t(1+r_s)-1$$

初始100、单位1；投入100后收益10%，资产220、份额200；下一期投入50、收益0，资产270；最后赎回30再亏损10%，资产216。单位净值0.99，累计TWR−1%。

研究边界及计算复杂度

O(n)，外部赎回不得耗尽全部资产，收益严格大于−100%。现金流发生在期中时需更细粒度估值，不能直接使用该期初口径。金额加权收益是另一个指标。

C++17完整实现

inline Report cashflow_portfolio_unitization(const Mat& x,const Vec& p){
    validate(x,1,2,2);parameters(p,2);double nav=positive(p[0]),price=positive(p[1]),base=price,units=nav/price;Report o{{"Period","OpeningValue","ExternalFlow","Units","UnitPrice","ClosingValue","PeriodReturn","TWR","ConservationResidual"},{}};for(std::size_t i=0;i<x.size();++i){double opening=nav,F=x[i][0],r=x[i][1];require(r>-1,"Portfolio return must exceed -100 percent");double invested=positive(opening+F);units=positive(units+F/price);price=positive(price*(1+r));nav=positive(units*price);o.rows.push_back({double(i+1),opening,F,units,price,nav,r,price/base-1,std::abs(nav-invested*(1+r))});}return o;
}
