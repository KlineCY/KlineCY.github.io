椭球均值不确定集的最坏组合期望

数学定义与推导

组合期望对均值向量为线性函数，椭球写为中心加线性映射的单位球。Cauchy–Schwarz给出最坏方向与Dᵀw反向，且界可达到。此实现D为对角不确定尺度，适合估计误差不相关的简化假设；一般相关椭球需完整矩阵。

$$\mathcal U=\{\hat\mu+D z:\|z\|_2\le\rho\}$$
$$\inf_{\mu\in\mathcal U}w^\top\mu=w^\top\hat\mu-\rho\|D^\top w\|_2$$
$$z^*=-\rho D^\top w/\|D^\top w\|_2\quad(D^\top w\ne0)$$

数值演算与金融应用

权重0.6、0.4，均值0.1、0.05，误差尺度0.02、0.03，名义组合期望0.08，不确定范数√0.000288。半径2时最坏期望约0.0461。半径不是自动的置信水平，必须根据估计方法校准。

算法复杂度、输入契约与边界

O(n)，不确定尺度及半径非负，权重允许空头。不确定集针对均值估计，而非一次实现收益；不能用该最坏均值替代VaR或最坏市场损失。

共同有限支持的一阶及二阶随机占优

数学定义与推导

一阶占优保证任意递增效用的期望不低；二阶占优对应递增凹效用。有限共同支持上CDF在相邻点之间常数，因此积分按上一点CDF差乘区间宽度更新，只需检查所有节点及最终均值差。程序输出全局判定并在每行重复。

$$A\succeq_1 B\iff F_A(x)\le F_B(x)\quad\forall x$$
$$A\succeq_2 B\iff\int_{-\infty}^x[F_A(u)-F_B(u)]\,du\le0\quad\forall x$$
$$\mathbb E[(x-A)^+]-\mathbb E[(x-B)^+]=\int_{-\infty}^x(F_A-F_B)(u)\,du$$

数值演算与金融应用

支持0、1、2，A概率0.2、0.3、0.5，B为0.4、0.4、0.2，A的CDF始终不高且积分差非正，故一阶与二阶均占优。若CDF交叉，一阶可能不成立而二阶仍成立；这不是样本统计显著性检验。

算法复杂度、输入契约与边界

O(n)，支持严格递增、两列概率非负各和1。数值容差1e−10用于边界；收益分布需同期限及货币单位，不能将经验分布占优直接解释为未来确定优势。

线性成本下的单资产不交易区间

数学定义与推导

将变量平移为交易量w−w0，得到L1近端问题。若理想权重偏差不超过成本除以曲率，则最优交易为零；否则只交易超过阈值的部分。目标关于w凸，在一维约束区间内将自由最优点截断即可。

$$\min_{l\le w\le u}\tfrac12a(w-z)^2+c|w-w_0|$$
$$w^*_{\mathrm{free}}=w_0+\operatorname{sign}(z-w_0)(|z-w_0|-c/a)_+$$
$$w^*=\operatorname{clip}(w^*_{\mathrm{free}},l,u)$$

数值演算与金融应用

曲率2、线性成本0.2，不交易半宽0.1。原权重0.2、目标0.25时不交易；目标0.5时新权重0.4；原0.8、目标0.5时降至0.6。体现成本与信号强度的经济权衡。

算法复杂度、输入契约与边界

O(n)，各行独立问题，曲率正，成本非负，下界≤上界且原权重可行。多资产预算与相关风险耦合时不能逐资产直接使用闭式。成本按权重变动的线性单位解释。

固定组合均值估计误差与收益风险

数学定义与推导

对独立同分布向量收益，样本均值的协方差是单期协方差除以n。固定权重的组合收益风险与均值估计风险使用同一二次型但尺度不同。若权重由同一训练样本优化，权重随机且与估计误差相关，公式不再给出无条件策略误差。

$$\operatorname{Cov}(\hat\mu)=\Sigma/n\quad\text{under iid sampling}$$
$$\operatorname{Var}(w^\top R)=w^\top\Sigma w$$
$$\operatorname{Var}(w^\top\hat\mu)=w^\top\Sigma w/n$$

数值演算与金融应用

协方差(0.04,0.01;0.01,0.09)，权重0.6、0.4，组合方差0.0336，100个独立样本时均值估计方差0.000336。均值标准误约1.833％，说明即使收益风险稳定，预期收益估计仍可能不精确。

算法复杂度、输入契约与边界

O(d²)计算二次型，附加Cholesky正定验证O(d³)。输入最后一列权重，协方差严格正定；n为样本量整数。时间依赖时应使用长期协方差，均值风险不可机械除以n。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace depth_robustallocation {
using namespace evidence;
inline Report ellipsoid_worst_mean(const Mat& x,const Vec& p){
    validate(x,1,3,3);parameters(p,1);require(p[0]>=0,"Negative uncertainty radius");double a=0,b=0;
    for(auto&r:x){require(r[2]>=0,"Negative uncertainty scale");a+=r[0]*r[1];b=std::hypot(b,r[0]*r[2]);}return scalar({"NominalReturn","UncertaintyNorm","WorstCaseReturn"},{a,b,a-p[0]*b});
}

inline Report stochastic_dominance(const Mat& x,const Vec& p){
    validate(x,1,3,3);parameters(p,0);double a=0,b=0,I=0;bool f=true,s=true;Report o{{"Outcome","CDFA","CDFB","IntegralDifference","AFirstOrder","ASecondOrder"},{}};
    for(std::size_t i=0;i<x.size();++i){auto&r=x[i];require(r[1]>=0&&r[2]>=0,"Negative probability");if(i)I+=(a-b)*positive(r[0]-x[i-1][0]);a+=r[1];b+=r[2];f=f&&a<=b+1e-10;s=s&&I<=1e-10;o.rows.push_back({r[0],a,b,I,0,0});}
    require(std::abs(a-1)<1e-10&&std::abs(b-1)<1e-10,"Probability sums");for(auto&r:o.rows){r[4]=double(f);r[5]=double(s);}return o;
}

inline Report single_asset_no_trade(const Mat& x,const Vec& p){
    validate(x,1,3,3);parameters(p,3);double c=p[0],l=p[1],u=p[2];require(c>=0&&l<=u,"Invalid cost or bounds");Report o{{"Current","Target","NewWeight","Trade","Cost"},{}};
    for(auto&r:x){double a=positive(r[2]),w=r[0],z=r[1];require(w>=l&&w<=u,"Current weight infeasible");double d=z-w,v=w+std::copysign(std::max(0.,std::abs(d)-c/a),d);v=std::max(l,std::min(u,v));o.rows.push_back({w,z,v,v-w,c*std::abs(v-w)});}return o;
}

inline Report mean_estimation_risk(const Mat& x,const Vec& p){
    auto d=validate(x,1,2,33)-1;parameters(p,1);require(x.size()==d,"Square covariance required");auto n=count(p[0],1,1000000000);Mat s;Vec w;
    for(auto&r:x){s.emplace_back(r.begin(),r.end()-1);w.push_back(r.back());}solve_spd(s,Vec(d,0));double v=dot(w,mul(s,w));require(v>=0,"Negative portfolio variance");return scalar({"PortfolioVariance","MeanEstimateVariance","MeanEstimateSE"},{v,v/n,std::sqrt(v/n)});
}
