二乘二双矩阵博弈的完全混合均衡

数学定义与推导

完全混合均衡要求双方以正概率使用两策略，因此每一方必须对自己的两种纯策略无差异。行玩家无差异条件决定列玩家概率q，列玩家条件决定p。解落在(0,1)内且分母非零时，这两个无差异条件与概率可行性构成完全混合Nash均衡。

$$A=\begin{pmatrix}a&b\\c&d\end{pmatrix},\quad B=\begin{pmatrix}e&f\\g&h\end{pmatrix}$$
$$q^*=\frac{d-b}{a-b-c+d},\quad p^*=\frac{h-g}{e-f-g+h}$$
$$q^*a+(1-q^*)b=q^*c+(1-q^*)d,\quad p^*e+(1-p^*)g=p^*f+(1-p^*)h$$

数值演算与金融应用

匹配博弈中行玩家匹配得1否则0，列玩家收益为其相反数，p=q=0.5，两方期望0.5和−0.5。该工具只处理非退化完全混合均衡，不枚举纯均衡或边界混合。适合理解战略不确定性与随机化。

算法复杂度、输入契约与边界

O(1)，两行每行分别给两玩家各两策略收益。近零分母及概率不在内部时拒绝，不表示无Nash均衡；退化博弈可能有连续均衡集合。

异质边际成本Cournot均衡的活跃集

数学定义与推导

企业选择非负产量，单个企业利润关于自身产量严格凹。一阶条件给出活跃企业P−c_i=Bq_i，非活跃企业P≤c_i。代入逆需求得到严格递增的价格方程；可二分求唯一解，再恢复每家产量和KKT残差。

$$P=A-B\sum_iq_i,\quad\pi_i=(P-c_i)q_i$$
$$q_i=(P-c_i)_+/B$$
$$P+\sum_i(P-c_i)_+=A$$

数值演算与金融应用

截距10、斜率1、成本2、4、20。前两家活跃，均衡价格(10+2+4)/3=16/3，数量10/3与4/3，成本20企业退出。模型说明异质成本如何影响市场结构；不含容量、固定成本、动态进入或差异化产品。

算法复杂度、输入契约与边界

O(80n)，需求截距正、斜率正、成本非负。若所有成本高于需求截距，均衡零产量、价格A。实际行业不能仅凭单一构造例推断市场竞争程度。

独立均匀私人价值的第一价格拍卖均衡

数学定义与推导

对称严格递增竞价策略下，价值v的中标概率为其他n−1个价值均低于v。激励相容的包络条件使期望效用为中标概率积分；零价值效用为0，由效用等于价值减出价再乘中标概率解出均衡出价。均匀分布下出价按价值固定比例折减。

$$V_i\overset{\mathrm{iid}}{\sim}U[0,1],\quad n\ge2$$
$$b(v)=v-\frac{\int_0^vF(t)^{n-1}\,dt}{F(v)^{n-1}}=\frac{n-1}{n}v$$
$$u(v)=(v-b(v))v^{n-1}=v^n/n$$

数值演算与金融应用

三位风险中性投标者，价值0.5的均衡出价1/3，中标概率0.25，期望效用1/24。该模型说明私有价值拍卖中的策略折价；交易所集合竞价通常是不同的清算机制，不能直接套用。

算法复杂度、输入契约与边界

O(n_rows)，投标者数≥2、价值[0,1]。假设独立同分布、风险中性、单物品、无保留价及对称均衡；共同价值、风险厌恶和不对称分布会改变策略。

Kyle单期线性信息交易均衡

数学定义与推导

在单期理论模型中，知情交易者的最优线性需求由最大化条件期望交易利润给出，竞争做市者将价格设为总订单流条件下的价值期望。联合正态使条件期望线性，将最优需求系数与回归价格冲击系数联立，得到均衡。模型用于理解信息、噪声与价格发现之间的关系，不描述真实市场中的具体交易者身份。

$$v\sim N(\mu,\sigma_v^2),\quad u\sim N(0,\sigma_u^2),\quad y=x+u$$
$$x=\beta(v-\mu),\quad p=\mu+\lambda y,\quad\beta=1/(2\lambda)$$
$$\lambda=\sigma_v/(2\sigma_u),\quad\beta=\sigma_u/\sigma_v,\quad \operatorname{Var}(v\mid y)=\sigma_v^2/2$$

数值演算与金融应用

价值方差4、噪声订单方差9，标准差2与3，均衡需求斜率1.5，价格冲击1/3，条件价值方差2，理论期望利润3。噪声订单标准差增大时单位流量价格冲击降低；该结论依赖单期线性正态结构。

算法复杂度、输入契约与边界

O(n)，两方差严格正，输入单位分别为价格平方与数量平方。模型是经典市场微观结构理论，参数不能从简单价量回归直接识别为结构性信息优势；实际合规交易不得利用非公开重大信息。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace depth_games {
using namespace evidence;
inline Report mixed_nash_interior(const Mat& x,const Vec& p){
    validate(x,2,4,4);parameters(p,0);require(x.size()==2,"Two strategies per player required");double a=x[0][0],b=x[0][1],c=x[1][0],d=x[1][1],e=x[0][2],f=x[0][3],g=x[1][2],h=x[1][3];double u=a-b-c+d,v=e-f-g+h;require(std::abs(u)>1e-14&&std::abs(v)>1e-14,"Degenerate indifference");double q=(d-b)/u,z=(h-g)/v;require(z>0&&z<1&&q>0&&q<1,"No strict interior solution");double r1=q*a+(1-q)*b,r2=q*c+(1-q)*d,c1=z*e+(1-z)*g,c2=z*f+(1-z)*h;return scalar({"RowProbFirst","ColProbFirst","RowExpectedPayoff","ColExpectedPayoff","RowIndifferenceGap","ColIndifferenceGap"},{z,q,z*r1+(1-z)*r2,q*c1+(1-q)*c2,r1-r2,c1-c2});
}

inline Report cournot_active_set(const Mat& x,const Vec& p){
    validate(x,1,1,1);parameters(p,2);double A=positive(p[0]),B=positive(p[1]),lo=0,hi=A;for(auto&r:x)require(r[0]>=0,"Negative marginal cost");
    for(int k=0;k<80;++k){double m=(lo+hi)/2,s=m;for(auto&r:x)s+=std::max(m-r[0],0.);if(s>A)hi=m;else lo=m;}double P=(lo+hi)/2;Report o{{"Firm","Quantity","MarketPrice","Profit","KKTGap"},{}};
    for(std::size_t i=0;i<x.size();++i){double c=x[i][0],q=std::max(0.,P-c)/B,g=P-c-B*q;o.rows.push_back({double(i+1),q,P,(P-c)*q,q>0?std::abs(g):std::max(0.,g)});}return o;
}

inline Report auction_uniform_bid(const Mat& x,const Vec& p){
    validate(x,1,1,1);parameters(p,1);double n=count(p[0],2,1000000);Report o{{"Valuation","EquilibriumBid","WinProbability","ExpectedUtility"},{}};
    for(auto&r:x){double v=r[0];require(v>=0&&v<=1,"Valuation outside support");double q=std::pow(v,n-1),b=v*(n-1)/n;o.rows.push_back({v,b,q,q*(v-b)});}return o;
}

inline Report kyle_linear_equilibrium(const Mat& x,const Vec& p){
    validate(x,1,2,2);parameters(p,0);Report o{{"InsiderSlope","PriceImpact","ResidualValueVariance","ExpectedInsiderProfit"},{}};
    for(auto&r:x){double v=std::sqrt(positive(r[0])),u=std::sqrt(positive(r[1]));o.rows.push_back({u/v,v/(2*u),r[0]/2,v*u/2});}return o;
}
