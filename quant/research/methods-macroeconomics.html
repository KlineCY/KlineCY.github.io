政府债务率、增长与初级余额

模型与推导

名义债务按有效利率滚存，再扣当期初级盈余并加入存量流量调整，除以当期名义GDP得到债务率恒等式。增长必须是名义增长，初级盈余及调整已按当期GDP归一。

$$b_t=\frac{1+i_t}{1+g_t}b_{t-1}-s_t+a_t$$
$$\Delta b_t=\frac{i_t-g_t}{1+g_t}b_{t-1}-s_t+a_t$$

研究应用与成立条件

初始债务率60％，名义增长10％高于利率5％，利息增长项为负。第二期增长为零且初级赤字1％，另有2％存量调整。该核算不预测财政反应或违约概率。

固定基期总量增长贡献

模型与推导

在可加总、同价格基期的实际总量中，整体增长为各组成增长按前期份额加权。链式不变价的非可加总部分须使用统计机构专门贡献率，不能直接用本恒等式。

$$g=(\sum_iY_{i,t}-\sum_iY_{i,t-1})/\sum_iY_{i,t-1}$$
$$g=\sum_iw_{i,t-1}g_i,\quad w_{i,t-1}=Y_{i,t-1}/Y_{t-1}$$

研究应用与成立条件

前期60及40，后期66及38，总增长4％，两个贡献6和−2个百分点。案例仅适合正的基期组成，不处理负净出口等带符号分项。

实际汇率的对数价格分解

模型与推导

名义汇率E为本币每单位外币，实际汇率比较国外商品篮子的本币成本与国内价格。对数变化可精确拆为名义贬值、外国通胀减国内通胀。实际汇率上升表示按该定义本币实际贬值。

$$q_t=E_tP_t^*/P_t$$
$$\Delta\log q_t=\Delta\log E_t+\Delta\log P_t^*-\Delta\log P_t$$

研究应用与成立条件

名义汇率从1至1.1，外国价格100至105、国内100至110，实际汇率从1至1.05。指数基期应一致，贸易加权汇率需要多币种权重，而非单边案例外推。

外币存款的精确超额收益与UIP

模型与推导

从本币换入外币存款，期末按即期汇率换回，外币利息与汇率变化以乘法组合。UIP在适当风险中性或期望条件下约束未对冲超额；实际实现包含汇率风险溢价及预测误差。

$$G^f=(1+i_f)E_{t+1}/E_t,\quad G^d=1+i_d$$
$$r^{\mathrm{excess}}=G^f-G^d,\quad \log(G^f/G^d)=\log(1+i_f)-\log(1+i_d)+\Delta\log E$$

研究应用与成立条件

本币利率2％、外币4％，外币升值5％时本币超额7.2个百分点；外币贬值2％时超额约−0.08个百分点。未计交易、融资及资本管制成本。

C++17实现

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace methods_macroeconomics {
using namespace evidence;
inline Report debt_dynamics(const Mat& x,const Vec& p){
    validate(x,1,4,4);
    parameters(p,1);
    double b=p[0];
    require(b>=0,"Negative initial debt ratio");
    Report o{{"Period","PreviousDebt","InterestGrowthEffect","PrimaryEffect","StockFlow","DebtRatio"},{}};
    for(std::size_t i=0;
    i<x.size();
    ++i){auto&r=x[i];
    positive(1+r[0]);
    double g=positive(1+r[1]),e=(r[0]-r[1])/g*b,v=b+e-r[2]+r[3];
    o.rows.push_back({double(i+1),b,e,-r[2],r[3],v});
    b=v;
    }return o;
    
}

inline Report gdp_growth_contributions(const Mat& x,const Vec& p){
    validate(x,1,2,2);
    parameters(p,0);
    double s=0;
    for(auto&r:x){s+=positive(r[0]);
    require(r[1]>=0,"Negative current component");
    }Report o{{"Component","BaseShare","OwnGrowth","Contribution"},{}};
    for(std::size_t i=0;
    i<x.size();
    ++i){auto&r=x[i];
    double a=r[0]/s,b=r[1]/r[0]-1;
    o.rows.push_back({double(i+1),a,b,(r[1]-r[0])/s});
    }return o;
    
}

inline Report real_fx_decomposition(const Mat& x,const Vec& p){
    validate(x,1,3,3);
    parameters(p,0);
    Report o{{"Period","RealFX","LogNominalChange","LogForeignInflation","LogDomesticInflation","LogRealChange"},{}};
    for(std::size_t i=0;
    i<x.size();
    ++i){auto&r=x[i];
    double a=positive(r[0]),b=positive(r[1]),c=positive(r[2]),u=0,v=0,w=0;
    if(i){u=std::log(a/x[i-1][0]);
    v=std::log(b/x[i-1][1]);
    w=std::log(c/x[i-1][2]);
    }o.rows.push_back({double(i+1),a*b/c,u,v,w,u+v-w});
    }return o;
    
}

inline Report uip_carry(const Mat& x,const Vec& p){
    validate(x,1,4,4);
    parameters(p,0);
    Report o{{"DomesticGross","ForeignInDomesticGross","ArithmeticExcess","LogExcess"},{}};
    for(auto&r:x){double a=positive(1+r[2]),b=positive(1+r[3])*positive(r[1])/positive(r[0]);
    o.rows.push_back({a,b,b-a,std::log(b/a)});
    }return o;
    
}
