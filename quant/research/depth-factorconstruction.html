并列信号的分数化尾部组合权重

数学定义与推导

固定尾部质量m可能落在并列信号组内。若简单按行顺序切割，会使相同信号的资产获得任意不同持仓。将剩余尾部质量在边界并列组内等分，形成对行顺序不敏感的分数化权重。高低尾部分别归一；若信号高度并列，两腿可能重叠，净权重因此抵销。

$$m=\tau n,\quad 0<\tau\le1/2$$
$$a_g=\frac{\min(m_{\mathrm{remain}},|g|)}{|g|}\quad\text{for a tied score group}$$
$$w_i^L=a_i^L/m,\quad w_i^S=a_i^S/m,\quad \sum_iw_i^L=\sum_iw_i^S=1$$

数值演算与金融应用

四资产信号0、1、1、2，尾部各50％，高尾包含2及两个1各半，低尾包含0及两个1各半，净权重−0.5、0、0、0.5。该规则保留信号对称性，但净组合总杠杆低于两腿名义之和，风险控制需基于实际净头寸。

算法复杂度、输入契约与边界

O(n log n)，τ∈(0,0.5]。精确相等才视为并列，近似并列应预先按明确精度分箱。组合权重由当期可用信号形成，不能按未来收益打破并列。

规模—价值六组合的市值加权因子构造

数学定义与推导

先按预定规模二分及价值三分形成六个互斥组合，在各组合内用期初市值加权。再按组合层面等权合成规模因子和价值因子，避免将所有小盘或高价值资产直接按总市值合并。输入分组标签必须由事前可用财务与市值信息得到。

$$R_{s,v}=\frac{\sum_{i\in(s,v)}M_{i,t-1}r_{i,t}}{\sum_{i\in(s,v)}M_{i,t-1}}$$
$$\mathrm{SMB}=(R_{SL}+R_{SM}+R_{SH}-R_{BL}-R_{BM}-R_{BH})/3$$
$$\mathrm{HML}=(R_{SH}+R_{BH}-R_{SL}-R_{BL})/2$$

数值演算与金融应用

六组合收益1％至6％依次递增，小盘三组均值2％、大盘5％，SMB=−3％；高价值组均值4.5％、低价值2.5％，HML=2％。该示例使用已分组资产，不能视为对正式Fama–French历史因子的复现。

算法复杂度、输入契约与边界

O(n)，SizeBin=0/1、ValueBin=0/1/2、市值严格正、简单收益≥−1，六组合均非空。实际复制需核对交易所样本、断点、再平衡频率、退市收益和账面价值可用日。

单因子Beta的正态共轭收缩

数学定义与推导

把回归估计视为带已知采样误差的观测，将正态先验与正态似然相乘，配方得到正态后验。后验均值为数据估计与先验均值的精度加权平均，采样方差越大向先验收缩越强。先验参数可由独立历史或层次模型估计，但不能用留出期结果调节。

$$\hat\beta\mid\beta\sim N(\beta,s^2),\quad\beta\sim N(b_0,\tau^2)$$
$$v=(s^{-2}+\tau^{-2})^{-1}$$
$$m=\frac{\tau^2}{s^2+\tau^2}\hat\beta+\frac{s^2}{s^2+\tau^2}b_0$$

数值演算与金融应用

先验均值1、方差1；估计Beta2且标准误1时后验1.5、方差0.5；标准误0.5时后验1.8、方差0.2。用于稳定风险暴露或资产定价回归系数，不能将后验方差当作资产收益方差。

算法复杂度、输入契约与边界

O(n)，标准误及先验方差严格正。似然正态近似在弱识别、重尾、极少样本时可能不足；回归标准误需按真实依赖结构估计，先验方差与估计单位一致。

常权重组合的逐期再平衡与买入持有对照

数学定义与推导

常权重组合在每个收益区间开始恢复目标权重，因此净值是组合单期增长因子乘积；买入持有组合不调仓，净值为两资产累积财富加权和。期末漂移权重与目标的差值是双资产单边换手，提供比较再平衡收益与交易成本的基础。

$$V_t^{\mathrm{CM}}=V_{t-1}^{\mathrm{CM}}[1+w r_{A,t}+(1-w)r_{B,t}]$$
$$V_t^{\mathrm{BH}}=w\prod_{s\le t}(1+r_{A,s})+(1-w)\prod_{s\le t}(1+r_{B,s})$$
$$w_t^{\mathrm{drift}}=\frac{w(1+r_{A,t})}{1+w r_{A,t}+(1-w)r_{B,t}},\quad TO_t=|w_t^{\mathrm{drift}}-w|$$

数值演算与金融应用

资产A先涨20％再跌1/6、B先跌10％再涨1/9，两者最终均回到1。常权重50％组合首期增长1.05，次期增长35/36，最终约1.02083，超过买入持有1。该收益源于构造的均值回复路径，不保证所有趋势或高成本场景获益。

算法复杂度、输入契约与边界

O(n)，长仓目标权重[0,1]、两资产增长因子严格正。假设无费用和融资，期末报告下一次恢复权重所需换手；最后一期换手只是潜在再平衡，不自动扣除费用。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace depth_factorconstruction {
using namespace evidence;
inline Report tie_aware_tail_weights(const Mat& x,const Vec& p){
    validate(x,2,1,1);parameters(p,1);require(p[0]>0&&p[0]<=.5,"Invalid tail fraction");Vec s=column(x,0);auto ix=order(s);double m=p[0]*x.size();Vec L(x.size(),0),S(x.size(),0);
    auto fill=[&](std::vector<std::size_t> ids,Vec& w){double rem=m;for(std::size_t i=0;i<ids.size()&&rem>0;){std::size_t j=i+1;while(j<ids.size()&&s[ids[j]]==s[ids[i]])++j;double a=std::min(rem,double(j-i)),v=a/(j-i)/m;for(std::size_t k=i;k<j;++k)w[ids[k]]=v;rem-=a;i=j;}};
    fill(ix,S);std::reverse(ix.begin(),ix.end());fill(ix,L);Report o{{"Asset","Score","LongWeight","ShortWeight","NetWeight"},{}};
    for(std::size_t i=0;i<x.size();++i)o.rows.push_back({double(i+1),s[i],L[i],S[i],L[i]-S[i]});return o;
}

inline Report size_value_six_cells(const Mat& x,const Vec& p){
    validate(x,1,4,4);parameters(p,0);Vec w(6,0),v(6,0);for(auto&r:x){auto s=count(r[0],0,1),k=count(r[1],0,2),j=3*s+k;double a=positive(r[2]);require(r[3]>=-1,"Invalid simple return");w[j]+=a;v[j]+=a*r[3];}
    for(std::size_t j=0;j<6;++j)v[j]/=positive(w[j]);double smb=(v[0]+v[1]+v[2]-v[3]-v[4]-v[5])/3,hml=(v[2]+v[5]-v[0]-v[3])/2;v.push_back(smb);v.push_back(hml);return scalar({"SmallLow","SmallMid","SmallHigh","BigLow","BigMid","BigHigh","SMB","HML"},v);
}

inline Report beta_posterior_shrink(const Mat& x,const Vec& p){
    validate(x,1,2,2);parameters(p,2);double m=p[0],v=positive(p[1]);Report o{{"EstimatedBeta","SamplingVariance","PosteriorMean","PosteriorVariance","DataWeight"},{}};
    for(auto&r:x){double s=positive(r[1]);s*=s;double a=v/(v+s);o.rows.push_back({r[0],s,a*r[0]+(1-a)*m,a*s,a});}return o;
}

inline Report constant_mix_diversification(const Mat& x,const Vec& p){
    validate(x,1,2,2);parameters(p,1);double w=p[0];require(w>=0&&w<=1,"Long-only target weight required");double a=1,b=1,v=1;Report o{{"Period","ConstantMixNAV","BuyHoldNAV","RebalanceExcess","PostReturnWeightA","OneWayTurnover"},{}};
    for(std::size_t i=0;i<x.size();++i){auto&r=x[i];double u=positive(1+r[0]),z=positive(1+r[1]),g=w*u+(1-w)*z;v*=g;a*=u;b*=z;double bh=w*a+(1-w)*b,d=w*u/g;o.rows.push_back({double(i+1),v,bh,v-bh,d,std::abs(d-w)});}return o;
}
