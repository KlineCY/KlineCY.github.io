配对及隐藏偏差

将匹配后的处理—对照结果差作为输入，去除零差值。对每对内处理分配，未观测协变量可能使接受处理的赔率相差至Γ倍。这里采用正差值计数的单侧敏感性分析。

$$\frac1{1+\Gamma}\le P(D_{i1}=1\mid\mathcal F)\le\frac{\Gamma}{1+\Gamma},\quad \Gamma\ge1.$$

统计量及支配界

尖锐零效应假设下，每对正差值指标概率落在上述区间，且对间独立。正差值计数的右尾概率随各对概率单调增加，因此同一端点的二项分布提供上下界。

$$T=\sum_i1_{\{\Delta_i>0\}},\quad P_L=P(\mathrm{Bin}(n,1/(1+\Gamma))\ge T),\quad P_U=P(\mathrm{Bin}(n,\Gamma/(1+\Gamma))\ge T).$$

数值计算

使用对数Gamma函数构造二项概率并在对数域求和，避免大量配对下阶乘或极小概率下溢。Γ=1时上下界相同。

$$\log P(K=k)=\log\Gamma(n+1)-\log\Gamma(k+1)-\log\Gamma(n-k+1)+k\log p+(n-k)\log(1-p).$$

敏感性含义

上界越过显著性阈值表明在给定隐藏偏差强度下，原显著性结论不再保证稳健；它不估计实际隐藏偏差，也不证明匹配设计无偏。仅比较同一匹配样本的不同Γ。

$$\Gamma^*=\inf\{\Gamma:P_U(\Gamma)>\alpha\}.$$

inline Report rosenbaum_pair_bounds(const Mat& x,const Vec& p){
    validate(x,1,1,1);require(!p.empty(),"gamma grid required");
    int n=0,t=0;for(const auto&r:x){if(r[0]!=0){++n;t+=r[0]>0;}}require(n>0,"no nonzero pair differences");
    auto tail=[&](double q){
        if(t==0)return 1.;Vec v;
        for(int k=t;k<=n;++k)v.push_back(std::lgamma(n+1.)-std::lgamma(k+1.)-std::lgamma(n-k+1.)+k*std::log(q)+(n-k)*std::log1p(-q));
        return std::min(1.,std::exp(logsumexp(v)));
    };
    Report out;out.header={"Gamma","Pairs","PositivePairs","LowerP","UpperP"};
    for(double g:p){require(g>=1&&g<=1e12,"gamma outside range");double q=1/(1+g);out.rows.push_back({g,double(n),double(t),tail(q),tail(1-q)});}
    return out;
}
