隐含总方差的远期方差提取

数学定义与推导

若期限方差报价代表同一风险中性累计实现方差的年化期望，则累计方差具有时间可加性，远期区间方差由总方差差值除以长度得到。方差互换的公平报价满足该关系；普通固定执行价的隐含波动率只有在适当条件下才可这样解释。

$$W(T)=T\sigma_{\mathrm{var}}^2(T)$$
$$v_{t,T}=[W(T)-W(t)]/(T-t)$$
$$\sigma_{t,T}^{\mathrm{forward}}=\sqrt{v_{t,T}}$$

数值演算与金融应用

一年方差波动率20％、两年25％，总方差0.04及0.125，远期年化方差0.085，波动约29.15％。若期限总方差下降，在相同方差支付定义下出现不一致，不能只取绝对值或强行开方。

算法复杂度、输入契约与边界

O(n)，期限起点非负、终点更大、波动非负，远期方差须非负（小数值误差容忍）。输入应匹配方差取样、年化、支付与币种口径，不将普通IV微笑直接视为方差互换。

独立报价噪声下实现方差的频率偏差

数学定义与推导

独立同分布报价噪声与有效价格独立时，每个噪声差分方差为2η²，交叉期望为零，n个间隔形成随采样频率线性增长的偏差。相邻噪声差分本身负相关，因此更高频率不一定提供更准确的实现方差。

$$Y_{t_i}=X_{t_i}+\epsilon_i,\quad \mathbb E\epsilon_i=0,\quad\operatorname{Var}\epsilon_i=\eta^2$$
$$\Delta Y_i=\Delta X_i+\epsilon_i-\epsilon_{i-1}$$
$$\mathbb E[RV_Y]=\mathbb E[RV_X]+2n\eta^2$$

数值演算与金融应用

有效总方差0.04、噪声方差0.00001，10、100、1000区间的偏差0.0002、0.002、0.02，期望实现方差逐步上升。可解释signature plot，但真实噪声可能异方差、内生或有序列相关。

算法复杂度、输入契约与边界

O(n_rows)，区间数为正整数，参数为整个观察窗有效方差与单次报价噪声方差。输出理论期望，不估计未知噪声；跨市场比较需相同时间窗。

对数正态实现方差下的波动率凸性调整

数学定义与推导

平方根是凹函数，波动率支付的期望低于方差期望开方。若实现方差服从对数正态，利用高斯指数矩得到精确差额，且只依赖对数方差s²。该模型是实现方差分布假设，不代表所有市场波动率产品的实际定价公式。

$$\log V\sim N(m,s^2),\quad \mathbb E V=e^{m+s^2/2}$$
$$\mathbb E\sqrt V=e^{m/2+s^2/8}=\sqrt{\mathbb EV}\,e^{-s^2/8}$$
$$\sqrt{\mathbb EV}-\mathbb E\sqrt V\ge0$$

数值演算与金融应用

方差均值0.04、对数方差0.16，开方20％，期望实现波动20％×e^{−0.02}，约19.604％。无不确定性时差额为0。比较方差互换与波动率互换时，必须匹配年化及风险中性测度。

算法复杂度、输入契约与边界

O(n)，均值方差严格正、对数方差非负。若V可能为零或有厚尾，需改用真实分布积分；参数s²为log V方差，不是V的水平样本方差。

GJR-GARCH的非对称新闻冲击曲线

数学定义与推导

GJR项只在负创新出现时增添方差反应，固定上一期方差绘制新闻冲击曲线可以隔离正负创新的非对称性。有限无条件二阶矩条件还依赖标准化创新的符号对称与矩假设。程序计算给定状态的一步方差，不拟合参数，也不强制所有输入满足长期平稳。

$$h_{t+1}=\omega+\alpha\varepsilon_t^2+\gamma\varepsilon_t^2\mathbf1_{\{\varepsilon_t<0\}}+\beta h_t$$
$$h(-a)-h(a)=\gamma a^2\quad(a>0)$$
$$\alpha+\beta+\gamma/2<1\quad\text{for finite unconditional variance under symmetric standardized innovations}$$

数值演算与金融应用

ω=0.1、α=0.1、γ=0.2、β=0.7、旧方差1，创新−2的方差2，+2为1.2，差额0.8。参数为非负以保证方差正；该示例的持久度0.9，小于1。

算法复杂度、输入契约与边界

O(n)，ω、旧方差正，α、γ、β非负；更一般允许部分负γ但要求α+γ≥0，本实现采用常见非负限制。实际估计需检验创新分布、标准化及状态初始化。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace depth_volatility {
using namespace evidence;
inline Report forward_variance(const Mat& x,const Vec& p){
    validate(x,1,4,4);parameters(p,0);Report o{{"Start","End","TotalVarianceStart","TotalVarianceEnd","ForwardVariance","ForwardVol"},{}};
    for(auto&r:x){require(r[0]>=0&&r[2]>=0&&r[3]>=0,"Invalid tenor or vol");double h=positive(r[1]-r[0]),a=r[0]*r[2]*r[2],b=r[1]*r[3]*r[3];require(b-a>=-1e-12*std::max({1.,a,b}),"Negative forward variance");double v=std::max(0.,(b-a)/h);o.rows.push_back({r[0],r[1],a,b,v,std::sqrt(v)});}return o;
}

inline Report noise_signature(const Mat& x,const Vec& p){
    validate(x,1,1,1);parameters(p,2);require(p[0]>=0&&p[1]>=0,"Negative variance");Report o{{"Intervals","EfficientVariance","NoiseBias","ExpectedRV"},{}};
    for(auto&r:x){auto n=count(r[0],1,1000000000);double v=2*n*p[1];o.rows.push_back({double(n),p[0],v,p[0]+v});}return o;
}

inline Report lognormal_vol_convexity(const Mat& x,const Vec& p){
    validate(x,1,2,2);parameters(p,0);Report o{{"MeanVariance","SqrtMeanVariance","ExpectedVol","ConvexityGap"},{}};
    for(auto&r:x){double a=std::sqrt(positive(r[0]));require(r[1]>=0,"Negative log variance");double b=a*std::exp(-r[1]/8);o.rows.push_back({r[0],a,b,a-b});}return o;
}

inline Report gjr_news_impact(const Mat& x,const Vec& p){
    validate(x,1,1,1);parameters(p,5);double w=positive(p[0]),a=p[1],g=p[2],b=p[3],h=positive(p[4]);require(a>=0&&g>=0&&b>=0,"Negative GJR parameter");Report o{{"Innovation","SymmetricComponent","AsymmetryComponent","NextVariance"},{}};
    for(auto&r:x){double e=r[0],q=e*e,u=a*q,v=e<0?g*q:0;o.rows.push_back({e,u,v,w+u+v+b*h});}return o;
}
} }
