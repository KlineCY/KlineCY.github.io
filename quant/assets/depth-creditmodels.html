生存条件下的远期违约概率与区间强度

数学定义与推导

无条件区间违约质量是生存曲线下降量；条件于存活至t的远期违约概率还需除以S(t)。强度是条件存活比例的负对数除以区间长度。在确定分段常强度模型中该平均强度正好是分段强度。

$$PD(t,T)=S(t)-S(T)$$
$$\Pr(t<\tau\le T\mid\tau>t)=1-S(T)/S(t)$$
$$\bar\lambda_{t,T}=-\frac{\log[S(T)/S(t)]}{T-t}$$

数值演算与金融应用

首年存活从1降至0.9，后两年从0.9降至0.81；两区间条件PD均10％，但第二段跨两年，年化强度只有首段的一半。可用于信用期限结构的边际与条件风险口径核对。

算法复杂度、输入契约与边界

O(n)，生存概率严格正且不增、起始时间非负、终止大于开始；各行独立区间，不自动拼接曲线。风险中性生存概率与实际违约概率不能直接混用。

保证金冻结期间的暴露跃迁

数学定义与推导

保证金风险期MPOR内假设不能及时收取新抵押，平仓时价值可能相对最后一次保证金状态变化。将冻结的同一抵押品余额与初始及平仓市值分别净额结算，得到暴露增量。负增量表示暴露下降，并非负损失。

$$E_t=(V_t-C_t)^+$$
$$E_{t+\delta}^{\mathrm{MPOR}}=(V_{t+\delta}-C_t)^+$$
$$\Delta E=E_{t+\delta}^{\mathrm{MPOR}}-E_t$$

数值演算与金融应用

初始市值100、抵押95，暴露5；平仓值120时暴露25，增加20；平仓90时暴露0。即使每日足额抵押，跳空、清算延迟和抵押品价值变化仍可产生剩余信用风险。

算法复杂度、输入契约与边界

O(n)，抵押为已收可抵销非负余额，市值允许负。真实MPOR需考虑双边保证金、抵押品价格和外汇变化、净额结算集及法律可执行性，本例固定抵押。

异质违约损失的条件矩与共同状态风险

数学定义与推导

给定共同状态后假设违约指标独立，但单个主体损失金额与PD可以不同。条件方差是各Bernoulli方差乘损失金额平方之和，状态间条件均值变化再通过全方差公式形成相关风险。代码按状态归集，不要求每组PD相同。

$$L=\sum_i a_iD_i,\quad D_i\mid Z=z\sim\operatorname{Bernoulli}(p_{iz})$$
$$m_z=\sum_i a_ip_{iz},\quad v_z=\sum_i a_i^2p_{iz}(1-p_{iz})$$
$$\operatorname{Var}(L)=\sum_z w_zv_z+\sum_z w_z(m_z-\bar m)^2$$

数值演算与金融应用

状态1的损失均值5，状态2为11，整体8；状态间方差9。条件方差分别73和117，平均95，总104。不同状态必须覆盖同一组合暴露结构；输入允许状态依赖的损失金额，但经济解释须保持一致。

算法复杂度、输入契约与边界

O(n log G)，每状态概率一致且状态权重和1，损失金额非负、PD在[0,1]。条件独立是模型假设，不代表真实信用资产独立；尾部形状不能仅由这两个矩确定。

右删失指数生存模型的强度极大似然

数学定义与推导

对默认事件贡献指数密度，对独立右删失贡献生存概率。合并对数似然后仅依赖违约次数D与风险暴露时间总和，导数置零得强度估计。无违约时最大值位于λ=0边界，按连续极限对数似然0处理。

$$L(\lambda)=\prod_i[\lambda e^{-\lambda t_i}]^{d_i}[e^{-\lambda t_i}]^{1-d_i}$$
$$\ell(\lambda)=D\log\lambda-\lambda\sum_i t_i$$
$$\hat\lambda=D/\sum_i t_i,\quad PD(1)=1-e^{-\hat\lambda}$$

数值演算与金融应用

三主体观察时间1、2、1年，违约标记1、0、1，总风险暴露4，估计强度0.5，一年PD约39.35％。这是教学数据的统计估计，不代表任何真实信用评级。

算法复杂度、输入契约与边界

O(n)，时间严格正、事件二元，假设同质常强度及独立非信息性删失。风险中性强度需要市场价格校准，不能将历史MLE直接当定价参数。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace depth_creditmodels {
using namespace evidence;
inline Report forward_default(const Mat& x,const Vec& p){
    validate(x,1,4,4);parameters(p,0);Report o{{"Start","End","UnconditionalPD","ConditionalPD","AverageHazard"},{}};
    for(auto&r:x){require(r[0]>=0&&r[2]>0&&r[2]<=1&&r[3]>0&&r[3]<=r[2],"Invalid survival interval");double h=positive(r[1]-r[0]),z=r[3]/r[2];o.rows.push_back({r[0],r[1],r[2]-r[3],1-z,-std::log(z)/h});}return o;
}

inline Report margin_period_risk(const Mat& x,const Vec& p){
    validate(x,1,3,3);parameters(p,0);Report o{{"Scenario","InitialExposure","CloseoutExposure","ExposureIncrease"},{}};
    for(std::size_t i=0;i<x.size();++i){auto&r=x[i];require(r[1]>=0,"Negative received collateral");double a=std::max(r[0]-r[1],0.),b=std::max(r[2]-r[1],0.);o.rows.push_back({double(i+1),a,b,b-a});}return o;
}

inline Report heterogeneous_credit_mixture(const Mat& x,const Vec& p){
    validate(x,1,4,4);parameters(p,0);std::map<double,Vec> g;
    for(auto&r:x){require(r[0]==std::floor(r[0])&&r[1]>=0&&r[2]>=0&&r[3]>=0&&r[3]<=1,"Invalid credit row");if(!g.count(r[0]))g[r[0]]={r[1],0,0};auto&v=g[r[0]];require(v[0]==r[1],"Inconsistent scenario probability");v[1]+=r[2]*r[3];v[2]+=r[2]*r[2]*r[3]*(1-r[3]);}
    double s=0,m=0,a=0;for(auto&z:g){auto&v=z.second;s+=v[0];m+=v[0]*v[1];a+=v[0]*v[2];}require(std::abs(s-1)<1e-10,"Scenario weights");double b=0;for(auto&z:g){auto&v=z.second;b+=v[0]*(v[1]-m)*(v[1]-m);}return scalar({"ExpectedLoss","WithinVariance","BetweenVariance","TotalVariance"},{m,a,b,a+b});
}

inline Report exponential_hazard_mle(const Mat& x,const Vec& p){
    validate(x,1,2,2);parameters(p,0);double T=0,d=0;
    for(auto&r:x){T+=positive(r[0]);require(r[1]==0||r[1]==1,"Binary default required");d+=r[1];}double l=d/T,v=d==0?0:d*std::log(l)-l*T;return scalar({"Defaults","TotalExposure","Hazard","LogLikelihood","OneYearPD"},{d,T,l,v,-std::expm1(-l)});
}
} }
