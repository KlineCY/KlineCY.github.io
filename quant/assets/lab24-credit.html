1．三状态信用迁移矩阵的多期推进

模型结构与数学定义

将信用状态划分为两个非违约评级和一个吸收违约状态。验证三行转移概率分别和为1、最后一行是吸收状态，再逐期推进初始概率向量。输出期限末三个状态的完整概率分布。

$$p_{t+h}=p_tP^h$$

推导、最优性条件与数值结构

$$\sum_jP_{ij}=1,\quad P_{D,D}=1,\quad p_D(t+1)\ge p_D(t)$$

转移矩阵每行概率和为1，所以概率向量在矩阵乘法下保持总质量。违约状态为吸收态，其质量只能增加；多期违约率可由最后一分量直接读取。

完整计算案例

初始全在优质状态，转移矩阵第一行(0.8,0.1,0.1)，第二行(0,0.8,0.2)，违约状态吸收。两期后概率为(0.64,0.16,0.2)。

$$\mathrm{Output}\approx\left(0.64,\ 0.16,\ 0.2\right)$$

输出顺序：期限末优质评级、弱评级、违约状态的概率。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

2．独立异质违约概率的Poisson–Binomial分布

模型结构与数学定义

初始化零违约概率为1。每加入一笔信用敞口，就从高违约数向低违约数倒序更新概率质量，分别考虑新增债项违约和不违约两种状态。输出从零违约至全部违约的完整概率质量函数。

$$p_k^{(i)}=(1-q_i)p_k^{(i-1)}+q_ip_{k-1}^{(i-1)}$$

推导、最优性条件与数值结构

$$G(z)=\prod_{i=1}^n[(1-q_i)+q_i z],\quad \Pr(N=k)=[z^k]G(z)$$

独立指示变量的概率生成函数相乘，每次乘入一个一次多项式即产生概率卷积。倒序更新避免本轮新概率覆盖尚未读取的上一轮概率。

完整计算案例

两笔独立违约概率0.1、0.2：零笔违约0.72、一笔0.26、两笔0.02。

$$\mathrm{Output}\approx\left(0.72,\ 0.26,\ 0.02\right)$$

输出顺序：由零违约到所有债项违约的概率质量。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

3．独立信用损失的整数格点卷积

模型结构与数学定义

将每个债项的违约损失金额映射到整数损失格点。动态规划在每新增一个债项后更新组合损失分布，然后计算预期损失、分位损失与精确尾部质量的Expected Shortfall。

$$f_i(\ell)=(1-q_i)f_{i-1}(\ell)+q_i f_{i-1}(\ell-L_i)$$

推导、最优性条件与数值结构

$$ES_\alpha=\frac{\sum_{k>v}k f(k)+v\,[1-\alpha-\Pr(L>v)]}{1-\alpha},\quad v=VaR_\alpha$$

先按损失格点分布求累计概率达到置信水平的最小损失。离散分布可能在分位数点存在概率原子，因此从最大损失开始精确取满1−α概率质量，比直接对超过VaR的样本平均更符合积分定义。

完整计算案例

两笔损失金额均1，违约概率0.1、0.2，置信度0.9；平均损失0.3，VaR为1，最坏10%质量含2%双违约、8%单违约，ES=1.2。

$$\mathrm{Output}\approx\left(0.3,\ 1,\ 1.2\right)$$

输出顺序：组合预期损失、分位数VaR、按尾部质量积分的ES。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

4．分段常数违约强度的边际违约与生存概率

模型结构与数学定义

在每段时间区间内假设违约强度常数。利用条件生存概率的指数形式逐段推进累计生存概率，并记录该段边际违约质量。输出交替排列的生存概率及边际违约概率。

$$S(t_i)=S(t_{i-1})e^{-\lambda_i\Delta t_i},\quad PD_i=S(t_{i-1})-S(t_i)$$

推导、最优性条件与数值结构

$$S(t)=\exp(-\int_0^t\lambda(s)ds),\quad \Pr(t_{i-1}<\tau\le t_i)=S(t_{i-1})(1-e^{-\lambda_i\Delta t_i})$$

累计强度为每段强度乘持续时间之和，生存概率由累计强度的指数衰减给出。边际违约质量使用前段末生存概率乘当前段条件违约概率；数值实现用expm1减少极短区间的消减误差。

完整计算案例

每段一年、强度log2，两段生存概率分别0.5、0.25，边际违约质量分别0.5、0.25。

$$\mathrm{Output}\approx\left(0.5,\ 0.5,\ 0.25,\ 0.25\right)$$

输出顺序：每个区间末生存概率与该区间边际违约概率，交替排列。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

5．离散支付CDS平价保护费率

模型结构与数学定义

按各期生存曲线下降确定边际违约概率，把约定损失率乘边际违约概率及期末贴现因子，构成保护腿；保费腿由生存概率加权的计息期现值构成。令双方现值相等，求平价年化费率。输出保护腿、风险年金及费率。

$$s=\frac{(1-R)\sum_iD_i(S_{i-1}-S_i)}{\sum_i\Delta t_iD_i S_i}$$

推导、最优性条件与数值结构

$$PV_{\rm protection}=LGD\sum_iD_i\Delta PD_i,\quad PV_{\rm premium}=s\sum_i\Delta t_iD_iS_i$$

用边际违约质量计算违约支付的期望，以生存概率计算仍需缴纳的保费。固定回收率下，令两个现值相等得到平价费率，若保费腿为零则费率没有定义。

完整计算案例

一年期生存概率0.9、贴现因子1、回收率0.4时，保护腿0.06、年金0.9、费率0.0666667。

$$\mathrm{Output}\approx\left(0.06,\ 0.9,\ 0.0666666667\right)$$

输出顺序：单位名义金额保护腿现值、风险年金、年化平价费率。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

#pragma once
#include "lab24_common.hpp"

namespace kline { namespace lab24 {
inline Vec migration_two(const Mat& x,const Vec& p){
    inputs(x,p,3,4,3);require(x.size()==3,"Three rating states required");auto h=integer(p[0],1,100000);Vec v(p.begin()+1,p.end());
    for(double q:v){require(q>=0&&q<=1,"Invalid initial state probability");}
    require(std::abs(sum(v)-1)<1e-10,"Initial probabilities must sum to one");
    for(const auto& r:x){for(double q:r)require(q>=0&&q<=1,"Invalid transition");require(std::abs(sum(r)-1)<1e-10,"Transition rows must sum to one");}
    require(x[2][0]==0&&x[2][1]==0&&x[2][2]==1,"Default state must be absorbing");
    for(std::size_t t=0;t<h;++t){Vec w(3,0);for(std::size_t i=0;i<3;++i)for(std::size_t j=0;j<3;++j)w[j]+=v[i]*x[i][j];v=std::move(w);}
    return checked(v);
}

inline Vec poisson_binomial(const Mat& x,const Vec& p){
    inputs(x,p,1,0);require(x.size()<=1000,"Exact convolution limited to 1000 debts");Vec d(x.size()+1,0);d[0]=1;std::size_t n=0;
    for(const auto& r:x){double q=r[0];require(q>=0&&q<=1,"Invalid PD");++n;for(std::size_t k=n;k>0;--k)d[k]=(1-q)*d[k]+q*d[k-1];d[0]*=1-q;}
    return checked(d);
}

inline Vec loss_convolution(const Mat& x,const Vec& p){
    inputs(x,p,2,1);require(p[0]>0&&p[0]<1,"Invalid confidence");require(x.size()<=1000,"Too many credit names");std::size_t maxloss=0;
    for(const auto& r:x){require(r[0]>=0&&r[0]<=1,"Invalid PD");maxloss+=integer(r[1],0,20000);require(maxloss<=20000,"Loss grid too large");}
    Vec d(maxloss+1,0);d[0]=1;std::size_t current=0;
    for(const auto& r:x){auto l=std::size_t(r[1]);double q=r[0];if(l==0)continue;current+=l;for(std::size_t k=current+1;k-->0;){d[k]=(1-q)*d[k]+(k>=l?q*d[k-l]:0);}}
    double el=0,cdf=0,var=0;bool found=false;for(std::size_t k=0;k<d.size();++k){el+=k*d[k];cdf+=d[k];if(!found&&cdf>=p[0]-1e-14){var=double(k);found=true;}}
    double mass=1-p[0],left=mass,tail=0;for(std::size_t k=d.size();k-->0&&left>0;){double take=std::min(left,d[k]);tail+=take*k;left-=take;}
    return checked({el,var,tail/mass});
}

inline Vec survival_hazard(const Mat& x,const Vec& p){
    inputs(x,p,2,0);double last=0,s=1;Vec out;
    for(const auto& r:x){require(r[0]>last&&r[1]>=0,"Invalid hazard interval");double e=-r[1]*(r[0]-last),d=s*(-std::expm1(e));s*=std::exp(e);out.push_back(s);out.push_back(d);last=r[0];}
    return checked(out);
}

inline Vec discrete_cds_spread(const Mat& x,const Vec& p){
    inputs(x,p,3,1);require(p[0]>=0&&p[0]<=1,"Invalid recovery");double t=0,s=1,a=0,b=0;
    for(const auto& r:x){require(r[0]>t&&r[1]>=0&&r[1]<=s,"Invalid survival schedule");positive(r[2]);a+=(1-p[0])*r[2]*(s-r[1]);b+=(r[0]-t)*r[2]*r[1];t=r[0];s=r[1];}
    return checked({a,b,a/positive(b)});
}

inline void inputs(const Mat& x,const Vec& p,std::size_t cols,std::size_t params,
                   std::size_t min_rows=1) {
    require(x.size()>=min_rows&&x.size()<=250000,"Invalid number of observations");
    require(p.size()==params,"Incorrect scalar parameter count");
    for(double v:p)require(std::isfinite(v),"Nonfinite scalar parameter");
    for(const auto& row:x){
        require(row.size()==cols,"Unexpected CSV column count");
        for(double v:row)require(std::isfinite(v),"Nonfinite matrix entry");
    }
}
inline std::size_t integer(double x,std::size_t low,std::size_t high){
    require(std::isfinite(x)&&x>=double(low)&&x<=double(high)&&std::floor(x)==x,
            "Integer parameter outside allowed range");
    return std::size_t(x);
}
inline double dot(const Vec& a,const Vec& b){
    require(a.size()==b.size(),"Dot product dimension mismatch");
    return std::inner_product(a.begin(),a.end(),b.begin(),0.0);
}
inline Vec col(const Mat& x,std::size_t j){
    Vec out;out.reserve(x.size());
    for(const auto& row:x)out.push_back(row.at(j));
    return out;
}
inline double positive(double x){require(x>0&&std::isfinite(x),"Positive finite quantity required");return x;}
inline Vec checked(Vec v){check_finite(v);return v;}
inline double logistic(double x){
    if(x>=0)return 1/(1+std::exp(-x));
    double e=std::exp(x);return e/(1+e);
}
