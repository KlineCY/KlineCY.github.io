1．带连续股息率的CRR美式期权倒推

模型结构与数学定义

在每一期二叉树节点，风险中性概率由无套利条件下的标的增长因子确定。末期从内在价值开始，逐期计算持有价值并与提前行权价值比较。内存仅保留当前层和下一层的值；输出美式价格及同树欧式价格。

$$V_{t,j}=\max\{g(S_{t,j}),e^{-r\Delta t}[qV_{t+1,j+1}+(1-q)V_{t+1,j}]\}$$

推导、最优性条件与数值结构

$$u=e^{\sigma\sqrt{\Delta t}},\quad d=u^{-1},\quad q=\frac{e^{(r-q_d)\Delta t}-d}{u-d}$$

复制两个下一期状态的期权现金流，可解出无套利价格的贴现概率形式。提前行权产生一个额外选择：若立即支付更高，则节点价值取立即行权收益；欧式树仅使用继续持有价值。

完整计算案例

标的100、执行价100、零利率零股息、波动率log(2)、到期1年、一步看跌。上节点200、下节点50，风险中性向上概率1/3，欧式及美式价格均为100/3。

$$\mathrm{Output}\approx\left(33.3333333,\ 33.3333333\right)$$

输出顺序：美式期权价格、相同树参数的欧式期权价格。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

2．离散算术平均亚式期权路径定价

模型结构与数学定义

每条路径占一行、三个等权观察时间的标的价格占三列，按行计算算术均值及看涨或看跌收益。再对预设风险中性等权样本计算贴现均值和基于独立路径假设的Monte Carlo标准误。输出期权价格、标准误。

$$\widehat V=e^{-rT}N^{-1}\sum_{i=1}^N(\overline S_i-K)_+$$

推导、最优性条件与数值结构

$$SE(\widehat V)=\sqrt{\frac{1}{N(N-1)}\sum_i(Y_i-\bar Y)^2},\quad Y_i=e^{-rT}g(\overline S_i)$$

贴现后的路径收益Y_i构成风险中性独立同分布样本。以路径均值估计期权价值，再以样本方差除以路径数得到均值估计方差，标准误反映抽样误差而非模型误差。

完整计算案例

两条路径的三个价格均为110或90，执行价100、零利率、期限1年。收益为10、0，价格5，样本标准误5。

$$\mathrm{Output}\approx\left(5,\ 5\right)$$

输出顺序：期权估计现值、Monte Carlo标准误。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

3．非均匀执行价网格的无蝶式套利检查

模型结构与数学定义

在同到期日看涨价格曲线上，先计算相邻执行价的割线斜率。无套利要求看涨价格非增且对执行价凸；两侧斜率差的非均匀二阶差分近似Breeden–Litzenberger风险中性密度。输出最小未贴现密度及负密度节点数量。

$$\rho_i\approx e^{rT}\frac{2}{K_{i+1}-K_{i-1}}\left(\frac{C_{i+1}-C_i}{K_{i+1}-K_i}-\frac{C_i-C_{i-1}}{K_i-K_{i-1}}\right)$$

推导、最优性条件与数值结构

$$C(K)=e^{-rT}\mathbb E^Q[(S_T-K)_+],\quad \frac{\partial^2 C}{\partial K^2}=e^{-rT}f_{S_T}(K)$$

对连续分布的看涨价格关于执行价求导，一阶导数对应负的风险中性尾概率，二阶导数对应贴现密度。实现以相邻割线斜率差检查凸性；价格单调性和边界斜率需额外检查。

完整计算案例

执行价90、100、120，对应价格15、8、2。斜率−0.7与−0.3，二阶差分为2×0.4/30=0.0266667；利率为零，负密度节点0。

$$\mathrm{Output}\approx\left(0.0266666667,\ 0\right)$$

输出顺序：最小离散风险中性密度近似、负密度内部节点数。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

4．离散期权条带的方差互换积分近似

模型结构与数学定义

输入远期价附近及两侧的价外期权报价，采用相邻执行价半间距作为内部积分权重、端点用最近间距。累计期权价格除以执行价平方的贡献，最后扣除远期价和基准执行价偏离的离散修正。输出年化方差与平方根波动率。

$$K_{\rm var}\approx\frac{2e^{rT}}{T}\sum_i\frac{\Delta K_i}{K_i^2}Q(K_i)-\frac1T(F/K_0-1)^2$$

推导、最优性条件与数值结构

$$\Delta K_i=\frac{K_{i+1}-K_{i-1}}2\quad (1<i<n),\qquad \sigma_{\rm ann}=\sqrt{K_{\rm var}}$$

连续复制表达式中，期权价格按执行价平方的倒数加权。离散化使用非均匀网格的区间宽度，对远期与基准执行价的偏离进行修正。实际基准执行价应采用不超过远期的最大可用执行价。

完整计算案例

三个执行价90、100、110，OTM期权价格均为1，远期与基准价均为100、零利率、期限1。方差为20×(1/90²+1/100²+1/110²)。

$$\mathrm{Output}\approx\left(0.00612202836,\ 0.0782433918\right)$$

输出顺序：离散年化方差、平方根年化波动率。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

5．带融资与交易成本的离散Delta对冲账本

模型结构与数学定义

卖出一份期权并按初始Delta买入标的，将剩余权利金记入现金账户。每个时间间隔现金账户先计息，随后按新Delta调整标的仓位并扣除比例交易成本；到期清算标的并支付给定的期权收益。返回最终复制盈亏和累计交易成本。

$$B_{t+1}=B_te^{r\Delta t}-(\Delta_{t+1}-\Delta_t)S_{t+1}-c|\Delta_{t+1}-\Delta_t|S_{t+1}$$

推导、最优性条件与数值结构

$$\Pi_T=B_T+\Delta_TS_T-H_T,\quad TC=\sum_t c|\Delta_t-\Delta_{t-1}|S_t$$

初始Delta购入股票消耗现金、期权权利金增加现金；之后自融资的现金账户变化来自持仓调整与费用。终止时归零持仓，现金余额减去期权支付即为盈亏。公式中Delta_T表示清算前库存，代码在最后一步显式将其清算。

完整计算案例

标的价格从100变至110，初始与末期Delta均0.5，期权初始权利金5，终值支付10，无成本零利率；初始现金−45、股票终值55，最终盈亏0。

$$\mathrm{Output}\approx\left(0,\ 0\right)$$

输出顺序：最终复制盈亏、累计交易成本。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

#pragma once

inline Vec crr_american(const Mat& x,const Vec& p){
    inputs(x,p,1,8);require(x.size()==1,"Single placeholder row required");double s=positive(p[0]),k=positive(p[1]),r=p[2],div=p[3],sig=positive(p[4]),T=positive(p[5]);auto n=integer(p[6],1,2500);require(p[7]==0||p[7]==1,"Call flag must be binary");
    double dt=T/n,a=sig*std::sqrt(dt),u=std::exp(a),d=1/u,q=(std::exp((r-div)*dt)-d)/(u-d),disc=std::exp(-r*dt);
    require(q>=0&&q<=1&&std::isfinite(disc),"Invalid risk-neutral tree");
    auto payoff=[&](double st){return std::max(0.0,p[7]==1?st-k:k-st);};
    Vec v(n+1),e(n+1);for(std::size_t j=0;j<=n;++j)v[j]=e[j]=payoff(s*std::exp((2.0*j-n)*a));
    for(std::size_t i=n;i-->0;)for(std::size_t j=0;j<=i;++j){v[j]=std::max(payoff(s*std::exp((2.0*j-i)*a)),disc*((1-q)*v[j]+q*v[j+1]));e[j]=disc*((1-q)*e[j]+q*e[j+1]);}
    return checked({v[0],e[0]});
}

inline Vec asian_path(const Mat& x,const Vec& p){
    inputs(x,p,3,4,2);double k=positive(p[0]),T=positive(p[2]);require(p[3]==0||p[3]==1,"Call flag must be binary");Vec payoff;
    double disc=std::exp(-p[1]*T);
    for(const auto& r:x){for(double q:r)positive(q);double a=sum(r)/3;payoff.push_back(disc*std::max(0.0,p[3]==1?a-k:k-a));}
    return checked({mean(payoff),std::sqrt(variance(payoff)/payoff.size())});
}

inline Vec butterfly_density(const Mat& x,const Vec& p){
    inputs(x,p,2,2,3);double T=positive(p[1]),minv=std::numeric_limits<double>::infinity();int bad=0;
    for(std::size_t i=0;i<x.size();++i){positive(x[i][0]);require(x[i][1]>=0,"Negative call price");if(i)require(x[i][0]>x[i-1][0],"Strikes must increase");}
    for(std::size_t i=1;i+1<x.size();++i){double l=(x[i][1]-x[i-1][1])/(x[i][0]-x[i-1][0]),r=(x[i+1][1]-x[i][1])/(x[i+1][0]-x[i][0]);double v=std::exp(p[0]*T)*2*(r-l)/(x[i+1][0]-x[i-1][0]);minv=std::min(minv,v);bad+=v<-1e-12;}
    return checked({minv,double(bad)});
}

inline Vec variance_strip(const Mat& x,const Vec& p){
    inputs(x,p,2,4,2);double F=positive(p[0]),K0=positive(p[1]),T=positive(p[3]),s=0;bool found=false;
    require(K0<=F,"Base strike must not exceed forward");
    for(std::size_t i=0;i<x.size();++i){positive(x[i][0]);require(x[i][1]>=0,"Negative option price");if(i)require(x[i][0]>x[i-1][0],"Strike grid must increase");found=found||x[i][0]==K0;}
    require(found,"Base strike missing");
    for(std::size_t i=0;i<x.size();++i){double dk=i==0?x[1][0]-x[0][0]:(i+1==x.size()?x[i][0]-x[i-1][0]:(x[i+1][0]-x[i-1][0])/2);s+=dk*x[i][1]/(x[i][0]*x[i][0]);}
    double v=(2*std::exp(p[2]*T)*s-std::pow(F/K0-1,2))/T;require(v>=0,"Negative discretized variance");return checked({v,std::sqrt(v)});
}

inline Vec discrete_delta_pnl(const Mat& x,const Vec& p){
    inputs(x,p,3,4,2);require(p[0]>=0&&p[1]>=0&&p[3]>=0&&x.front()[0]==0,"Invalid hedge setup");
    for(std::size_t i=0;i<x.size();++i){positive(x[i][1]);if(i)require(x[i][0]>x[i-1][0],"Hedge times must increase");}
    double h=x[0][2],cost=p[3]*std::abs(h)*x[0][1],cash=p[0]-h*x[0][1]-cost;
    for(std::size_t i=1;i<x.size();++i){cash*=std::exp(p[2]*(x[i][0]-x[i-1][0]));double target=i+1==x.size()?0:x[i][2],change=target-h,fee=p[3]*std::abs(change)*x[i][1];cash-=change*x[i][1]+fee;cost+=fee;h=target;}
    return checked({cash-p[1],cost});
}

inline void inputs(const Mat& x,const Vec& p,std::size_t cols,std::size_t params,
                   std::size_t min_rows=1) {
    require(x.size()>=min_rows&&x.size()<=250000,"Invalid number of observations");
    require(p.size()==params,"Incorrect scalar parameter count");
    for(double v:p)require(std::isfinite(v),"Nonfinite scalar parameter");
    for(const auto& row:x){
        require(row.size()==cols,"Unexpected CSV column count");
        for(double v:row)require(std::isfinite(v),"Nonfinite matrix entry");
    }
}
inline std::size_t integer(double x,std::size_t low,std::size_t high){
    require(std::isfinite(x)&&x>=double(low)&&x<=double(high)&&std::floor(x)==x,
            "Integer parameter outside allowed range");
    return std::size_t(x);
}
inline double dot(const Vec& a,const Vec& b){
    require(a.size()==b.size(),"Dot product dimension mismatch");
    return std::inner_product(a.begin(),a.end(),b.begin(),0.0);
}
inline Vec col(const Mat& x,std::size_t j){
    Vec out;out.reserve(x.size());
    for(const auto& row:x)out.push_back(row.at(j));
    return out;
}
inline double positive(double x){require(x>0&&std::isfinite(x),"Positive finite quantity required");return x;}
inline Vec checked(Vec v){check_finite(v);return v;}
inline double logistic(double x){
    if(x>=0)return 1/(1+std::exp(-x));
    double e=std::exp(x);return e/(1+e);
}
inline double normal_cdf(double x){return 0.5*std::erfc(-x/std::sqrt(2.0));}
