风险中性树的逐节点鞅缺口

数学定义与推导

无分红资产在风险中性测度下的贴现价格是鞅。有限状态树中，这一条件必须逐节点满足，而非仅在起点比较无条件期望；每个节点的条件概率和为1，贴现因子及父节点价格在该组内一致。缺口报告用于校验模型，不自动修正概率。

$$\widetilde S_t=S_t/B_t,\quad \mathbb E^Q[\widetilde S_{t+1}\mid\mathcal F_t]=\widetilde S_t$$
$$S(v)=D_v\sum_{u\in\mathrm{child}(v)}q_{vu}S(u)\quad\text{(no dividends)}$$
$$\epsilon_v=D_v\sum_u q_{vu}S(u)-S(v)$$

数值演算与金融应用

节点1父价100，子价80、120等概率，贴现1，缺口0。节点2父价50，子价40、60等概率，贴现0.95，贴现期望47.5，缺口−2.5。若输入资产含息或分红，需将期间现金流加入子节点总价值。

算法复杂度、输入契约与边界

O(n log G)，节点ID整数，概率非负、贴现正、价格非负，组内一致性以容差检验。非零缺口可能来自现金流遗漏、概率误设或单位不一致；不单凭此断言市场存在可交易套利。

有限情景的计价基准测度变换

数学定义与推导

当N和B均为正的可交易计价基准时，贴现相对价值是基准测度下的鞅，其终值与初值之比为Radon–Nikodym密度。有限情景逐项乘密度即可获得新测度概率。代码要求密度已按初值归一，不将任意归一化权重冒充合法市场测度。

$$\frac{dQ^N}{dQ^B}\bigg|_T=\frac{N_T/B_T}{N_0/B_0}=Z_T$$
$$\mathbb E^{Q^B}Z_T=1,\quad q_i^N=q_i^B Z_i$$
$$\mathbb E^{Q^N}[H_T/N_T]=\mathbb E^{Q^B}[Z_T H_T/N_T]$$

数值演算与金融应用

基础等概率，密度0.5与1.5，新概率0.25与0.75；以新基准为单位的支付2及4，其两项期望贡献0.5与3。改变计价基准不会改变对应货币价格，但支付也必须同步转换单位。

算法复杂度、输入契约与边界

O(n)，基础概率非负且和1，密度严格正且基础加权均值1。实际计价基准必须可交易并满足鞅条件，数值归一只是必要条件，不是充分的市场证明。

固定停止策略的路径估值与行权分布

数学定义与推导

美式合约价值为合法停止时刻的最优期望。给定在各时点只依赖当时信息的固定行权策略，沿路径找到首次行权，未提前行权则在最终时点支付。独立估值路径上的均值估计该策略价值，可作为最优价值的期望下界；有限Monte Carlo样本本身不保证逐次低于真实最优值。

$$\tau(\omega)=\inf\{t:\pi_t(\omega)=1\}\wedge T$$
$$V^\pi=\mathbb E^Q[H_\tau/B_\tau]$$
$$V^\pi\le\sup_{\tau\in\mathcal T}\mathbb E^Q[H_\tau/B_\tau]$$

数值演算与金融应用

三条已贴现支付路径，行权时点分别1、2、0，支付3、4、1，样本均值8/3。将训练期拟合的行权规则用于独立模拟路径，避免在同一路径上训练并选择最优事后时点造成向上偏差。

算法复杂度、输入契约与边界

O(nT)，前T+1列已贴现支付、后T列二元行权标记，末期强制结算。输入标记的适应性不能由结果反推，须由策略生成过程保证。程序只报告样本均值，不自动置信区间。

美式期权的鞅对偶上界

数学定义与推导

对任何合法停止时刻，贴现支付期望等于支付减零初值鞅的期望。路径最大值支配任一停止时点，因此得到对偶上界。选择与Snell包络Doob分解接近的鞅可收紧界；若直接取事后最大支付，对应零鞅的较松上界。

$$V_0=\sup_{\tau\in\mathcal T}\mathbb E[H_\tau]$$
$$\mathbb E[M_\tau]=M_0=0\quad\text{for an integrable martingale and bounded }\tau$$
$$V_0\le\mathbb E[\max_{0\le t\le T}(H_t-M_t)]$$

数值演算与金融应用

两条等权路径H=(1,3,2)及(1,0,4)，M=(0,1,1)及(0,−1,−1)。第一期鞅均值0，之后各分支保持不变，因而在此两分支树中是合法鞅。逐路径最大差为2和5，样本均值3.5。一般输入不能仅靠无条件均值证明鞅性。

算法复杂度、输入契约与边界

O(nT)，前半列为贴现支付，后半列为同时间网格的鞅值，初值必须0。程序不推断过滤信息，合法鞅必须由独立模型证明；Monte Carlo样本均值有抽样误差，不是确定性上界。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace depth_dynamicpricing {
using namespace evidence;
inline Report node_martingale(const Mat& x,const Vec& p){
    validate(x,1,5,5);parameters(p,0);std::map<double,Vec> g;
    for(auto&r:x){require(r[0]==std::floor(r[0])&&r[1]>=0&&r[2]>=0&&r[3]>=0,"Invalid node data");positive(r[4]);if(!g.count(r[0]))g[r[0]]={r[1],r[4],0,0};auto&v=g[r[0]];require(v[0]==r[1]&&v[1]==r[4],"Inconsistent parent or discount");v[2]+=r[3];v[3]+=r[3]*r[2];}
    Report o{{"Node","Parent","DiscountedChildMean","MartingaleGap"},{}};
    for(auto&z:g){auto&v=z.second;require(std::abs(v[2]-1)<1e-10,"Conditional probability sum");double a=v[1]*v[3];o.rows.push_back({z.first,v[0],a,a-v[0]});}return o;
}

inline Report numeraire_measure(const Mat& x,const Vec& p){
    validate(x,1,3,3);parameters(p,0);double a=0,b=0;Report o{{"Scenario","NewProbability","BaseWeightedPayoff","NewWeightedPayoff"},{}};
    for(std::size_t i=0;i<x.size();++i){auto&r=x[i];require(r[0]>=0,"Negative base probability");double z=positive(r[1]),q=r[0]*z;a+=r[0];b+=q;o.rows.push_back({double(i+1),q,r[0]*z*r[2],q*r[2]});}require(std::abs(a-1)<1e-10&&std::abs(b-1)<1e-10,"Probability or density normalization");return o;
}

inline Report stopping_policy_value(const Mat& x,const Vec& p){
    auto d=validate(x,1,3,63);parameters(p,0);require(d%2==1,"Payoff and exercise dimensions differ");auto T=(d-1)/2;double s=0;Report o{{"Path","ExerciseTime","DiscountedPayoff","RunningMean"},{}};
    for(std::size_t i=0;i<x.size();++i){auto&r=x[i];std::size_t k=T;for(std::size_t j=0;j<T;++j){double a=r[T+1+j];require(a==0||a==1,"Binary policy flag required");if(a&&k==T)k=j;}double v=r[k];s+=v;o.rows.push_back({double(i+1),double(k),v,s/(i+1)});}return o;
}

inline Report dual_stopping_bound(const Mat& x,const Vec& p){
    auto d=validate(x,1,4,64);parameters(p,0);require(d%2==0,"Equal payoff and martingale columns required");auto n=d/2;double s=0;Report o{{"Path","PathwiseUpper","RunningMean"},{}};
    for(std::size_t i=0;i<x.size();++i){auto&r=x[i];require(r[n]==0,"Martingale must start at zero");double v=r[0];for(std::size_t j=1;j<n;++j)v=std::max(v,r[j]-r[n+j]);s+=v;o.rows.push_back({double(i+1),v,s/(i+1)});}return o;
}
