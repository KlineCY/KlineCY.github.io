Margrabe双资产交换期权

模型与推导

将到期支付(S₁−S₂)正部改以第二资产总收益为计价基准，资产比率的对数扩散由两资产协方差决定。相对波动率替代单资产波动率，风险中性利率在该交换支付中抵销。相关性必须处于合法范围；有效波动率为零时采用确定性极限。

$$\sigma_*^2=\sigma_1^2+\sigma_2^2-2\rho\sigma_1\sigma_2$$
$$C=S_1e^{-q_1T}\Phi(d_1)-S_2e^{-q_2T}\Phi(d_2),\quad d_1=\frac{\log(S_1/S_2)+(q_2-q_1+\sigma_*^2/2)T}{\sigma_*\sqrt T},\ d_2=d_1-\sigma_*\sqrt T$$

研究应用与成立条件

两个现货均100，波动率均20％、相关0.5、无分红，交换波动20％，价格约7.97。适用于成对资产交换的理想化欧式定价；随机相关、非同步交易或融资差异需要更丰富模型。

远期起始平值比例期权

模型与推导

在起始日t₀，执行价成为κ倍当期标的，Black–Scholes价格对S_{t₀}一次齐次。再将该条件价格贴现取期望，得到现值S₀e^{-qt₀}乘剩余期限比例期权价值。实现固定κ＝1。

$$H_T=(S_T-\kappa S_{t_0})^+$$
$$C_0=S_0e^{-qt_0}\left[e^{-q\Delta}\Phi(d_1)-\kappa e^{-r\Delta}\Phi(d_2)\right],\quad d_1=\frac{-\log\kappa+(r-q+\sigma^2/2)\Delta}{\sigma\sqrt\Delta}$$

研究应用与成立条件

起始0.5年、到期1年、现货100、波动30％且利率分红为零，剩余有效波动约0.2121。该公式依赖常波动与确定利率，不能直接用于带波动率偏斜的远期起始报价。

Quanto外币资产的本币测度漂移

模型与推导

外汇X定义为每单位外币的本币价格。将外币资产转换为本币价值XS，Itô乘积的协变差项为ρσSσX；本币风险中性漂移约束使外币资产漂移扣除该项。此处输出固定汇率Quanto支付的基础期望，未乘本币贴现和约定汇率。

$$dS/S=(r_f-q-\rho\sigma_S\sigma_X)\,dt+\sigma_S\,dW^{(d)}$$
$$\mathbb E^{Q_d}S_T=S_0\exp[(r_f-q-\rho\sigma_S\sigma_X)T]$$

研究应用与成立条件

外币利率3％、分红1％、波动20％与10％、相关0.5，调整漂移1％。外汇报价倒数会改变相关符号；随机波动和随机利率需联合模型。

对数正态幂支付的解析价格

模型与推导

高斯矩母函数将幂支付转化为指数函数期望，公式对任意有限实数幂成立。幂0对应贴现债券，幂1对应预付远期，幂2包含波动率凸性调整。

$$\log S_T=\log S_0+(r-q-\sigma^2/2)T+\sigma W_T$$
$$e^{-rT}\mathbb E^{Q}S_T^a=S_0^a\exp\{[-r+a(r-q)+\tfrac12a(a-1)\sigma^2]T\}$$

研究应用与成立条件

现货100、波动20％、零利率及分红，一年二次支付价值10000e^0.04。支付单位随幂变化，实际合约需确定货币缩放；负幂对接近零的价格极敏感。

C++17实现

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace methods_derivatives {
using namespace evidence;
inline Report margrabe_exchange(const Mat& x,const Vec& p){
    validate(x,1,5,5);
    parameters(p,3);
    double T=positive(p[0]),q1=p[1],q2=p[2];
    Report o{{"EffectiveVol","ExchangeCall"},{}};
    for(auto&r:x){double a=positive(r[0]),b=positive(r[1]),u=r[2],v=r[3],c=r[4];
    require(u>=0&&v>=0&&std::abs(c)<=1,"Invalid volatility or correlation");
    double vol=std::sqrt((u-v)*(u-v)+2*u*v*(1-c)),f=a*std::exp(-q1*T),g=b*std::exp(-q2*T),z=vol*std::sqrt(T),price=std::max(f-g,0.);
    if(z>0){double d=std::log(f/g)/z+.5*z;
    price=f*normal(d)-g*normal(d-z);
    }o.rows.push_back({vol,price});
    }return o;
    
}

inline Report forward_start(const Mat& x,const Vec& p){
    validate(x,1,2,2);
    parameters(p,4);
    double S=positive(p[0]),r=p[1],q=p[2],vol=positive(p[3]);
    Report o{{"RemainingVol","Call"},{}};
    for(auto&a:x){double t=a[0],T=a[1];
    require(t>=0&&T>t,"Invalid exercise times");
    double h=T-t,z=vol*std::sqrt(h),d=(r-q+.5*vol*vol)*h/z;
    o.rows.push_back({z,S*std::exp(-q*t)*(std::exp(-q*h)*normal(d)-std::exp(-r*h)*normal(d-z))});
    }return o;
    
}

inline Report quanto_expectation(const Mat& x,const Vec& p){
    validate(x,1,1,1);
    parameters(p,6);
    double s=positive(p[0]),rf=p[1],q=p[2],u=p[3],v=p[4],rho=p[5];
    require(u>=0&&v>=0&&std::abs(rho)<=1,"Invalid vol or correlation");
    double a=rf-q-rho*u*v;
    Report o{{"Horizon","AdjustedDrift","ExpectedForeignPrice"},{}};
    for(auto&r:x){require(r[0]>=0,"Negative horizon");
    o.rows.push_back({r[0],a,s*std::exp(a*r[0])});
    }return o;
    
}

inline Report power_payoff(const Mat& x,const Vec& p){
    validate(x,1,1,1);
    parameters(p,5);
    double S=positive(p[0]),r=p[1],q=p[2],v=p[3],T=positive(p[4]);
    require(v>=0,"Negative volatility");
    Report o{{"Power","DiscountedMoment"},{}};
    for(auto&z:x){double a=z[0];
    o.rows.push_back({a,std::exp(a*std::log(S)+(-r+a*(r-q)+.5*a*(a-1)*v*v)*T)});
    }return o;
    
}
