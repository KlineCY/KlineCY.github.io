连续复制与有限报价

对连续路径及适当可积性，未来实现方差的风险中性期望可由对数合约静态复制。以未贴现远期看涨看跌价格表示，OTM条带在远期以下使用Put、以上使用Call，权重按执行价平方倒数衰减。有限执行价范围的积分只是截尾近似，不包含缺失尾部。

$$K_{\rm var}=\frac2T\left(\int_0^F\frac{P(K)}{K^2}dK+\int_F^\infty\frac{C(K)}{K^2}dK\right)$$

远期节点与报价口径

要求执行价网格严格递增且含远期F。远期节点上Put和Call应由平价相等；实现先检查每个报价的未贴现平价C−P=F−K，再使用远期节点两者均值。贴现市场报价必须先按一致曲线转换。未检查完整报价曲线的凸性及日历套利。

$$C(K)-P(K)=F-K,\quad f(K)=K^{-2}\begin{cases}P(K),&K<F\\(C(K)+P(K))/2,&K=F\\C(K),&K>F\end{cases}$$

梯形积分及误差

每个执行价区间使用梯形规则计算2/T倍积分贡献，并逐段累计。与实际指数方法的非均匀执行价权重、零买价规则及K0调整不同，此处是明确有限区间的教学积分。增加网格密度可改善内部积分误差，但不能恢复区间外尾部。

$$\Delta K_{{\rm var},i}=\frac{K_{i+1}-K_i}{T}(f_i+f_{i+1}),\quad K_{\rm var}^{[L,U]}=\sum_i\Delta K_{{\rm var},i}$$

参考与研究限制

F=100，执行价80、100、120，对应OTM价2、5、1，积分由两个长度20的梯形直接计算。输出每段、累计值及最大平价误差。跳跃过程下对数合约与实现二次变差的等价关系需调整，离散监测、费用和报价质量也会影响实际方差互换。

$$K_{\rm var}-K_{\rm var}^{[L,U]}=\frac2T\left(\int_0^L P(K)K^{-2}dK+\int_U^\infty C(K)K^{-2}dK\right)$$

C++17完整实现

inline Report variance_strip_quadrature(const Mat& x,const Vec& p){
    validate(x,3,3,3);parameters(p,3);double F=positive(p[0]),T=positive(p[1]),tol=positive(p[2]);
    Vec K,f;bool center=false;double err=0;
    for(auto&r:x){
        double k=positive(r[0]),c=r[1],put=r[2];
        require((K.empty()||k>K.back())&&c>=0&&put>=0,"Invalid option strip");
        double e=std::abs(c-put-F+k);err=std::max(err,e);
        require(e<=tol*std::max(1.,F),"Forward parity violated");
        center|=k==F;K.push_back(k);f.push_back((k<F?put:k>F?c:.5*(c+put))/(k*k));
    }
    require(center&&K.front()<F&&K.back()>F,"Strip must bracket and include forward");
    double s=0;Report out{{"LowerStrike","UpperStrike","LeftIntegrand","RightIntegrand","VarianceContribution","CumulativeVariance","ParityResidual"},{}};
    for(std::size_t i=1;i<K.size();++i){
        double v=(K[i]-K[i-1])*(f[i]+f[i-1])/T;s+=v;
        out.rows.push_back({K[i-1],K[i],f[i-1],f[i],v,s,err});
    }
    return out;
}
