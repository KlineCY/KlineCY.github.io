贴现与投影分离

多曲线框架中，抵押品贴现因子与参考利率远期曲线不是同一对象。在给定OIS贴现曲线下，同一参考期限的远期利率通过相应平价互换市场报价反推。这里要求逐期到期互换、相同固定与浮动支付时间、相同应计因子及无额外基差。

$$V_{\rm payer}(T_m)=N\sum_{i=1}^m D_i\alpha_i(F_i-K_m)$$

三角Bootstrap

第m条市场报价满足互换现值为零；前m−1期远期已经从更短期限报价识别，仅第m期未知。因此通过累计年金与累计浮动腿现值直接求F_m。这是一种精确离散Bootstrap，与对全部曲线做平滑最小二乘不同。

$$A_m=\sum_{i=1}^mD_i\alpha_i,\quad F_m=\frac{K_m A_m-\sum_{i<m}D_i\alpha_iF_i}{D_m\alpha_m}$$

重定价及单位

使用新远期更新浮动腿累计值，并按其与固定腿年金之比重构互换平价利率。注意输入ParSwap为年化简单利率，与应计因子相乘得到期间支付率；贴现因子为相对当前时点的价格。负利率可以存在，程序不强制远期非负。

$$\widehat K_m=\frac{\sum_{i\le m}D_i\alpha_i F_i}{A_m},\quad |\widehat K_m-K_m|$$

基准与边界

首期D=.95、平价2%，F1=.02；第二期D=.9、平价3%，F2=(.03×1.85−.019)/.9。所有市场互换重定价误差近零。复杂度O(n)，不对稀疏到期报价插值、不处理支付滞后、不同固定浮动频率、复利或跨币种基差。

$$\operatorname{PV01}_m=N\times10^{-4}\sum_{i=1}^mD_i\alpha_i$$

C++17完整实现

inline Report multicurve_forward_bootstrap(const Mat& x,const Vec& p){
    validate(x,1,4,4);parameters(p,0);
    double prev=0,A=0,B=0;Report out{{"Maturity","Accrual","Discount","ParSwap","Forward","Annuity","FloatingPV","RepricedSwap","Residual"},{}};
    for(auto&r:x){
        require(r[0]>prev,"Increasing maturity required");prev=r[0];
        double a=positive(r[1]),D=positive(r[2]),K=r[3],w=a*D;
        A+=w;double F=(K*A-B)/w;B+=w*F;
        double model=B/A;out.rows.push_back({r[0],a,D,K,F,A,B,model,std::abs(model-K)});
    }
    return out;
}
