数字期权、波动率二阶敏感度与远期方差

期权组合的风险既包括标的价格暴露，也包括波动率冲击与期限结构变化。数字期权价值、Vanna、Volga和远期方差从分布概率、混合偏导及总方差无套利关系出发建立一致的研究口径。

1．现金结算数字看涨期权

数学对象与估计量

$$V_{\mathrm{digital}}=e^{-rT}\Phi(d_2),\quad d_2=\frac{\ln(S/K)+(r-q-\sigma^2/2)T}{\sigma\sqrt T}$$

统计结构与推导

在连续股息收益率、常数波动率和风险中性几何布朗运动假设下，到期标的高于执行价的风险中性概率为标准正态分布函数在d2处的值。乘无风险贴现因子得到支付固定一单位现金的数字期权价格。

数值计算与经济解释

标的与执行价都为100、利率股息率均为零、波动率为20%、期限为一年时，d2为负0.1，数字看涨价格约为0.46017。该数值是单位现金到期支付的现值。

识别条件、数据口径与边界

数字期权的支付在行权点不连续，实际交易的报价跳跃与复制对冲成本可能显著。模型假设使用连续路径与常数参数，不能直接等同于真实分布尾概率。

CSV或参数复算

./kline_quant digital-call 100 100 0 0 0.2 1

2．看涨期权Vanna

数学对象与估计量

$$\mathrm{Vanna}=\frac{\partial^2C}{\partial S\,\partial\sigma}=-e^{-qT}\varphi(d_1)\frac{d_2}{\sigma}$$

统计结构与推导

Vanna是Delta对隐含波动率的偏导，亦可解释为Vega对标的价格的偏导。由Black–Scholes看涨Delta对波动率求导，利用d1与d2关系得到解析式。

数值计算与经济解释

当标的和执行价相等，利率与股息率为零，波动率为20%、期限为一年时，d1为0.1、d2为负0.1，Vanna为正，说明小幅增加波动率会提高该位置的Delta。

识别条件、数据口径与边界

Vanna数值的单位依赖波动率输入的表示方式；代码使用小数形式的年化波动率，二阶局部敏感度不替代大幅波动冲击时的期权全重估。

CSV或参数复算

./kline_quant vanna-call 100 100 0 0 0.2 1

3．看涨期权Volga（Vomma）

数学对象与估计量

$$\mathrm{Volga}=\frac{\partial^2C}{\partial\sigma^2}=\mathrm{Vega}\frac{d_1d_2}{\sigma}$$

统计结构与推导

Volga度量Vega随波动率变化的曲率。以Black–Scholes的Vega为起点对波动率再求导，可将二阶敏感度表示为Vega乘以d1和d2的乘积再除以波动率。

数值计算与经济解释

平值期权且r=q=0、sigma为0.2、T为1时，d1=0.1、d2=-0.1，所以Volga为负；这一局部二阶符号与实际大幅波动变化的总价格方向是不同概念。

识别条件、数据口径与边界

隐含波动率曲面变形包含到期和执行价之间的联动，不同点的Vega与Volga不能在无共同冲击规则下机械求和。

CSV或参数复算

./kline_quant volga-call 100 100 0 0 0.2 1

4．两期限隐含远期方差

数学对象与估计量

$$\sigma^2_{f}(T_1,T_2)=\frac{T_2\sigma_2^2-T_1\sigma_1^2}{T_2-T_1}$$

统计结构与推导

在零息贴现与方差期限结构的简化研究中，总方差可以写成期限乘对应年化隐含方差。两个期限的总方差差除以期限差，形成区间隐含远期方差。

数值计算与经济解释

近期限1年波动率为20%，远期限2年波动率为30%，隐含总方差分别为0.04和0.18。期限差为1年，远期方差为0.14，对应远期波动率约37.4%。

识别条件、数据口径与边界

不同执行价的隐含波动率曲面并不天然对应可交易方差合约的无套利总方差。函数拒绝负向总方差差，但实际期限结构还涉及风险中性方差、定价误差和插值规则。

CSV或参数复算

./kline_quant forward-variance 1 0.2 2 0.3

#pragma once
#include "stats.hpp"
#include <algorithm>
#include <cmath>
#include <vector>
namespace kline {
inline double black_scholes_cash_digital_call(
 double spot,double strike,double rate,double dividend,double sigma,double maturity){
 require(std::isfinite(spot)&&spot>0&&std::isfinite(strike)&&strike>0&&
         std::isfinite(rate)&&std::isfinite(dividend)&&
         std::isfinite(sigma)&&sigma>0&&std::isfinite(maturity)&&maturity>0,
         "Invalid cash-or-nothing option");
 const double d2=(std::log(spot/strike)+(rate-dividend-0.5*sigma*sigma)*maturity)/
                 (sigma*std::sqrt(maturity));
 return std::exp(-rate*maturity)*0.5*std::erfc(-d2/std::sqrt(2.0));
}
inline double black_scholes_vanna_call(
 double spot,double strike,double rate,double dividend,double sigma,double maturity){
 require(std::isfinite(spot)&&spot>0&&std::isfinite(strike)&&strike>0&&
         std::isfinite(rate)&&std::isfinite(dividend)&&
         std::isfinite(sigma)&&sigma>0&&std::isfinite(maturity)&&maturity>0,
         "Invalid vanna option");
 const double d1=(std::log(spot/strike)+(rate-dividend+0.5*sigma*sigma)*maturity)/
                 (sigma*std::sqrt(maturity));
 const double d2=d1-sigma*std::sqrt(maturity);
 return -std::exp(-dividend*maturity-d1*d1/2)/std::sqrt(2*std::acos(-1.0))*
        d2/sigma;
}
inline double black_scholes_volga_call(
 double spot,double strike,double rate,double dividend,double sigma,double maturity){
 require(std::isfinite(spot)&&spot>0&&std::isfinite(strike)&&strike>0&&
         std::isfinite(rate)&&std::isfinite(dividend)&&
         std::isfinite(sigma)&&sigma>0&&std::isfinite(maturity)&&maturity>0,
         "Invalid volga option");
 const double d1=(std::log(spot/strike)+(rate-dividend+0.5*sigma*sigma)*maturity)/
                 (sigma*std::sqrt(maturity));
 const double d2=d1-sigma*std::sqrt(maturity);
 const double vega=spot*std::exp(-dividend*maturity-d1*d1/2)*
                   std::sqrt(maturity/(2*std::acos(-1.0)));
 return vega*d1*d2/sigma;
}
inline double annualized_forward_variance(
 double nearYears,double nearVol,double farYears,double farVol){
 require(std::isfinite(nearYears)&&nearYears>=0&&
         std::isfinite(farYears)&&farYears>nearYears&&
         std::isfinite(nearVol)&&nearVol>=0&&
         std::isfinite(farVol)&&farVol>=0,
         "Invalid implied volatility maturities");
 const double diff=farYears*farVol*farVol-nearYears*nearVol*nearVol;
 require(diff>=-1e-12,"Calendar total variance decreases");
 return std::max(0.0,diff)/(farYears-nearYears);
}
}
