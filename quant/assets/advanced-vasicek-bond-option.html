Vasicek利率模型：零息债券期权与远期测度

高级研究方法　完整模型源码　公共数值函数

模型定义与识别条件

Vasicek短率为高斯均值回复扩散，零息债券价格具指数仿射形式。债券期权在行权日S对应剩余到期T的债券价格；采用S期债券作为numeraire后，债券远期在高斯模型下呈对数正态，得到Black形式价格。负短率在Vasicek中允许存在。

数学推导与求解机制

先由风险中性短率参数计算两只零息债券现值，再计算S至T债券加载及积分方差。用expm1处理短期限或小κ时的消减误差。零波动时远期确定，采用贴现内在价值。输出两种折现因子、远期、对数方差及平价残差。

$$dr_t=\kappa(\theta-r_t)dt+\sigma dW_t^Q$$
$$B(t,T)=\frac{1-e^{-\kappa(T-t)}}{\kappa},\quad P(t,T)=\exp(A(t,T)-B(t,T)r_t)$$
$$A=(\theta-\sigma^2/(2\kappa^2))(B-\tau)-\sigma^2B^2/(4\kappa)$$
$$v=\sigma^2B(S,T)^2\frac{1-e^{-2\kappa S}}{2\kappa},\quad F=P(0,T)/P(0,S)$$
$$C=P(0,S)[F\Phi(d_1)-K\Phi(d_2)],\quad d_{1,2}=\frac{\log(F/K)\pm v/2}{\sqrt v}$$

独立解析基准

零短率、长期均值0、波动0时，两只债券均为1；K=0.9，期权看涨0.1、看跌0。非零波动时检验看涨看跌平价和价格对行权价的单调性。

计算复杂度与研究边界

每条情景O(1)，κ严格正，σ非负，0<S<T，执行价为债券价格单位。常参数Vasicek一般不能精确匹配任意初始市场期限结构；Hull–White通过时变漂移扩展。期权价格由模型风险中性参数决定，不等于历史短率回归的直接外推。

C++17完整实现

inline Report vasicek_bond_option(const Mat& x,const Vec& p){
    validate(x,1,7,7);parameters(p,0);
    Report o{{"DiscountExpiry","DiscountMaturity","BondForward","LogForwardVariance","Call","Put","ParityResidual"},{}};
    for(auto&r:x){
        double r0=r[0],k=positive(r[1]),theta=r[2],sig=r[3],s=positive(r[4]),t=positive(r[5]),K=positive(r[6]);
        require(sig>=0&&t>s&&k>=1e-6,"Invalid Vasicek option domain");
        auto B=[&](double h){return -std::expm1(-k*h)/k;};
        auto P=[&](double h){double b=B(h),a=(theta-sig*sig/(2*k*k))*(b-h)-sig*sig*b*b/(4*k);return positive(std::exp(a-b*r0));};
        double ps=P(s),pt=P(t),f=pt/ps,v=sig*sig*B(t-s)*B(t-s)*(-std::expm1(-2*k*s))/(2*k);
        double c,put;
        if(v==0){c=ps*std::max(f-K,0.);put=ps*std::max(K-f,0.);}
        else{double d1=(std::log(f/K)+v/2)/std::sqrt(v),d2=d1-std::sqrt(v);c=ps*(f*normal(d1)-K*normal(d2));put=ps*(K*normal(-d2)-f*normal(-d1));}
        o.rows.push_back({ps,pt,f,v,c,put,c-put-(pt-K*ps)});
    }
    return o;
}
