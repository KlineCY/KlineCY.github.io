算术亚式期权模拟：独立pilot控制变量与方差缩减

系统化研究与实验　完整源码

经济机制与模型设定

算术平均是相关对数正态变量之和，一般无简单闭式价格。以同路径几何平均支付作控制变量，能利用几何平均解析价格及两者强相关减少采样误差。独立pilot样本估计系数，正式估计样本不再改变该系数。

推导与计算方法

每条GBM路径使用精确对数增量，累计算术和与对数和，构造两种折现支付。pilot计算样本协方差及方差；若控制变量恒定则系数0。正式样本同时积累原始支付与控制后支付的均值和标准误。

$$A_m=m^{-1}\sum_{j=1}^m S_{jT/m},\quad X=e^{-rT}(A_m-K)^+$$
$$Y=e^{-rT}(G_m-K)^+,\quad E[Y]=C_{\rm geom}$$
$$\beta=\operatorname{Cov}(X,Y)/\operatorname{Var}(Y)$$
$$\widehat C_{\rm cv}=n^{-1}\sum_{i=1}^n[X_i-\hat\beta_{\rm pilot}(Y_i-EY)]$$

可复算样本与解析基准

零波动、零利率、现货100、执行价90，两种支付均为10，标准误0、控制系数0、方差比约定1。非退化情形应比较两种标准误，并用独立随机种子检验统计波动。

研究边界及计算复杂度

O((pilot+n)m)时间及常数状态存储。控制变量不会消除监测约定或模型误差；方差比是有限样本估计，可能大于1。随机数生成器跨标准库不保证逐路径完全一致。

C++17完整实现

inline Report asian_arithmetic_control(const Mat& x,const Vec& p){
    validate(x,1,6,6);parameters(p,4);auto m=count(p[0],1,10000),pilot=count(p[1],2,1000000),n=count(p[2],2,2000000),seed=count(p[3],0,1000000000);require(double(m)*(pilot+n)*x.size()<=1e8,"Asian simulation work limit");Report o{{"PlainCall","ControlledCall","PlainSE","ControlledSE","PilotBeta","ExactGeometricCall","VarianceReduction"},{}};for(std::size_t k=0;k<x.size();++k){auto&r=x[k];double S=positive(r[0]),K=positive(r[1]),rate=r[2],q=r[3],sig=r[4],T=positive(r[5]);require(sig>=0,"Nonnegative volatility required");double dt=T/m,df=std::exp(-rate*T),a=std::log(S)+(rate-q-.5*sig*sig)*T*(m+1)/(2*m),v=sig*sig*T*(m+1)*(2.*m+1)/(6.*m*m),f=std::exp(a+v/2),exact=df*std::max(f-K,0.);if(v>0){double d2=(a-std::log(K))/std::sqrt(v);exact=df*(f*normal(d2+std::sqrt(v))-K*normal(d2));}std::mt19937_64 gen(seed+k);std::normal_distribution<double> norm(0,1);auto path=[&](){double l=std::log(S),s=0,g=0;for(std::size_t j=0;j<m;++j){l+=(rate-q-.5*sig*sig)*dt+sig*std::sqrt(dt)*norm(gen);s+=std::exp(l)/m;g+=l/m;}return Vec{df*std::max(s-K,0.),df*std::max(std::exp(g)-K,0.)};};double mx=0,my=0,cov=0,vy=0;for(std::size_t i=1;i<=pilot;++i){Vec z=path();double dx=z[0]-mx,dy=z[1]-my;mx+=dx/i;my+=dy/i;cov+=dx*(z[1]-my);vy+=dy*(z[1]-my);}double beta=vy>0?cov/vy:0;double u=0,w=0,ss=0,tt=0;for(std::size_t i=1;i<=n;++i){Vec z=path();double y=z[0]-beta*(z[1]-exact),du=z[0]-u,dw=y-w;u+=du/i;w+=dw/i;ss+=du*(z[0]-u);tt+=dw*(y-w);}o.rows.push_back({u,w,std::sqrt(std::max(0.,ss)/(n-1)/n),std::sqrt(std::max(0.,tt)/(n-1)/n),beta,exact,ss>0?tt/ss:1});}return o;
}
