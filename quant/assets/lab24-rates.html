1．年度平价息票债的贴现曲线自举

模型结构与数学定义

以面值1的年度付息平价债券为基本工具，先确定一年期贴现因子，再逐期限利用已知短端贴现因子解出最后一笔现金流的贴现因子。输出各年度贴现因子，供随后估值使用。

$$D_n=\frac{1-c_n\sum_{j<n}D_j}{1+c_n}$$

推导、最优性条件与数值结构

$$1=c_nD_1+\cdots+c_nD_{n-1}+(1+c_n)D_n$$

每个期限的平价债券定价方程包含先前全部付息日贴现因子，以及最后一期面值和息票。已知短端因子后，方程仅剩一个未知数，直接移项获得自举递推。

完整计算案例

第一年息票率5%、第二年息票率5%，平坦年度利率曲线给出贴现因子1/1.05、1/1.05²。

$$\mathrm{Output}\approx\left(0.952380952,\ 0.907029478\right)$$

输出顺序：依期限排列的贴现因子。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

2．非等距贴现节点的连续复利远期利率

模型结构与数学定义

贴现曲线节点间的连续复利远期利率由无套利贴现因子比值推出。将时间0、贴现因子1作为隐含起点，逐相邻节点计算区间平均远期利率，避免直接将零息利率差解释为远期利率。

$$f(t_i,t_{i+1})=\frac{\log D(t_i)-\log D(t_{i+1})}{t_{i+1}-t_i}$$

推导、最优性条件与数值结构

$$D(t_{i+1})=D(t_i)e^{-f_i(t_{i+1}-t_i)},\quad f_i=\frac{t_{i+1}z_{i+1}-t_i z_i}{t_{i+1}-t_i}$$

从贴现因子的一致性条件可解出远期折现率。若使用零息利率表达，连续复利远期为相邻两个总利率期限乘积之差再除以期限差。

完整计算案例

期限1、2年的贴现因子分别为exp(−0.02)、exp(−0.06)，两个区间的远期利率依次为2%、4%。

$$\mathrm{Output}\approx\left(0.02,\ 0.04\right)$$

输出顺序：从时间0起各相邻期限区间的连续复利远期利率。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

3．分段线性零息曲线的节点DV01

模型结构与数学定义

将给定节点零息利率通过分段线性方式插值到现金流时间，并在曲线端点采用平坦外推。独立向上平移一个节点1个基点，重复完整估值，得到节点敏感度向量；与所有节点同时平移不同，该方法保留曲线局部形变。

$$P=\sum_j C_je^{-t_j z(t_j)},\quad DV01_k=P(z)-P(z+10^{-4}e_k)$$

推导、最优性条件与数值结构

$$z(t)=(1-\omega_t)z_1+\omega_tz_2,\quad \omega_t=\min(1,\max(0,(t-t_1)/(t_2-t_1)))$$

节点利率的扰动经插值权重传导至各现金流折现率。节点1上移后，第j笔现金流的相对现值变化为1−exp(−t_j(1−ω_j)10⁻⁴)，节点2同理。该表达使有限差分无需对两个接近的大数作差。

完整计算案例

曲线节点为1年2%、2年4%，支付时间恰在两节点，现金流10、100。每个节点DV01等于对应现金流现值乘以1−exp(−0.0001t)。

$$\mathrm{Output}\approx\left(102.113621,\ 0.000980149665,\ 0.0184604808\right)$$

输出顺序：原始现值、第一个节点DV01、第二个节点DV01。以下CSV按列顺序定义输入，首行为字段名。命令按上述参数口径读取数值。

4．双零息债对确定性负债的久期免疫

模型结构与数学定义

以两个到期年限不同的零息债组合匹配负债的现值与对连续复利平行利率冲击的一阶敏感度。求解两元线性系统获得两债现值权重，再由贴现率转换为到期面值。输出两项配置面值及两项现值。

$$V_1+V_2=L,\quad t_1V_1+t_2V_2=t_LL$$

推导、最优性条件与数值结构

$$V_2=L\frac{t_L-t_1}{t_2-t_1},\quad V_1=L-V_2,\quad F_i=V_ie^{rt_i}$$

以第二债权重代替第一债权重，现值约束代入久期约束后得到一元线性方程。零息债的连续复利修正久期等于其到期时间，故现值匹配与一阶风险匹配可同时满足。

5．带括区保护的连续复利债券到期收益率求解

模型结构与数学定义

对正现金流债券，现值随连续复利收益率严格下降。先验证给定收益率上下界夹住目标价格，再利用二分法稳定缩小括区；若Newton步仍落在括区内，则使用其加速收敛。输出收益率及价格残差。

$$F(y)=\sum_iC_ie^{-yt_i}-P,\quad F'(y)=-\sum_it_iC_ie^{-yt_i}$$

推导、最优性条件与数值结构

$$y_{k+1}^{N}=y_k-\frac{F(y_k)}{F'(y_k)}$$

严格正现金流使F单调下降，且F二阶导数为正。Newton法通常局部快速收敛；利用价格残差符号不断缩小括区，只有候选Newton步保持在括区内部才采用，否则回到二分中点。

完整计算案例

一年后支付110，现价100，连续复利收益率为log(1.1)，价格残差趋近0。

$$\mathrm{Output}\approx\left(0.0953101798,\ 0\right)$$

#pragma once
#include "lab24_common.hpp"

namespace kline { namespace lab24 {
inline Vec discount_bootstrap(const Mat& x,const Vec& p){
    inputs(x,p,1,0);Vec d;double s=0;
    for(const auto& r:x){require(r[0]>-1,"Invalid coupon rate");double q=positive((1-r[0]*s)/(1+r[0]));d.push_back(q);s+=q;}
    return checked(d);
}

inline Vec forward_curve(const Mat& x,const Vec& p){
    inputs(x,p,2,0);double t=0,logd=0;Vec out;
    for(const auto& r:x){require(r[0]>t,"Maturities must increase");double q=std::log(positive(r[1]));out.push_back((logd-q)/(r[0]-t));t=r[0];logd=q;}
    return checked(out);
}

inline Vec curve_keyrate(const Mat& x,const Vec& p){
    inputs(x,p,2,4);require(p[0]>0&&p[1]>p[0],"Invalid key-rate nodes");
    double pv=0,k1=0,k2=0;
    for(const auto& r:x){require(r[0]>=0,"Negative cash-flow time");double h=std::clamp((r[0]-p[0])/(p[1]-p[0]),0.0,1.0);double v=r[1]*std::exp(-r[0]*((1-h)*p[2]+h*p[3]));pv+=v;k1+=v*(-std::expm1(-.0001*r[0]*(1-h)));k2+=v*(-std::expm1(-.0001*r[0]*h));}
    return checked({pv,k1,k2});
}

inline Vec duration_immunize(const Mat& x,const Vec& p){
    inputs(x,p,1,3,2);require(x.size()==2,"Two instruments required");
    double a=x[0][0],b=x[1][0],l=positive(p[0]),t=p[1],r=p[2];require(a>0&&b>a&&t>=a&&t<=b,"Invalid maturity bracket");
    double v2=l*(t-a)/(b-a),v1=l-v2;
    return checked({v1*std::exp(r*a),v2*std::exp(r*b),v1,v2});
}

inline Vec yield_newton(const Mat& x,const Vec& p){
    inputs(x,p,2,3);double price=positive(p[0]),lo=p[1],hi=p[2];require(lo<hi,"Reversed yield bracket");
    for(const auto& r:x){positive(r[0]);positive(r[1]);}
    auto f=[&](double y){double v=-price,d=0;for(const auto& r:x){double c=r[1]*std::exp(-y*r[0]);v+=c;d-=r[0]*c;}require(std::isfinite(v)&&std::isfinite(d),"Yield bracket causes overflow");return std::pair<double,double>{v,d};};
    require(f(lo).first>=0&&f(hi).first<=0,"Price not bracketed");
    double y=lo+(hi-lo)/2;
    for(int i=0;i<150;++i){auto a=f(y);if(std::abs(a.first)<1e-12*price)break;if(a.first>0)lo=y;else hi=y;double z=y-a.first/a.second;y=std::isfinite(z)&&z>lo&&z<hi?z:lo+(hi-lo)/2;}
    require(std::abs(f(y).first)<=1e-8*price,"Yield iteration did not converge");return checked({y,f(y).first});
}
} }

namespace kline { namespace lab24 {
using Vec=std::vector<double>;
using Mat=std::vector<Vec>;

inline void inputs(const Mat& x,const Vec& p,std::size_t cols,std::size_t params,
                   std::size_t min_rows=1) {
    require(x.size()>=min_rows&&x.size()<=250000,"Invalid number of observations");
    require(p.size()==params,"Incorrect scalar parameter count");
    for(double v:p)require(std::isfinite(v),"Nonfinite scalar parameter");
    for(const auto& row:x){
        require(row.size()==cols,"Unexpected CSV column count");
        for(double v:row)require(std::isfinite(v),"Nonfinite matrix entry");
    }
}
inline std::size_t integer(double x,std::size_t low,std::size_t high){
    require(std::isfinite(x)&&x>=double(low)&&x<=double(high)&&std::floor(x)==x,
            "Integer parameter outside allowed range");
    return std::size_t(x);
}
inline double dot(const Vec& a,const Vec& b){
    require(a.size()==b.size(),"Dot product dimension mismatch");
    return std::inner_product(a.begin(),a.end(),b.begin(),0.0);
}
inline Vec col(const Mat& x,std::size_t j){
    Vec out;out.reserve(x.size());
    for(const auto& row:x)out.push_back(row.at(j));
    return out;
}
inline double positive(double x){require(x>0&&std::isfinite(x),"Positive finite quantity required");return x;}
inline Vec checked(Vec v){check_finite(v);return v;}
inline double logistic(double x){
    if(x>=0)return 1/(1+std::exp(-x));
    double e=std::exp(x);return e/(1+e);
}
inline double normal_cdf(double x){return 0.5*std::erfc(-x/std::sqrt(2.0));}
inline double sum(const Vec& v){return std::accumulate(v.begin(),v.end(),0.0);}
