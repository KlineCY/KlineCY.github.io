对数贴现曲线的区间瞬时远期

数学定义与推导

零息贴现因子等于瞬时远期的负积分指数。若在曲线节点之间对logD作线性插值，区间瞬时远期恒等于两端logD的负斜率。该插值使贴现因子连续，但远期在节点可能跳跃；负远期并不必然违背无套利。

$$f(0,t)=-\partial_t\log D(0,t)$$
$$\log D(0,T)-\log D(0,t)=-\int_t^Tf(0,u)\,du$$
$$\bar f_{t,T}=\frac{\log D(0,t)-\log D(0,T)}{T-t}$$

数值演算与金融应用

D(0)=1、D(1)=0.95、D(3)=0.81，首区间远期−ln0.95，第二区间为ln(0.95/0.81)/2。用于利率曲线情景与现金流插值，必须区别于简单复利远期。

算法复杂度、输入契约与边界

O(n)，节点严格递增且贴现因子正，允许负利率。输入日期已转换为同一计息年分数；若使用平滑样条，瞬时远期形状将不同。

远期起始互换的固定腿年金与平价利率

数学定义与推导

单曲线、无信用与本金交换的互换中，浮动利率现金流现值望远镜相消为起始与终止贴现差。固定腿每次支付N K α_i，年金为各支付贴现权重之和。对固定票息K的敏感度为NA，不等同于整条市场利率曲线平移后的DV01。

$$A=\sum_i\alpha_iD(0,t_i),\quad P_{\mathrm{float}}=N[D(0,t_0)-D(0,t_n)]$$
$$K^*=\frac{D(0,t_0)-D(0,t_n)}{A}$$
$$V_{\mathrm{rec}}=N(KA-D(0,t_0)+D(0,t_n)),\quad \mathrm{PV01}_{K}=NA\,10^{-4}$$

数值演算与金融应用

起始贴现1、终止0.9，两个半年支付贴现0.95与0.9，年金0.925，平价利率约10.8108％。名义100、固定票息10％时，收固定价值−0.75，票息每1bp敏感度0.00925。

算法复杂度、输入契约与边界

O(n)，年分数与贴现正、起始贴现正，固定利率允许负。多曲线环境浮动远期应由预测曲线计算并用抵押曲线贴现，本公式仅单曲线。

FRA在计息期开始时的提前现金结算

数学定义与推导

以收浮动付固定的FRA为例，若利率差在计息终点支付，则金额为名义乘年分数乘差值。实际提前在起始日结算时，以当期确定的浮动率折回，使提前金额再投资到期恰等于终点支付。不能把事前估计远期利率直接代入实现结算。

$$H_T=N\alpha(L-K)$$
$$H_{t_0}=\frac{N\alpha(L-K)}{1+\alpha L}$$
$$H_{t_0}(1+\alpha L)=H_T$$

数值演算与金融应用

名义1000、固定4％、半年期。若fixing为6％，终点差额10、开始结算约9.7087；若fixing为2％，结算为−9.9010。方向约定为收浮动，改变持仓方向需改变符号。

算法复杂度、输入契约与边界

O(n)，计息年分数正，名义正，1+αL须正，利率可为负。实际合同依基准利率、日计数和结算约定确定，不能用本例替代合同条款。

隔夜复利的逐日累计与线性差额

数学定义与推导

隔夜利率按每段实际日计数生成增长因子，多个重置日通过乘积形成复利累计。线性累计忽略交叉项；当利率为负或变化时，差额不保证总是正。使用log1p加总再expm1可稳定计算小利率乘积。

$$G_i=1+r_i\delta_i,\quad G_{1:n}=\prod_iG_i$$
$$R_c=G_{1:n}-1,\quad R_s=\sum_i r_i\delta_i$$
$$R_c-R_s=\sum_{i<j}r_i\delta_i r_j\delta_j+\cdots$$

数值演算与金融应用

两段利率4％与8％、年分数各0.25，增长因子1.01和1.02，复利累计3.02％、线性3％，差额0.02个百分点。示例较长计息段仅用于演算；真实RFR还涉及节假日、lookback、lockout等规则。

算法复杂度、输入契约与边界

O(n)，各年分数正且增长因子正。输入按实际观察顺序，重复利率跨节假日需由上游计息规则展开。该工具不是特定交易所或基准的正式结算规则。

C++17完整实现

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace depth_termstructure {
using namespace evidence;
inline Report log_discount_forward(const Mat& x,const Vec& p){
    validate(x,2,2,2);parameters(p,0);Report o{{"Start","End","DiscountRatio","ContinuousForward"},{}};
    for(std::size_t i=0;i<x.size();++i){auto&r=x[i];require(r[0]>=0,"Negative time");positive(r[1]);if(i){auto&a=x[i-1];double h=positive(r[0]-a[0]);o.rows.push_back({a[0],r[0],r[1]/a[1],(std::log(a[1])-std::log(r[1]))/h});}}return o;
}

inline Report forward_swap_annuity(const Mat& x,const Vec& p){
    validate(x,1,2,2);parameters(p,3);double start=positive(p[0]),N=positive(p[1]),K=p[2],a=0;
    for(auto&r:x)a+=positive(r[0])*positive(r[1]);positive(a);
    double f=N*(start-x.back()[1]),v=N*K*a;return scalar({"Annuity","ParRate","FixedPV","FloatPV","ReceiveFixedPV","DV01"},{a,(start-x.back()[1])/a,v,f,v-f,N*a*1e-4});
}

inline Report fra_settlement(const Mat& x,const Vec& p){
    validate(x,1,2,2);parameters(p,2);double N=positive(p[0]),K=p[1];Report o{{"FixingRate","Accrual","EndPayment","StartSettlement"},{}};
    for(auto&r:x){double a=positive(r[1]),v=N*a*(r[0]-K),d=positive(1+a*r[0]);o.rows.push_back({r[0],a,v,v/d});}return o;
}

inline Report overnight_accrual_bridge(const Mat& x,const Vec& p){
    validate(x,1,2,2);parameters(p,0);double l=0,s=0;Report o{{"Period","AccrualFactor","CompoundedReturn","SimpleAccrued","CompoundingGap"},{}};
    for(std::size_t i=0;i<x.size();++i){auto&r=x[i];double a=r[0]*positive(r[1]);positive(1+a);l+=std::log1p(a);s+=a;double v=std::expm1(l);o.rows.push_back({double(i+1),1+a,v,s,v-s});}return o;
}
} }
