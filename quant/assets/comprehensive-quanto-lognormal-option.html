固定汇率支付

Quanto合约将外币标的的支付按事先约定固定汇率转换为本币，故期末随机汇率不直接进入支付。但在本币风险中性测度下，外币标的漂移与本币/外币汇率协方差有关。明确X为每单位外币对应的本币价格，可确定相关性调整的符号。

$$dS_t/S_t=(r_f-q-\rho\sigma_S\sigma_X)dt+\sigma_SdW_t^d,\quad X=\text{domestic currency per foreign currency}$$

远期与解析公式

本币测度下标的条件期望为Quanto远期F_Q=S exp[(r_f−q−ρσSσX)T]，再以本币无风险利率折现固定汇率支付。使用Black型对数正态截断期望；与普通外币期权价格乘随机汇率或当前汇率不同。

$$C=X_0^*e^{-r_dT}(F_Q\Phi(d_1)-K\Phi(d_2)),\quad d_1=\frac{\log(F_Q/K)+\sigma_S^2T/2}{\sigma_S\sqrt T},\ d_2=d_1-\sigma_S\sqrt T$$

相关性与平价

正相关且采用本币/外币汇率定义时，Quanto漂移降低，其他参数固定时看涨远期价值下降。看涨看跌平价为固定汇率乘本币折现的Quanto远期减执行价。σS=0时用确定性支付，避免除零。

$$C-P=X_0^*e^{-r_dT}(F_Q-K),\quad \partial_\rho\log F_Q=-\sigma_S\sigma_XT$$

参考与边界

标的100、执行价90、利率股息0、标的波动0、固定汇率1，确定性看涨价10。改变汇率波动和相关性但标的波动为0时，调整项仍为0。模型假设常数利率、波动率及相关性，不包含随机基差、随机利率或相关性微笑。

$$F_Q=F_f\exp(-\rho\sigma_S\sigma_XT),\quad F_f=S_0e^{(r_f-q)T}$$

inline Report quanto_lognormal_option(const Mat& x,const Vec& p){
    validate(x,1,10,10);parameters(p,0);
    Report out{{"Call","Put","QuantoForward","AdjustedDrift","DiscountedUnderlying","ParityResidual"},{}};
    for(auto&r:x){
        double S=positive(r[0]),K=positive(r[1]),rd=r[2],rf=r[3],q=r[4],s=r[5],v=r[6],rho=r[7],T=positive(r[8]),fx=positive(r[9]);
        require(s>=0&&v>=0&&std::abs(rho)<=1,"Invalid quanto volatility or correlation");
        double drift=rf-q-rho*s*v,F=positive(S*std::exp(drift*T)),df=positive(fx*std::exp(-rd*T)),c,put;
        if(s==0){c=df*std::max(F-K,0.);put=df*std::max(K-F,0.);}
        else{
            double z=s*std::sqrt(T),d1=std::log(F/K)/z+z/2,d2=d1-z;
            c=df*(F*normal(d1)-K*normal(d2));put=df*(K*normal(-d2)-F*normal(-d1));
        }
        out.rows.push_back({c,put,F,drift,df*F,c-put-df*(F-K)});
    }
    return out;
}
