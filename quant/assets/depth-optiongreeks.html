现金二元与资产二元期权的支付分解

数学定义与推导

将普通看涨在价内区域的支付拆成一单位资产二元支付减K单位现金二元支付。对风险中性对数正态分布积分，现金二元是贴现概率；资产二元是截断一阶矩，完成平方后正态阈值从d2变为d1。Delta与风险中性价内概率分别含d1与d2，经济解释不同。

$$(S_T-K)^+=S_T\mathbf1_{\{S_T>K\}}-K\mathbf1_{\{S_T>K\}}$$
$$D_c=e^{-rT}\Phi(d_2),\quad D_a=S_0e^{-qT}\Phi(d_1)$$
$$C=D_a-KD_c,\quad Q(S_T>K)=\Phi(d_2)$$

数值演算与金融应用

现货及执行价100、零利率分红、波动率20％、一年期限，d1=0.1、d2=−0.1。两二元腿组合的价格约7.9656。数字期权支付跳跃，临近执行价时Delta和Gamma可变得很大，报价误差对隐含概率敏感。

算法复杂度、输入契约与边界

每行独立BS参数，S、K、σ、T严格正，利率可为负。O(n)。欧式、常波动、连续分红假设；真实数字期权需考虑执行价附近微笑与离散结算规则。

Black–Scholes交叉敏感度Vanna与Volga

数学定义与推导

对BS Delta关于σ求导，利用d1对σ的导数等于−d2/σ，得到Vanna。再对Vega求导，正态密度导数为−d1φ(d1)，由此得到Volga。欧式看涨和看跌的这些波动相关敏感度相同，因为平价差不依赖σ。

$$\mathrm{Vega}=S_0e^{-qT}\varphi(d_1)\sqrt T$$
$$\mathrm{Vanna}=\partial_\sigma\Delta=-e^{-qT}\varphi(d_1)d_2/\sigma$$
$$\mathrm{Volga}=\partial_\sigma^2 C=\mathrm{Vega}\,d_1d_2/\sigma$$

数值演算与金融应用

平值样本d1=0.1、d2=−0.1，Vega约39.695，Vanna约0.1985，Volga约−1.9848。Vega是波动率以绝对单位1变化的导数；按1个百分点计价需乘0.01，二阶项要使用一致单位。

算法复杂度、输入契约与边界

O(n)，输入同BS模型，σ及期限严格正。高阶Greek为局部导数，波动率曲面同时随现货移动时，sticky-strike与sticky-delta情景不同，不能机械套用常波动导数。

零持有成本近似下Gamma对冲方差损益

数学定义与推导

在零利率及分红、波动率不变的BS局部近似中，Delta对冲移除一阶现货项，PDE将Theta与隐含方差Gamma项对应。剩余损益近似为实现平方收益与隐含方差之差乘美元Gamma。这里逐期使用给定的期初现货与Gamma，不根据后验收益重新估计。

$$dC\approx\Delta\,dS+\Theta\,dt+\tfrac12\Gamma(dS)^2$$
$$\Theta+\tfrac12\sigma_{\mathrm{imp}}^2S^2\Gamma=0\quad(r=q=0)$$
$$\Delta\Pi\approx\tfrac12\Gamma S^2(r_t^2-\sigma_{\mathrm{imp}}^2\Delta t)$$

数值演算与金融应用

现货100、Gamma0.02、隐含波动20％、日长1/252。两日收益3％和−1％的实现Gamma项0.09与0.01，隐含Theta项每天−4/252。正Gamma组合在高实现方差情景获益，但不能忽略交易成本与跳跃。

算法复杂度、输入契约与边界

O(n)，Δt>0、隐含波动非负、现货正；Gamma可正可负。该式是小变动二阶近似，不是含利率、分红、Vega、离散对冲及成本的精确损益账本。

现货与波动率联合冲击的二阶损益归因

数学定义与推导

对期权价值在现货和波动两个维度做二阶Taylor展开。Hessian的交叉项出现两次，抵销二阶展开前的1/2，所以Vanna项没有额外1/2。每个头寸先乘合约数量再汇总，避免将单合约Greek误作组合Greek。

$$\Delta C\approx C_S\Delta S+C_\sigma\Delta\sigma+\tfrac12C_{SS}(\Delta S)^2+C_{S\sigma}\Delta S\Delta\sigma+\tfrac12C_{\sigma\sigma}(\Delta\sigma)^2$$
$$\Delta\Pi_j=n_j\Delta C_j$$
$$\Delta\Pi_{\mathrm{total}}=\sum_j\Delta\Pi_j$$

数值演算与金融应用

两头寸数量2及−1，现货冲击3、波动冲击0.02。第一头寸Delta贡献3、Gamma贡献0.18、Vega贡献0.4、交叉0.012、Volga0.0008。第二头寸方向相反。适合风险报告中解释近似P&L，不代表精确重新定价。

算法复杂度、输入契约与边界

O(n)，假设各行同一标的及波动冲击，Greek与数量已按合约乘数一致换算。未包含时间衰减、利率及高阶交叉项；较大冲击应对照完整定价。

#pragma once
#include "evidence_common.hpp"
namespace kline { namespace depth_optiongreeks {
using namespace evidence;
inline Report digital_decomposition(const Mat& x,const Vec& p){
    validate(x,1,6,6);parameters(p,0);Report o{{"CashDigital","AssetDigital","ReplicatedCall","RiskNeutralITM"},{}};
    for(auto&r:x){double s=positive(r[0]),k=positive(r[1]),v=positive(r[4]),t=positive(r[5]),z=v*std::sqrt(t),d1=(std::log(s/k)+(r[2]-r[3]+.5*v*v)*t)/z,d2=d1-z;double pr=normal(d2),a=std::exp(-r[2]*t)*pr,b=s*std::exp(-r[3]*t)*normal(d1);o.rows.push_back({a,b,b-k*a,pr});}return o;
}

inline Report vanna_volga(const Mat& x,const Vec& p){
    validate(x,1,6,6);parameters(p,0);Report o{{"Vega","Vanna","Volga"},{}};double c=std::sqrt(2*std::acos(-1.));
    for(auto&r:x){double s=positive(r[0]),k=positive(r[1]),v=positive(r[4]),t=positive(r[5]),z=v*std::sqrt(t),d1=(std::log(s/k)+(r[2]-r[3]+.5*v*v)*t)/z,d2=d1-z,f=std::exp(-d1*d1/2)/c,df=std::exp(-r[3]*t),vega=s*df*f*std::sqrt(t);o.rows.push_back({vega,-df*f*d2/v,vega*d1*d2/v});}return o;
}

inline Report delta_hedge_variance(const Mat& x,const Vec& p){
    validate(x,1,4,4);parameters(p,1);require(p[0]>=0,"Negative implied vol");double s=0;Report o{{"Period","RealizedGamma","ImpliedTheta","NetApprox","Cumulative"},{}};
    for(std::size_t i=0;i<x.size();++i){auto&r=x[i];double z=positive(r[0]),h=positive(r[3]),g=.5*r[1]*z*z,a=g*r[2]*r[2],b=-g*p[0]*p[0]*h;s+=a+b;o.rows.push_back({double(i+1),a,b,a+b,s});}return o;
}

inline Report spot_vol_taylor(const Mat& x,const Vec& p){
    validate(x,1,6,6);parameters(p,2);double ds=p[0],dv=p[1];Report o{{"PositionIndex","DeltaPnL","GammaPnL","VegaPnL","VannaPnL","VolgaPnL","TotalApprox"},{}};
    for(std::size_t i=0;i<x.size();++i){auto&r=x[i];double n=r[0],a=n*r[1]*ds,b=.5*n*r[2]*ds*ds,c=n*r[3]*dv,d=n*r[4]*ds*dv,e=.5*n*r[5]*dv*dv;o.rows.push_back({double(i+1),a,b,c,d,e,a+b+c+d+e});}return o;
}
